# 立体几何

## 三视图与直观图
### 三视图
- 正视图：由前向后
- 侧视图：由左向右或由右向左
- 俯视图：由上向下
### 对应关系
- 长对正：正视图与俯视图
- 高平齐：正视图与侧视图
- 宽相等：俯视图与侧视图
### 斜二测画法
- 横不变：平行 x 轴的线段长度不变
- 纵减半：平行 y 轴的线段长度减半
- 竖不变：平行 z 轴的线段长度不变，方向与 x 轴成 45 度
- 角变 45：两邻边夹角变成 45 度
- 面积比：直观图 = 原图的 √2/2
### 区别
- 三视图用实长，面积不变
- 直观图按斜二测，面积缩小

## 柱锥台球
### 结构特征
- 棱柱：两个面平行且全等，其余是平行四边形
- 棱锥：一个多边形底面，其余面共顶点
- 棱台：棱锥的平行截面
- 圆柱：矩形绕一边旋转
- 圆锥：直角三角形绕直角边旋转
- 圆台：圆锥的平行截面
- 球：半圆弧绕直径旋转
### 体积公式
- 棱柱：V = Sh
- 棱锥：V = Sh/3
- 圆柱：V = πr²h
- 圆锥：V = πr²h/3
- 圆台：V = πh(R² + Rr + r²)/3
- 球：V = 4πR³/3
### 表面积
- 棱柱侧面积：底面周长 × 高
- 圆柱侧面积：2πrh
- 圆锥侧面积：πrl
- 球表面积：S = 4πR²
- 球冠：S = 2πRh
### 轴截面
- 圆锥轴截面是等腰三角形
- 母线：l² = r² + h²
- 大圆面积 = 球表面积的 1/4

## 点线面位置关系
### 直线与直线
- 相交
- 平行
- 异面：既不相交也不平行
### 直线与平面
- 线在面内
- 线面相交
- 线面平行
### 平面与平面
- 平行
#### 相交
- 含垂直这一特殊情形
### 三个空间角
- 异面直线所成角：平移到相交，取锐角
- 直线与平面所成角：直线与射影的夹角
- 二面角：两个半平面围成，范围 0 到 π
### 两个易混概念
- 二面角可以是钝角
- 两平面所成的角只取锐角或直角

## 平行的判定与性质
### 判定定理
- 线面平行：平面外一条直线平行于平面内一条直线
- 面面平行：一个平面内两条相交直线都平行于另一平面
### 性质定理
- 线面平行：过该直线的平面与原平面的交线与该直线平行
- 面面平行：一个平面内的任意直线都平行于另一平面
### 书写四件套
- 直线在平面外
- 一条直线在平面内
- 两线平行
- 引出结论
### 失效的推理
- 线面平行不传递到第三个平面
- 两条平行线定不了平面

## 垂直的判定与性质
### 判定定理
- 线面垂直：一条直线垂直于平面内两条相交直线
- 面面垂直：一个平面过另一个平面的垂线
### 性质定理
- 线面垂直：垂直于同一平面的两直线平行
- 面面垂直：平面内垂直于交线的直线垂直于另一平面
### 四个任意不能省
- 线面垂直结论是任意一条直线
- 不能反推
- 面面垂直性质要先证垂直于交线
- 判定中的垂线要在平面内
### 常用构造
- 正方体的棱互相垂直或平行
- 等腰三角形底边中线垂直底边
- 中位线平行第三边
- 三垂线定理及其逆定理

## 空间向量求角
### 建系原则
- 原点取顶点或中点
- 坐标轴取平行于两平面的两条相交直线
- 法向量至少有一个分量为零
### 坐标书写
- 中点坐标先求后代
- 顶点坐标逐个列出
### 向量
- 方向向量：终点减起点
- 法向量：与平面内两条相交直线都垂直
- 法向量求法：叉积、设元、观察
### 三个公式
- 二面角：cos θ = |n₁ · n₂| / (|n₁||n₂|)
- 线面角：sin θ = |a · n| / (|a||n|)
- 异面直线所成角：sin θ = |a · n| / (|a||n|)，n 为公垂向量
### 锐钝判断
- 法向量绝对值只能给锐角
- 二面角要在棱上作垂直于棱的射线
- 点积为负说明是钝角
### 双验三查
- 验两个点积为零
- 查不与原向量共线
- 查分子绝对值在、结果为正

## 空间中的距离
### 点到平面
- 平面方程：Ax + By + Cz + D = 0
- 法向量：n = (A, B, C)
- 点到平面：d = |Ax₀ + By₀ + Cz₀ + D| / √(A² + B² + C²)
### 点到直线
- 用方向向量与起点向量的投影型公式
- 或先作垂线求垂足再用勾股
### 异面直线距离
- 公垂向量：n = a × b
- 异面直线距离：d = |A₁A₂ · n| / |n|
- 两方向向量互相垂直时可直接取其一作 n
### 体积法
- 体积：V = 底面积 × 高 / 3
- 体积法求距离：d = 3V / 底面积
- 结果必为正，可用来验算向量法

## 常见陷阱
### 斜二测减半的轴记反
### 直观图面积照抄原面积
### 体积公式漏掉 1/3 系数
### 圆锥侧面积写错圆周率个数
### 线面平行判定漏掉平面外
### 面面平行判定用两条平行线
### 线面垂直判定只用一条直线
### 面面垂直性质漏掉垂直于交线
### 法向量夹角直接当二面角
### 法向量与公垂向量不双验
### 证明只写结论不写定理
