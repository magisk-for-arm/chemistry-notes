# 函数与导数

## 函数的概念
### 三要素
#### 定义域 A
#### 对应关系 f
#### 值域 f(A)
### 三件事
#### 求定义域
#### 判单调性
#### 列表作图
### 表示方法
#### 解析式
#### 列表
#### 图象
#### 三者互相印证
#### 特殊点 f(0)、f(1)、f(-1)

## 定义域
### 四查规则
#### 分母 ≠ 0
#### 偶次根内 ≥ 0
#### 对数真数 > 0
#### 正切排除 π/2 + kπ
### 两条易漏
#### 零次负指数
#### 根式套分母要严格大于
### 开闭规律
#### 偶次根式给闭端点
#### 对数真数给开端点
#### 分母在内部挖点
### 验证
#### 任取一点回代

## 单调性
### 定义
#### x1 < x2
#### f(x1) < f(x2)
### 限定
#### 必须在同一区间上
#### 定义域不连通不能整体判
### 常见函数
#### y = x 递增
#### y = x² 两侧反向
#### y = 1/x 两支都减
#### y = aˣ 与 logₐx 同增同减
### 乘除法则
#### 同向单调且恒正 → 乘积递增
#### 反向单调 → 乘积不定
#### 商不宜直接判 → 构造函数之差

## 奇偶性
### 前提
#### 定义域关于原点对称
### 偶函数
#### f(-x) = f(x)
#### 图象关于 y 轴对称
### 奇函数
#### f(-x) = -f(x)
#### 图象关于原点对称
#### 必有 f(0) = 0
### 判定顺序
#### 先对称
#### 后关系
### 常见类型
#### x² + 1 偶
#### x + 1/x 奇
#### x³ - x 奇

## 周期性
### 定义
#### f(x + T) = f(x)
#### T ≠ 0
#### 最小正周期记 T
### 常见周期
#### sin(ωx + φ)：2π/|ω|
#### cos(ωx + φ)：2π/|ω|
#### tan(ωx + φ)：π/|ω|
#### 复合周期取最小公倍数
### 与奇偶联用
#### 搬：用周期把自变量压回已知区间
#### 翻：用奇偶性去掉负号
#### 代：代入已知表达式

## 对称性
### 关于 x = a 对称
#### f(a + x) = f(a - x)
#### 等价 f(2a - x) = f(x)
### 关于点 (a, b) 中心对称
#### f(a + x) + f(a - x) = 2b
#### 等价 f(2a - x) + f(x) = 2b
### 特例
#### a = 0 且 b = 0 → 奇函数
#### a = 0 的偶函数 → 关于 y 轴对称

## 导数的概念
### 定义式
#### f′(x) = lim [f(x + Δx) - f(x)] / Δx
#### 退极限时分子是 f(x₀) 不是 f(0)
### 几何意义
#### 切线斜率
#### 曲线趋近水平的快慢
### 数量意义
#### 瞬时变化率
### 导函数
#### f′ 本身是函数
#### 定义域与 f 相同
### 可导与连续
#### 可导 ⇒ 连续
#### 连续 ⇏ 可导
#### 反例 f = |x| 在 0 处
#### 分界点必查左右导数

## 求导公式
### 幂与根
#### (xⁿ)′ = n xⁿ⁻¹
#### (1/x)′ = -1/x²
#### (√x)′ = 1/(2√x)
### 三角
#### (sin x)′ = cos x
#### (cos x)′ = -sin x
#### (tan x)′ = 1/cos²x
### 指数对数
#### (eˣ)′ = eˣ
#### (ln x)′ = 1/x
#### (aˣ)′ = aˣ ln a
#### (logₐ x)′ = 1/(x ln a)
### 运算法则
#### (u ± v)′ = u′ ± v′
#### (uv)′ = u′v + uv′
#### (u/v)′ = (u′v - uv′)/v²
#### 链式法则 [u(v)]′ = u′(v)·v′(v)
### 常见陷阱
#### 漏乘内层导数
#### 商法则分母忘记平方

## 导数与单调性
### 正增负减
#### f′ > 0 ⇒ 递增
#### f′ < 0 ⇒ 递减
### 恒成立方向
#### f′ ≥ 0 恒成立 ⇒ 恒递增
#### f′ ≤ 0 恒成立 ⇒ 恒递减
### 反向只能是非严格
#### 递增 ⇒ f′ ≥ 0
#### 递减 ⇒ f′ ≤ 0
#### 反例 f = x³ 在 0 处
### 三列表格法
#### 求 f′
#### 解 f′ = 0 得驻点
#### 列符号行读区间

## 极值与最值
### 极值
#### 局部概念
#### 看导数变号
#### 左负右正 → 极小
#### 左正右负 → 极大
#### 同号 → 不是极值
### 驻点不是极值点
#### f′(x₀) = 0 只是必要条件
#### 反例 f = x³ 在 0 处
### 最值
#### 全局概念
#### 闭区间上连续必存在
### 闭区间最值模型
#### 驻点 + 两个端点
#### 列表比较 f 的值
#### 答案写值与取等点
### 极值不等于最值
#### f = e^(-x) 有极大值无最大值
#### f = -x² 有极大值无最小值

## 导数的应用
### 求切线
#### 已知切点：点斜式
#### 过点定切线：列方程解 x₀
#### 几条实根写几条切线
#### 把 x₀ 代回验 y = f(x₀)
### 恒成立
#### f ≥ m 恒成立 ⇔ m ≤ f最小
#### f ≤ m 恒成立 ⇔ m ≥ f最大
### 证明不等式
#### 构造函数
#### 求最小值
#### 说明最小值达标
### 零点个数
#### 写两端趋势
#### 求驻点与驻点函数值
#### 正负号判交点
#### 峰值压轴 → 两根含重根
#### 按参数分类写边界
### 求参数范围
#### 翻译成 f′ 的符号条件
#### 或分离参数后恒成立
#### 注意区间端点是否取到
### 比较大小
#### 用单调性
#### 或构造差函数再求导
