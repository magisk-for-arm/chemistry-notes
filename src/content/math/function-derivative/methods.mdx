## 一、定义域「四查」模型

任何带分式、根号、对数、正切的解析式，定义域都必须先算出来——它是后面所有步骤的地基。

<SolutionSteps
  model="定义域四查模型"
  steps={[
    '第一步：查分母，写出「分母 ≠ 0」这一条不等式或不等式组',
    '第二步：查偶次根号，把被开方数写成 ≥ 0 的不等式',
    '第三步：查对数，把真数写成 > 0 的不等式；常数底数还要排除底数为 1',
    '第四步：查正切，把变量换成内层表达式后，写出「不等于 π/2 加 kπ」',
    '第五步：把四条限制取交集，得到区间（必要时在内部挖掉若干点）',
    '第六步：从最终区间里任取一点回代原式，确认分式有值、根号非负、对数真数为正',
  ]}
  tip="偶次根号给闭端点，对数真数给开端点，分母与正切是在区间内部挖点。开闭写反是最常见的丢分点。"
/>

<Callout type="memory" title="求域口诀速记">

1. **分母不为零**。
2. **偶次根号非负**（奇次根号不限）。
3. **对数真数为正**（底数还需 > 0 且 ≠ 1，题目通常已给）。
4. **正切无定义点**：写成内层表达式后不等于 π/2 加 kπ。
5. **回代验一验**：任取一点代回原式，四个条件逐个打勾。

</Callout>

## 二、单调性与奇偶性判定模型

<SolutionSteps
  model="性质判定模型"
  steps={[
    '第一步：先求定义域，把它写成区间的并，判断是否关于原点对称（判奇偶的前提）',
    '第二步：判奇偶只算两点——比较 f(负值) 与 ±f(正值)，再顺带看一眼 f(0) 是否为 0',
    '第三步：判单调先定区间范围（导数法或图像法），特别注意「同一区间上」这个限定',
    '第四步：由 f(x+T) = f(x) 与奇偶性联合求值时，先用周期把自变量搬进已知区间，再用奇偶去掉负号',
    '第五步：结论写完整——区间端点写闭区间，必要时注明 k 取整数',
  ]}
  tip="奇函数必有 f(0) = 0，这条免费结论能一秒否掉一半的错误奇函数判定；周期平移记得取最小正周期的整数倍，别平移过头。"
/>

<Callout type="formula" title="性质判定的四条硬结论">

$$
\begin{aligned}
\text{奇} &\Rightarrow f(0) = 0,\quad \text{偶} \Rightarrow \text{图象关于 } y \text{ 轴对称} \\
f(x+a)+f(x-a) &= 2b \iff \text{关于点 } (a, b) \text{ 中心对称} \\
f(x+a) = f(x-a) &\iff \text{关于直线 } x = a \text{ 对称} \\
f \text{ 递增} &\Rightarrow f'(x) \ge 0 \quad\text{（不能写成 } > 0\text{）}
\end{aligned}
$$

</Callout>

## 三、导数计算「脱衣分层」模型

<SolutionSteps
  model="求导计算模型"
  steps={[
    '第一步：先看结构——是积/商/幂/根/指数/对数/三角/复合中的哪几种？决定用哪几条法则',
    '第二步：把复合结构「脱衣」，写成外层 Φ 套内层 u，明确一共有几层',
    '第三步：从最外层开始求导，每求完一层立刻乘上这一层内层的导数，一层只乘一次',
    '第四步：四则运算按「先乘后除、加减最后」处理，分母不为零',
    '第五步：化简整理成最简形式，做次数自检——原函数最高次数减 1 应等于结果最高次数',
    '第六步：关键节点（如 x = 0、x = 1）代回原式与导数各验一次',
  ]}
  tip="漏乘内层导数是头号失分点。外层求导后如果写不出「乘」字，停下来想一想 u′ 去哪了。"
/>

<Callout type="formula" title="求导公式与法则">

基本初等函数：$(x^n)'=nx^{n-1}$；$\left(\frac1x\right)'=-\frac{1}{x^2}$；$(\sin x)'=\cos x$；$(\cos x)'=-\sin x$；$(\tan x)'=\frac{1}{\cos^2x}$；$(e^x)'=e^x$；$(\ln x)'=\frac1x$；$(a^x)'=a^x\ln a$；$(\log_a x)'=\frac{1}{x\ln a}$。

法则：$(u\pm v)'=u'\pm v'$；$(uv)'=u'v+uv'$；$\left(\frac uv\right)'=\frac{u'v-uv'}{v^2}$；$[u(v)]'=u'(v)\cdot v'(v)$。

</Callout>

## 四、闭区间最值「三点比较」模型

<SolutionSteps
  model="闭区间最值模型"
  steps={[
    '第一步：求 f(负向) 在区间内的定义，确认端点 a、b 有意义（闭区间上连续是定理前提）',
    '第二步：求导，解 f′ 等于 0，列出开区间内的全部解 x1、x2……',
    '第三步：把 x1、x2…… 与两个端点 a、b 凑成一张表，逐格算 f 的值',
    '第四步：表内最大者即最大值、最小者即最小值',
    '第五步：答案写全「值 + 取等点」两项，只写值扣一半分',
  ]}
  tip="草稿上把这张表画出来。表里端点那两格没填，就是最典型的漏项。"
/>

<Callout type="formula" title="闭区间最值定理与常见答案形态">

若 f 在闭区间 [a, b] 上连续，则 f 在 [a, b] 上必有最大值与最小值。

$$
f_{\max} = \max\left\{f(a),\ f(b),\ f(x_1),\ f(x_2),\ \dots\right\},\qquad
f_{\min} = \min\left\{f(a),\ f(b),\ f(x_1),\ f(x_2),\ \dots\right\}
$$

</Callout>

## 五、恒成立问题的「最值转化」模型

「$f(x) \ge m$ 恒成立」「$f(x) < 0$ 恒成立」这类题，本质都是**把不等式整体转成极值问题**。

<SolutionSteps
  model="恒成立转化模型"
  steps={[
    '第一步：把不等式整理成「f(x) 与 0 比较」或「f(x) 与 m 比较」的标准形式',
    '第二步：求 f′，解出全部驻点，列表判符号，写出单调区间',
    '第三步：求 f 的最大值与最小值（注意开区间端点处要用极限值代替）',
    '第四步：把条件翻译成极值的不等式，例如「恒有 f ≥ 0」翻译成「f 的最小值 ≥ 0」',
    '第五步：解不等式求参数范围，回代检验端点是否取到',
  ]}
  tip="开区间端点用极限：f 减且 f(0) 有意义时端点值就是极限；端点无定义时只能说「大于」不能说「大于等于」，直接决定参数端点开闭。"
/>

<Callout type="memory" title="四个必背的翻译">

1. $f(x) \ge m$ 恒成立 $\iff$ $m \le f_{\min}$。
2. $f(x) \le m$ 恒成立 $\iff$ $m \ge f_{\max}$。
3. 「在区间上递减」$\iff$ $f'(x) \le 0$ 在该区间**恒成立**（正增负减，方向不能反）。
4. 「有最大值」$\iff$ 能取到上确界；「有极大值」$\iff$ 存在一点邻域内最大。$e$ 的负指数这类函数有极大值但没有最大值。

</Callout>

## 六、零点个数「极值 + 趋势」模型

方程 $f(x) = 0$ 的根的个数 = $f$ 的图象与 $x$ 轴交点个数。导数告诉你图象在哪些区间上升、在哪些区间下降，极值告诉你峰谷的高度。

<SolutionSteps
  model="零点个数模型"
  steps={[
    '第一步：写清定义域及两端趋势——趋近正无穷、正负无穷还是某个极限值',
    '第二步：求 f′，解出全部驻点，按从小到大编号 x1、x2……',
    '第三步：列表写出每个驻点处的函数值 f(x1)、f(x2)…… 并标出正负号',
    '第四步：逐段数交点——一段单调区间上最多一个交点，符号变化就有一个，符号不变就没有',
    '第五步：驻点函数值恰好为 0 时，该点是重根，需要单独说明根的个数与重数',
    '第六步：按参数大小分类写出每类的根个数，注意端点开闭',
  ]}
  tip="「峰值在轴上、正峰在轴下」两句就够：三根要正峰高、负谷深；一根只看外侧那一段。峰值恰好压在 x 轴上时是两根（其中一根重根）。"
/>

<Callout type="formula" title="根的个数与极值符号的关系">

设 f 在区间上先增后减再增（两个驻点 x1、x2，x1 为极大点、x2 为极小点）：

| 极大值 f(x1) | 极小值 f(x2) | 不同实根个数 |
|-------------|-------------|--------------|
| $>0$ | $<0$ | 3 |
| $>0$ | $=0$ | 2（x2 为二重根） |
| $>0$ | $>0$ | 1（在 x1 左侧那段） |
| $\le 0$ | $<0$ | 1（在 x2 右侧那段） |

</Callout>

## 七、检查清单（交卷前 30 秒）

<SolutionSteps
  model="函数与导数检查清单"
  steps={[
    '定义域：分母、偶次根号、对数真数、正切无定义点，四查做了吗？区间内部该挖的点挖了吗？',
    '定义域的区间开闭：闭端点该在哪？开端点又该在哪？有没有写反？',
    '奇偶性：定义域关于原点对称吗？奇函数 f(0) 是不是 0？',
    '周期与奇偶联用：先搬后翻的顺序对吗？平移的倍数取的是最小正周期的整数倍吗？',
    '可导性：分界点都圈了吗？左右导数分别算了吗？有没有从「连续」错推「可导」？',
    '求导：复合结构有没有漏乘内层导数？商法则的分母平方有没有写错？',
    '导数与单调：正增负减的方向对吗？从「单调」反推导数时只写了非严格不等号吗？',
    '极值：驻点解全了吗？两侧变号判了吗？不变号的驻点有没有被误写成极值？',
    '闭区间最值：两个端点和全部驻点都进表了吗？答案写了取等点吗？',
    '应用题：切线用点斜式并把切点代回验过吗？恒成立翻译成极值了吗？根的个数按参数分类的边界取到了吗？',
  ]}
  tip="前四条管函数题，第五条到第九条管导数与最值题，第十条管压轴。每条勾不上的立刻回查对应小节的公式，不要从头重算。"
/>

<Callout type="memory" title="口诀速记（解题方法篇）">

1. **分母非零、根内非负、真数为正、正切挖点**——定义域四查。
2. **先对称后关系**——奇偶判定铁律；奇函数必有零值点。
3. **外层求导乘内层导数，外面只乘一次**——链式法则。
4. **次数自检：原减一，结果对**——求导后立刻验。
5. **正增负减，方向不反**；从单调反推只能是非严格不等号。
6. **解驻点只算半程，判变号才算完**——极值判据。
7. **轴在峰谷、心在零线**是三角的对称口诀；导数版是**驻点 + 变号**。
8. **驻点加端点，三点比大小**——闭区间最值。
9. **恒成立转最值、两解看极值符号**——压轴四翻译。
10. **可导必连续，连续未必可导**。

</Callout>
