## 一、斜率：整章的第一个开关

两点 $A(x_1, y_1)$、$B(x_2, y_2)$ 所在直线的斜率

$$
k = \frac{y_2 - y_1}{x_2 - x_1} \quad (x_1 \ne x_2)
$$

**$x_1 = x_2$ 时斜率不存在**，此时直线垂直于 $x$ 轴（竖直直线），只能说「斜率不存在」，**不能写成 $k = 0$，也不能参与 $k_1k_2 = -1$**。

直线倾斜角的范围是 $[0, \pi)$，斜率与倾斜角的关系是 $k = \tan\alpha$；正切在 $(0, \pi)$ 上不单调，所以「倾斜角 $\alpha$ 在第二象限 $\Rightarrow k < 0$」。

## 二、直线方程的四种形式

| 形式 | 表达式 | 适用前提 |
|------|--------|----------|
| 点斜式 | $y - y_0 = k(x - x_0)$ | 经过点 $(x_0, y_0)$ 且斜率存在 |
| 两点式 | $\dfrac{y - y_1}{y_2 - y_1} = \dfrac{x - x_1}{x_2 - x_1}$ | $x_1 \ne x_2$ 且 $y_1 \ne y_2$ |
| 斜截式 | $y = kx + b$ | 斜率存在；$b$ 就是**纵截距** |
| 一般式 | $Ax + By + C = 0$ | $A, B$ 不同时为 0；$B \ne 0$ 时斜率 $k = -\dfrac{A}{B}$ |

竖直直线只能写成 $x = x_0$。**凡是「设直线方程为 $y = kx + b$」的场合，竖直直线都是被漏掉的那一支**，这是本知识点最贵的一个失分点。

## 三、平行与垂直的判定

**用斜率**（前提：两条直线的斜率都存在）：

$$
l_1 \parallel l_2 \iff k_1 = k_2, \qquad l_1 \perp l_2 \iff k_1 k_2 = -1
$$

<Callout type="note" title="斜率不存在时的补充规则">

- 两条直线都竖直（斜率都不存在）：**平行**；
- 一条竖直、一条斜率存在：**垂直**（与 $k_1k_2=-1$ 无关）；
- 只要有一条竖直，「$k_1 k_2 = -1$」与「$k_1 = k_2$」都**失效**。

</Callout>

**用一般式**（对任意直线都成立，含竖直直线）：

$$
\begin{aligned}
l_1 \parallel l_2 &\iff A_1B_2 - A_2B_1 = 0 \ \text{且}\ \dfrac{A_1}{A_2} = \dfrac{B_1}{B_2} \ne \dfrac{C_1}{C_2} \\
l_1 \perp l_2 &\iff A_1A_2 + B_1B_2 = 0
\end{aligned}
$$

「$\dfrac{A_1}{A_2} = \dfrac{B_1}{B_2} \ne \dfrac{C_1}{C_2}$」= **系数对应成比例但常数项不成比例**：三个比值都相等是**重合**（不是两条不同的直线），所以判定平行必须把重合排除。

## 四、距离公式

**点到直线的距离**（$Ax_0 + By_0 + C \ne 0$）：

$$
d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}
$$

**两条平行线的距离**（先把两条线的系数化成相同的 $A$、$B$）：

$$
l_1: Ax + By + C_1 = 0,\quad l_2: Ax + By + C_2 = 0 \implies d = \frac{|C_2 - C_1|}{\sqrt{A^2 + B^2}}
$$

点到坐标轴的距离是特例：$P(x_0, y_0)$ 到 $x$ 轴的距离为 $|y_0|$，到 $y$ 轴为 $|x_0|$。

> **切线长**另有一套：圆外一点 $P$（到圆心 $C$ 的距离 $PC > r$）引圆 $C$ 的切线，切线长 $=\sqrt{PC^2 - r^2}$。这里的 $PC$ 是**点到圆心**的距离，与上面「圆心到直线的距离 $d$」是两回事，别混。

## 五、圆的方程与位置关系

圆的标准式与一般式：

$$
(x - a)^2 + (y - b)^2 = r^2 \iff x^2 + y^2 - 2ax - 2by + a^2 + b^2 - r^2 = 0
$$

对一般式 $x^2 + y^2 + Dx + Ey + F = 0$，用配方法读出三要素：

$$
\text{圆心}\left(-\frac{D}{2},\ -\frac{E}{2}\right),\qquad
r = \frac{1}{2}\sqrt{D^2 + E^2 - 4F},\qquad
\text{直径}\ d = \sqrt{D^2 + E^2 - 4F}
$$

<Callout type="note" title="半径与直径只差一个 2">

$r = \dfrac{1}{2}\sqrt{D^2+E^2-4F}$ 里的 $\dfrac{1}{2}$ 是最高频的漏写点，而 $D^2+E^2-4F$ 开根**不用**再乘 $\dfrac{1}{2}$（那已是直径）。要判断是否为圆，只需 $D^2 + E^2 - 4F > 0$。

</Callout>

**直线与圆的位置关系**（$d$ 为圆心到直线的距离）：

| 条件 | 位置关系 | 弦长 |
|------|----------|------|
| $d > r$ | 相离 | 无公共点 |
| $d = r$ | 相切 | $0$ |
| $d < r$ | 相交 | $\lvert AB\rvert = 2\sqrt{r^2 - d^2}$ |

**求「直线与圆相切」的标准动作是令 $d = r$**，即把直线方程与圆方程的距离式联立求参数，比解方程组快得多，也避免重根讨论。

## 六、圆与圆的位置关系

两圆半径 $r_1, r_2$，圆心距 $d$：

| 条件 | 位置关系 |
|------|----------|
| $d > r_1 + r_2$ | 外离 |
| $d = r_1 + r_2$ | 外切 |
| $\lvert r_1 - r_2\rvert < d < r_1 + r_2$ | 相交 |
| $d = \lvert r_1 - r_2\rvert > 0$ | 内切 |
| $0 < d < \lvert r_1 - r_2\rvert$ | 内含 |
| $d = 0$ 且 $r_1 = r_2$ | 重合 |

<Callout type="tip" title="相交的判据只有一条">

「相交」等价于**公共点有两个**，判据是 $\lvert r_1-r_2\rvert < d < r_1+r_2$（两端都严格不等）。把「相交」误写成 $\lvert r_1-r_2\rvert \le d \le r_1+r_2$ 是常见错误——等号对应的是相切，不是相交。

</Callout>

## 七、椭圆

**定义**：平面内与两个定点 $F_1, F_2$ 的距离之和等于常数 $2a$（且大于 $F_1F_2$）的点的轨迹。标准方程

$$
\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b > 0),\qquad c^2 = a^2 - b^2,\qquad e = \frac{c}{a} \in (0, 1)
$$

| 元素 | 位置 |
|------|------|
| 焦点 | $(\pm c, 0)$ |
| 长轴顶点（实轴端点） | $(\pm a, 0)$ |
| 短轴顶点 | $(0, \pm b)$ |
| 离心率 | $e = \dfrac{c}{a} = \sqrt{1 - \dfrac{b^2}{a^2}}$ |

**焦半径公式**（椭圆焦点在 $x$ 轴上，$P(x, y)$ 在椭圆上）：

$$
\lvert PF_1\rvert = a + ex,\qquad \lvert PF_2\rvert = a - ex \quad \bigl(F_1(-c,0),\ F_2(c,0)\bigr)
$$

两条焦半径之和恒为 $2a$；**乘积** $a^2 - e^2x^2$ 在 $\lvert x\rvert \le a$ 上的取值范围是 $\bigl[b^2,\ a^2\bigr]$（顶点在最小值，$y$ 轴上取最大值）。

## 八、双曲线

**定义**：与两个定点的距离之**差**等于常数 $2a$（且小于 $F_1F_2$）的点的轨迹。标准方程

$$
\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \quad (a, b > 0),\qquad c^2 = a^2 + b^2,\qquad e = \frac{c}{a} > 1
$$

- 焦点 $(\pm c, 0)$，实轴顶点 $(\pm a, 0)$，虚轴端点 $(0, \pm b)$；
- **两条渐近线**：$y = \pm\dfrac{b}{a}x$（**分子分母不可写反**，写反就变成椭圆的方向了）；
- 焦半径（右支上 $x \ge a$）：$\lvert PF_1\rvert = ex + a$，$\lvert PF_2\rvert = ex - a$，差恒为 $2a$；
- 渐近线与实轴夹角记为 $\alpha$，则 $\tan\alpha = \dfrac{b}{a} = \sqrt{e^2 - 1}$，即 $e = \dfrac{1}{\cos\alpha}$。**$e = 2 \iff \alpha = 60^\circ$**，此时两条渐近线之间的锐角也是 $60^\circ$。

> **椭圆与双曲线的分水岭只有一处**：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 里 $c^2 = a^2 - b^2$（$e<1$），$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 里 $c^2 = a^2 + b^2$（$e>1$）。看到 $c^2$ 就先问「加还是减」。

## 九、抛物线

本知识点统一采用人教 A 版的记法：**$y^2 = 2px$**（$p > 0$）。另一常见记法 $y^2 = 4ax$ 与之等价，只需令 $a = \dfrac{p}{2}$，两者在本题库里不混用。

| 元素 | $y^2 = 2px$ |
|------|-------------|
| 焦点 | $\left(\dfrac{p}{2},\ 0\right)$ |
| 准线 | $x = -\dfrac{p}{2}$ |
| 焦半径 | $\lvert PF\rvert = x + \dfrac{p}{2}$ |
| 顶点 | $(0, 0)$ |
| 过曲线上 $(x_0, y_0)$ 的切线 | $y_0y = p(x + x_0)$ |
| 通径（过焦点的垂直弦）长 | $2p$ |

<Callout type="note" title="为什么焦半径不必写绝对值">

由 $y^2 = 2px$（$p > 0$）得 $x \ge 0$，故 $x + \dfrac{p}{2} > 0$，$\lvert PF\rvert = x + \dfrac{p}{2}$ 可以直接去掉绝对值。也正因为整条抛物线都在准线右侧，$y^2 = 2px$ 的另一支（$x \le 0$）在实数范围内不存在——这是它与椭圆、双曲线的关键差别。

</Callout>

**切线的判据**：$l: y = kx + b$（$k \ne 0$）与 $y^2 = 2px$ 相切 $\iff$ 判别式 $\Delta = 4p(p - 2kb) = 0 \iff kb = \dfrac{p}{2}$；相切点为 $\left(\dfrac{p}{2k^2},\ \dfrac{p}{k}\right)$。用 $x = my + \dfrac{p}{2}$ 表示则永不漏竖直情形，联立即得 $y^2 - 2pmy - p^2 = 0$。

## 十、联立与韦达定理（核心运算）

把直线方程代入曲线方程，得到关于 $x$（或 $y$）的二次方程 $Ax^2 + Bx + C = 0$，则

$$
x_1 + x_2 = -\frac{B}{A},\qquad x_1 x_2 = \frac{C}{A},\qquad (x_1 - x_2)^2 = \frac{\Delta}{A^2}
$$

### 圆与斜截式直线联立

$$
(1 + k^2)x^2 + (2kb + D + kE)x + (b^2 + Eb + F) = 0
$$

$$
x_1 + x_2 = -\frac{2kb + D + kE}{1 + k^2},\qquad x_1 x_2 = \frac{b^2 + Eb + F}{1 + k^2}
$$

**$x^2$ 的系数是 $1 + k^2$ 而不是 1**——这是韦达定理最高频的记错点。由判别式还可整理出

$$
\Delta = 4(1 + k^2)\bigl(r^2 - d^2\bigr)
$$

于是 $\lvert AB\rvert = \dfrac{\sqrt{\Delta}}{\sqrt{1+k^2}} = 2\sqrt{r^2-d^2}$，两种算法互相验证。

### 椭圆与斜截式直线联立

$$
(b^2 + a^2k^2)x^2 + 2a^2kmx + a^2(m^2 - b^2) = 0,\qquad
\Delta = 4a^2b^2\bigl(a^2k^2 + b^2 - m^2\bigr)
$$

所以**相交（含相切）** 的条件是 $m^2 \le a^2k^2 + b^2$，其中等号对应相切。

### 双曲线与抛物线的同款结果

| 曲线 | 与 $y = kx + m$ 联立后的判别式 | 相交条件 |
|------|--------------------------------|----------|
| $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ | $\Delta = 4a^2b^2\bigl(m^2 + b^2 - a^2k^2\bigr)$ | $m^2 + b^2 > a^2k^2$ |
| $y^2 = 2px$ | $\Delta = 4p\bigl(p - 2km\bigr)$ | $km < \dfrac{p}{2}$ |

> 双曲线那一行必须补一个前提：$b^2 - a^2k^2 \ne 0$，即 $k \ne \pm\dfrac{b}{a}$。当直线**平行于渐近线**时，二次项系数为 0，方程退化成一次，此时**不能套韦达定理**。
> 抛物线那一行的 $y = kx+m$ 漏掉竖直情形（$k$ 不存在）。求「过焦点的弦」这类题，统一改设 $x = my + \dfrac{p}{2}$，联立即得 $y^2 - 2pmy - p^2 = 0$，与韦达定理配合最顺。

## 十一、点差法

已知 $A(x_1, y_1)$、$B(x_2, y_2)$ 在同一曲线上，把两点的坐标分别代入曲线方程再**相减**，可以不联立求出 $k_{AB}$ 或中点。

对椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$：

$$
\frac{x_1^2 - x_2^2}{a^2} + \frac{y_1^2 - y_2^2}{b^2} = 0
\;\Longrightarrow\;
\frac{(x_1 + x_2)(x_1 - x_2)}{a^2} + \frac{(y_1 + y_2)(y_1 - y_2)}{b^2} = 0
$$

$$
k_{AB} = \frac{y_1 - y_2}{x_1 - x_2} = -\frac{b^2(x_1 + x_2)}{a^2(y_1 + y_2)}
$$

写成交点弦的斜率与中点形式就是 $k_{AB} = -\dfrac{b^2 x_0}{a^2 y_0}$（中点 $M(x_0, y_0)$），它与「过定点求斜率」是同一个结论的两种用法。

<Callout type="formula" title="点差法三个前提">

① 两个点都在曲线上；② $x_1 \ne x_2$（否则斜率不存在，中点处是竖直弦）；③ 曲线上两点代入相减时，**平方必须先因式分解成和差形式** $x_1^2 - x_2^2 = (x_1+x_2)(x_1-x_2)$。漏掉因式分解是点差法最主要的错误。

</Callout>

## 十二、定值、定点与参数范围

| 问题类型 | 通用做法 |
|----------|----------|
| 定值问题 | 联立后用韦达把所求量写成 $x_1 + x_2$、$x_1x_2$ 的组合，消掉参数 $k$、$m$ |
| 定点问题 | 直线方程写成 $y = k(x - x_0) + y_0$（过定点 $(x_0, y_0)$），代入后**令 $k$ 的系数为 0**，解出的点就是定点 |
| 存在性问题 | 把结论翻译成「存在实数 $\lambda$ 使某个关于 $\lambda$ 的方程有解」，再用分离参数法或判别式 |
| 参数范围 | 联立 → 由 $\Delta > 0$（相交）、$\Delta = 0$（相切）解不等式 → **端点开闭由 $\Delta$ 的等号决定** |

三条都要落到「联立 + 判别式」这一条主线上，只是最后一步处理目标不同。
