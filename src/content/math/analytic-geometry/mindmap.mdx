# 解析几何

## 斜率与直线方程
### 斜率定义
- k = (y₂ - y₁) / (x₂ - x₁)
- 必须 x₁ ≠ x₂
- x₁ = x₂ → 斜率不存在（竖直直线）
- 斜率不存在 ≠ 斜率为 0
### 倾斜角
- 0 ≤ α < π
- k = tan α
- 第二象限时 k < 0
### 四种形式
- 点斜式 y - y₀ = k(x - x₀)
- 两点式（分母为差）
- 斜截式 y = kx + b（b 为纵截距）
- 一般式 Ax + By + C = 0，A、B 不同时为 0
- 竖直线只能写 x = x₀
### 一般式的优势
- 竖直线照样能用
- k = -A / B（B ≠ 0）

## 平行与垂直
### 用斜率（前提：斜率都存在）
- 平行 ⇔ k₁ = k₂
- 垂直 ⇔ k₁k₂ = -1
### 含竖直时的补充
- 都竖直 → 平行
- 一竖一斜 → 垂直
### 用一般式（对任意直线成立）
- 方向相同 ⇔ A₁B₂ - A₂B₁ = 0
- 平行 ⇔ A₁/A₂ = B₁/B₂ ≠ C₁/C₂
- 三比值全等 → 重合
- 垂直 ⇔ A₁A₂ + B₁B₂ = 0

## 距离公式
### 点到直线
- d = |Ax₀ + By₀ + C| / √(A² + B²)
- 绝对值不能丢
- y = kx + b 即 kx - y + b = 0
### 两平行线距离
- 先化成相同 A、B
- d = |C₂ - C₁| / √(A² + B²)
### 点到坐标轴
- 到 x 轴 = |y₀|
- 到 y 轴 = |x₀|
### 切线长
- √(PC² - r²)
- PC 是点到圆心的距离
- 前提 PC > r

## 圆的方程与位置关系
### 一般式
- x² + y² + Dx + Ey + F = 0
- 圆心 (-D/2, -E/2)
- r = (1/2)√(D² + E² - 4F)
- 直径 = √(D² + E² - 4F)
- 是圆 ⇔ D² + E² - 4F > 0
### 配方读法
- x² - 2ax → (x - a)² - a²
- 右端常数即 r²
### 直线与圆
- d > r 相离
- d = r 相切
- d < r 相交
- 弦长 2√(r² - d²)
### 圆与圆
- 相交 ⇔ |r₁ - r₂| < d < r₁ + r₂
- 两端严格不等
- 外切 d = r₁ + r₂
- 内切 d = |r₁ - r₂|
- 重合 d = 0 且 r₁ = r₂

## 椭圆
### 定义
- 到两定点距离之和 = 2a（大于焦距）
### 标准式
- x²/a² + y²/b² = 1，a > b > 0
- c² = a² - b²（减）
- e = c/a ∈ (0, 1)
### 元素
- 焦点 (±c, 0)
- 长轴顶点 (±a, 0)
- 短轴顶点 (0, ±b)
### 焦半径
- |PF₁| = a + ex
- |PF₂| = a - ex
- 和恒为 2a
- 积 a² - e²x² ∈ [b², a²]

## 双曲线
### 定义
- 到两定点距离之差 = 2a（小于焦距）
### 标准式
- x²/a² - y²/b² = 1
- c² = a² + b²（加）
- e = c/a > 1
### 元素
- 焦点 (±c, 0)
- 实轴顶点 (±a, 0)
- 虚轴端点 (0, ±b)
### 渐近线
- y = ±(b/a)x
- b 在分子，勿写成 a/b
- 与实轴夹角 α：tan α = b/a = √(e² - 1)
- e = 1/cos α，e = 2 ⇒ α = 60°
### 焦半径
- 右支：|PF₁| = ex + a，|PF₂| = ex - a
- 差恒为 2a
- 积 = e²x² - a² ≥ b²

## 抛物线
### 本页统一记法
- y² = 2px，p > 0
- 与 y² = 4ax 等价，令 a = p/2
### 元素
- 焦点 (p/2, 0)
- 准线 x = -p/2
- 顶点 (0, 0)
- 焦半径 |PF| = x + p/2（x ≥ 0，无绝对值）
### 切线
- 过 (x₀, y₀) 的切线 y₀y = p(x + x₀)
- y = kx + m 相切 ⇔ km = p/2
- 切点 (p/(2k²), p/k)
### 焦点弦
- 设 x = my + p/2（覆盖竖直）
- 联立 y² - 2pmy - p² = 0
- |AB| = 2p(m² + 1) ≥ 2p
- 通径长 2p
### 切点弦
- vy = px + pu
- 恒过定点 (-u, 0)

## 联立与韦达定理
### 三项式通式
- Ax² + Bx + C = 0
- x₁ + x₂ = -B/A
- x₁x₂ = C/A
- (x₁ - x₂)² = Δ/A²
### 圆
- (1 + k²)x² + (2kb + D + kE)x + (b² + Eb + F) = 0
- Δ = 4(1 + k²)(r² - d²)
- |AB| = √Δ / √(1 + k²)
### 椭圆
- (b² + a²k²)x² + 2a²kmx + a²(m² - b²) = 0
- Δ = 4a²b²(a²k² + b² - m²)
### 双曲线
- (b² - a²k²)x² - 2a²kmx - a²(m² + b²) = 0
- Δ = 4a²b²(m² + b² - a²k²)
- k ≠ ±b/a，否则退化成一次
### 抛物线
- y = kx + m：Δ = 4p(p - 2km)
- x = my + p/2：y² - 2pmy - p² = 0

## 点差法
### 三步
- 两点代入曲线方程
- 相减并因式分解
- 同除差，得斜率与「和」的关系
### 结论
- 椭圆 k = -(b²/a²)·(x₁+x₂)/(y₁+y₂)
- 双曲线 k = +(b²/a²)·(x₁+x₂)/(y₁+y₂)
- 中点形式 k = -(b²/a²)·x₀/y₀（椭圆）
### 前提
- 两点都在曲线上
- x₁ ≠ x₂（否则竖直弦）
- 结果里必须含「和」

## 定值定点与参数范围
### 定点
- 直线写成 y = k(x - x₀) + y₀
- 令 k 的系数为 0
- 解出的 (x₀, y₀) 即定点
### 定值
- 目标量只含 x₁+x₂、x₁x₂
- 约掉 k 后剩常数即定值
- 代 k = 0 与 k = 1 互相核对
### 参数范围
- 相交 Δ > 0
- 相切 Δ = 0
- 有公共点 Δ ≥ 0
- 端点回代定开闭
### 存在性
- 翻译成「存在实数使方程有解」
- 即 Δ ≥ 0 的恒成立问题

## 常见陷阱
### 竖直线当成斜率 0
### 设 y = kx + m 漏竖直
### 韦达的 A 漏乘 1 + k²
### 弦长漏乘 √(1 + k²)
### 半径当直径
### d 与 r 比较方向反
### 切线长混用 d 与 PC
### 点差法不分解平方差
### 重合当平行
### 相交端点写成闭区间
### 椭圆双曲 c² 加减记混
### 渐近线 b 与 a 写反

## 解题方法
### 距离判定法
- 配方读圆
- 算 d 比 r
- 相切令 d = r
### 联立韦达法
- 先合并同类项
- 系数单列一行
- 目标量改写成和与积
### 点差法
- 相减 → 分解 → 提因式
### 参数范围法
- 关系译成 Δ 不等式
- 端点必须回代
### 消参法
- 定点令系数为零
- 定值代 k = 0 核对
### 检查清单
- 斜率存不存在
- 设式有没有漏方向
- 三项式系数对不对
- 弦长乘没乘根号
- 端点开闭对不对
