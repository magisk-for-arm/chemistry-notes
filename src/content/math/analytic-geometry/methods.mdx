## 一、模型一：距离判定法（圆的一切问题）

圆的问题几乎都能化成「圆心到直线的距离 $d$ 与半径 $r$ 比大小」。**能不联立就不联立**——联立要解方程、判重根，代价远高于一个距离式。

<SolutionSteps
  model="距离判定法"
  steps={[
    '第一步：配方把圆写成标准式，读出圆心与半径（别用公式背圆心符号）',
    '第二步：把所求直线化成一般式 Ax + By + C = 0，竖直线照样能用',
    '第三步：算 d = |A·x₀ + B·y₀ + C| / √(A²+B²)，与 r 比较或直接令 d = r',
    '第四步：相交时用 |AB| = 2√(r² - d²) 求弦长；相切时用垂足公式回代求切点',
    '第五步：结果代回验算，例如弦长不应超过直径 2r',
  ]}
  tip="求切线长时用的是点到圆心的距离 PC，不是圆心到直线的距离 d，两个 d 千万别混。"
/>

<Callout type="formula" title="圆的标准动作清单">

| 目标 | 做法 |
|------|------|
| 圆心、半径 | 配方，或 $C\left(-\frac D2, -\frac E2\right)$、$r = \frac12\sqrt{D^2+E^2-4F}$ |
| 与直线位置关系 | $d$ 与 $r$ 比大小：$d>r$ 相离、$d=r$ 相切、$d<r$ 相交 |
| 弦长 | $2\sqrt{r^2-d^2}$ |
| 切线长 | $\sqrt{PC^2-r^2}$ |
| 切点 | 垂足：$x_0 - \frac{AD_0}{A^2+B^2}$，$y_0 - \frac{BD_0}{A^2+B^2}$ |
| 圆与圆 | $\lvert r_1-r_2\rvert < d < r_1+r_2$ 相交 |

</Callout>

## 二、模型二：联立 + 韦达定理

圆锥曲线解答题的主线。目标是把「与 $k$ 有关」的式子变成「只含 $x_1 + x_2$、$x_1x_2$」，再消掉参数。

<SolutionSteps
  model="联立韦达模型"
  steps={[
    '第一步：写出直线方程，尽量用 y = kx + m；过定点的写成 y = k(x - x₀) + y₀ 以便定值',
    '第二步：代入曲线方程，合并同类项，写成 Ax² + Bx + C = 0，并把 A、B、C 三个系数单列一行',
    '第三步：用韦达把 x₁ + x₂ = -B/A、x₁x₂ = C/A 写出，同时写出判别式 Δ = B² - 4AC',
    '第四步：把目标量改写成 x₁ + x₂、x₁x₂ 的组合（弦长、中点、距离平方、面积都在这一步完成转换）',
    '第五步：若目标与 k 无关，读出定值；若与 k 有关，再对 k 求极值并检查 Δ 的限制',
  ]}
  tip="第二步里 x² 的系数必须含 k²：圆是 1+k²，椭圆是 b²+a²k²，双曲线是 b²-a²k²。双曲线当 b²-a²k²=0 时方程退化，不能套韦达。"
/>

<Callout type="formula" title="常用目标量的改写">

$$
\begin{aligned}
\lvert AB\rvert &= \sqrt{1+k^2}\,\lvert x_1-x_2\rvert,\quad (x_1-x_2)^2 = (x_1+x_2)^2-4x_1x_2 = \frac{\Delta}{A^2} \\
\text{中点}\quad M &\left(\frac{x_1+x_2}{2},\ k\frac{x_1+x_2}{2}+m\right) \\
\lvert OA\rvert^2+\lvert OB\rvert^2 &= (1+k^2)(x_1^2+x_2^2) + 2km(x_1+x_2)+2m^2
\end{aligned}
$$

圆的情形还可以用一条更快的路：$\Delta = 4(1+k^2)(r^2-d^2)$，故 $\lvert AB\rvert = 2\sqrt{r^2-d^2}$，与韦达结果必然一致，两法互为验证。

</Callout>

## 三、模型三：点差法（求斜率与中点的捷径）

当题目只关心 $k_{AB}$、弦中点、或「过定点的弦的斜率」时，点差法能绕开整个联立过程。

<SolutionSteps
  model="点差法模型"
  steps={[
    '第一步：设 A(x₁,y₁)、B(x₂,y₂) 都在曲线上，代入曲线方程得两个等式',
    '第二步：两式相减，平方立刻因式分解成和差之积',
    '第三步：两边同除 (x₁ - x₂)(y₁ - y₂)，得到 k_AB 与两个「和」的关系',
    '第四步：若已知中点或过定点，把「和」换成中点坐标或定点坐标',
    '第五步：检查答案里是否含有「和」——若只剩差，说明分解漏了',
  ]}
  tip="两个前提不能忘：两点确实在曲线上、x₁ ≠ x₂（否则是竖直弦，斜率不存在，此时直接写 x₁ = x₂ = 常数）。"
/>

<Callout type="formula" title="点差法结论速查">

椭圆 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$：$k_{AB} = -\dfrac{b^2(x_1+x_2)}{a^2(y_1+y_2)}$，中点 $M(x_0,y_0)$ 时 $k_{AB} = -\dfrac{b^2x_0}{a^2y_0}$。

双曲线 $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$：$k_{AB} = \dfrac{b^2(x_1+x_2)}{a^2(y_1+y_2)}$，中点形式 $k_{AB} = \dfrac{b^2x_0}{a^2y_0}$（**与椭圆差一个负号**，源于方程里的减号）。

</Callout>

## 四、模型四：参数范围模型

<SolutionSteps
  model="参数范围模型"
  steps={[
    '第一步：把题干的位置关系翻译成 Δ 的不等式：相交 Δ>0、相切 Δ=0、有公共点 Δ≥0',
    '第二步：展开判别式（约分掉正系数），得到关于参数的一元二次不等式或恒成立问题',
    '第三步：解不等式，注意定义域限制（k≠0、k≠±b/a 等）',
    '第四步：逐个端点回代，判定它是相切还是无公共点，据此决定括号开闭',
    '第五步：写成区间或集合，最后用「取一个中间值代回原题验证」收尾',
  ]}
  tip="第四步是最容易被跳过的，也是最容易丢分的。端点代回去只需几十秒，却能挡掉整道题的符号性错误。"
/>

<Callout type="formula" title="三类判别式速查">

$$
\begin{aligned}
\text{圆}\ x^2+y^2+Dx+Ey+F=0,\ l: y=kx+b &:\ \Delta = 4(1+k^2)(r^2-d^2) \\
\text{椭圆}\ \frac{x^2}{a^2}+\frac{y^2}{b^2}=1,\ l: y=kx+m &:\ \Delta = 4a^2b^2\bigl(a^2k^2+b^2-m^2\bigr) \\
\text{双曲线}\ \frac{x^2}{a^2}-\frac{y^2}{b^2}=1,\ l: y=kx+m &:\ \Delta = 4a^2b^2\bigl(m^2+b^2-a^2k^2\bigr) \\
\text{抛物线}\ y^2=2px,\ l: y=kx+m &:\ \Delta = 4p\bigl(p-2km\bigr)
\end{aligned}
$$

</Callout>

## 五、模型五：消参与定值定点

<SolutionSteps
  model="定值定点模型"
  steps={[
    '第一步：判断类型——定点题是「过定点」，定值题是「某个量不随参数变」',
    '第二步：定点题把直线写成 y = k(x - x₀) + y₀；定值题照常写 y = kx + m',
    '第三步：代入曲线方程并整理，让方程成为关于 k 的一次式（定点题）或把 k 全部约掉（定值题）',
    '第四步：定点题令 k 的系数为 0，解出的 (x₀, y₀) 就是定点；定值题剩下的常数就是所求',
    '第五步：代一个具体的 k（如 k = 0）回代核对定值',
  ]}
  tip="消参后必须回代核对。若代 k = 0 与 k = 1 得到的定值不同，说明消元过程有符号错误。"
/>

<Callout type="memory" title="定值定点三句口诀">

1. **定点**：令 $k$ 的系数为 0，剩下的 $(x_0, y_0)$ 就是定点坐标。
2. **定值**：目标量与 $k$ 无关时，把 $k = 0$ 的特例算出来当答案，再验证一般 $k$。
3. **抛物线切点弦**：$y^2 = 2px$ 上过 $P(u, v)$ 的两切线，其切点弦为 $vy = px + pu$，恒过 $(-u, 0)$。

</Callout>

## 六、模型六：抛物线与切线模型

抛物线的方向特殊性（开口向哪边）决定了它的设法与椭圆、双曲线不同：$y = kx + m$ 恰好漏掉与对称轴平行的竖直情形，用 $x = my + n$ 覆盖全部。

<SolutionSteps
  model="抛物线模型"
  steps={[
    '第一步：定标准式 y² = 2px（p > 0），读出焦点 (p/2, 0)、准线 x = -p/2、焦半径 x + p/2',
    '第二步：涉及「过定点的直线」时改设 x = my + n，一次覆盖所有方向',
    '第三步：求切线用判别式：y = kx + m 与抛物线相切当且仅当 km = p/2，切点 (p/(2k²), p/k)',
    '第四步：涉及焦点弦长度时设 x = my + p/2，联立即得 y² - 2pmy - p² = 0',
    '第五步：写出结论后用韦达反查一遍端点（最简情形 m = 0 即通径，长度应为 2p）',
  ]}
  tip="通径是最短的焦点弦，长度 2p；如果算出的下界小于 2p，一定是设式漏了竖直方向。"
/>

<Callout type="formula" title="抛物线常用结论">

$$
\begin{aligned}
\text{焦点弦} &\quad \lvert AB\rvert = 2p(m^2+1) \ge 2p \quad (\text{设 } x = my + \tfrac p2) \\
\text{切线} &\quad y_0y = p(x+x_0),\quad l: y=kx+m \text{ 相切} \iff km = \tfrac p2 \\
\text{切点} &\quad \left(\frac{p}{2k^2},\ \frac{p}{k}\right) \\
\text{切点弦} &\quad vy = px + pu \text{，恒过 } (-u, 0)
\end{aligned}
$$

</Callout>

## 七、检查清单（交卷前 30 秒）

<SolutionSteps
  model="解析几何检查清单"
  steps={[
    '斜率：所有涉及斜率的判定，两条线的斜率都存在吗？有没有竖直线被漏掉？',
    '设式：写 y = kx + m 时，竖直情形是单独补的一支吗？',
    '圆：圆心符号对吗？半径还是直径？配方与公式两种算法一致吗？',
    '距离：距离公式的绝对值在吗？切线长里用的是 PC 还是 d，没有搞混？',
    '联立：三项式的 x² 系数含 k² 吗？二次项系数有没有等于 0（退化）的可能？',
    '韦达：x₁+x₂ = -B/A、x₁x₂ = C/A 里的 A 用对了吗？',
    '弦长：乘了 √(1+k²) 吗？结果是否不超过直径？',
    '点差法：平方分解成和差之积了吗？答案里还有「和」吗？',
    '参数范围：端点回代了吗？相切的端点按题意保留还是排除？',
  ]}
  tip="前四条挡住「概念级」失分，中间三条挡住「计算级」失分，最后两条挡住「范围级」失分，逐条过一遍只需半分钟。"
/>

<Callout type="memory" title="口诀速记">

1. **斜率先问存不存在**，存在才用 $k_1k_2=-1$。
2. **设式先声明方向**，$y=kx+m$ 必配一支竖直。
3. **圆看 $d$ 与 $r$**：$d>r$ 相离、$d=r$ 相切、$d<r$ 相交。
4. **韦达先合并**：$x^2$ 系数是 $1+k^2$，不是 1。
5. **弦长乘根号**：$\sqrt{1+k^2}\lvert x_1-x_2\rvert$。
6. **点差必分解**：平方拆成和 × 差，答案里要留「和」。
7. **端点必回代**：$\Delta=0$ 是相切，开闭由题意定。
8. **椭圆减、双曲加**：$c^2=a^2-b^2$ 与 $c^2=a^2+b^2$；渐近线 $b$ 在分子。
9. **定点令系数为零**，**定值代 $k=0$** 核对。

</Callout>
