## 一、模型一：古典概型三步法

<SolutionSteps
  model="古典概型三步模型"
  steps={[
    '第一步：列全体——说清从几个里、按什么顺序、取几个，写出全部等可能结果的个数',
    '第二步：数有利——有利结果的个数必须与分母同口径（同有序或同无序）',
    '第三步：写比值并约分，用「概率在 0 与 1 之间」做量级自检',
  ]}
  tip="分母是本模型唯一的失分点。若算出大于 1 的概率，几乎必然是样本空间漏了情形。"
/>

<Callout type="formula" title="同口径的两种建模">

| 建模方式 | 分母 | 有利数 | 何时选 |
|----------|------|--------|--------|
| 有序 | $n(n-1)\cdots(n-k+1)$ | 逐步选出的有序序列 | 「依次」「先甲后乙」 |
| 无序 | $C_n^k$ | $C_m^i$ 之类的组合 | 「取 $k$ 个」「选代表」 |

两法必须同口径；实在拿不准时，**用两种建模各算一遍**，结果一致才放心。

</Callout>

## 二、模型二：计数原理与排列组合

<SolutionSteps
  model="计数模型"
  steps={[
    '第一步：判有序还是无序——顺序变就用排列 A，顺序不变就用组合 C',
    '第二步：判一步还是多步——分类用加法（互斥），分步用乘法（相乘）',
    '第三步：有「甲不站某位」「甲乙相邻」「至少一个」等限制时，选特殊元素法、捆绑法、插空法或间接法',
    '第四步：写出表达式如 C(5,3)C(3,1)，把每一步的选择数标清楚',
    '第五步：换一种顺序再算一遍，结果必须一致',
  ]}
  tip="「选代表」几乎永远是组合，「分配不同岗位、排队颁奖」几乎永远是排列；判断依据是题目里有没有出现名次。"
/>

<Callout type="memory" title="组合数四条性质">

1. $C_n^m = C_n^{n-m}$（对称性）；
2. $C_n^m + C_n^{m-1} = C_{n+1}^m$（递推性，杨辉三角）；
3. $m\,C_n^m = n\,C_{n-1}^{m-1}$（变形，化简求和常用）；
4. $\sum\limits_{k=0}^{n} C_n^k = 2^n$（二项式定理的 $k=0$ 特例）。

</Callout>

## 三、模型三：分布模型判定与分布列

这是概率部分最值钱的一次判断：判错模型，答案全错。先定模型，再谈计算；模型定下来之后，正态题还有一套专门的对称性打法。

<SolutionSteps
  model="分布模型判定与分布列模型"
  steps={[
    '第一步：圈出「放回」「不放回」「取后放回」「重复试验」字样；没有「放回」但写明「从 N 个中取 n 个」的，一律按不放回处理',
    '第二步：放回或试验独立用二项分布 P(X=k) = C(n,k)·p^k·(1-p)^(n-k)；不放回用组合数 P(X=k) = C(M,k)·C(N-M, n-k) / C(N,n)（公式见下方「公式」框）',
    '第三步：写出 X 的含义与取值范围，逐个取值算概率列成分布表',
    '第四步：检查各概率之和为 1，再用 E(X) = n·M/N 复核期望（两种模型期望相同、方差不同）',
    '第五步：二项分布直接用 E = np、D = np(1-p)；其他分布用 E = Σ xᵢpᵢ 与 D = Σ xᵢ²pᵢ - (E(X))²',
  ]}
  tip="判错模型比算错更致命：放回与不放回的答案一般不同。分水岭就是「放回」两个字，没有就按不放回。"
/>

<Callout type="formula" title="两种模型的分布列">

放回（独立重复试验，二项分布 $B(n,p)$，$p = \dfrac{M}{N}$）：

$$
P(X=k) = C_n^k\,p^k(1-p)^{n-k},\qquad k = 0, 1, \dots, n
$$

不放回（超几何分布）：

$$
P(X=k) = \frac{C_M^k\,C_{N-M}^{\,n-k}}{C_N^n},\qquad \max(0,\, n-(N-M)) \le k \le \min(n, M)
$$

</Callout>

<Callout type="formula" title="不放回情形的方差对照">

$$
E(X) = n\cdot\frac{M}{N} \ (\text{两模型相同}),\qquad D(X) = n\cdot\frac{M}{N}\cdot\frac{N-M}{N}\cdot\frac{N-n}{N-1} \ (\text{不放回})
$$

不放回的方差比二项分布的 $np(1-p)$ **小**，因为不放回使各次抽取「互相排斥」：抽走一个后总体里该类的比例下降。

</Callout>

<SolutionSteps
  model="正态分布对称性模型"
  steps={[
    '第一步：写清 μ 与 σ——N(μ, σ²) 的第二个参数是方差，σ 要开根',
    '第二步：把每个端点写成 μ ± kσ，数清 k 是几（1σ、2σ、3σ 直接查 0.6827、0.9545、0.9973）',
    '第三步：端点不在标准倍数上时，找它关于 μ 的对称点 2μ - a，并把不等号方向同步翻转',
    '第四步：跨过 μ 的区间用「一半加一半」，即 P(X ≤ a) = P(X ≤ μ) + P(μ ≤ X ≤ a)',
    '第五步：用「阈值在 μ 的哪一侧」估算量级，落在 0.5 附近就说明算错了',
  ]}
  tip="μ 决定对称轴、σ 决定胖瘦：σ 越大曲线越矮胖、越不集中，σ 越小才越集中。"
/>

<Callout type="formula" title="对称性三条互推式">

$$
P(X \le a) = P(X \ge 2\mu - a),\qquad P(X \ge a) = P(X \le 2\mu - a),\qquad P(\mu - t \le X \le \mu) = \frac{1}{2}P(\mu - t \le X \le \mu + t)
$$

</Callout>

## 四、模型四：统计量与频率分布直方图

<SolutionSteps
  model="统计量估计模型"
  steps={[
    '第一步：确认纵轴是「频率 / 组距」，需要的频率用「矩形高 × 组距」换算',
    '第二步：用各组中值代表该组，列出中值与频率（或频数）',
    '第三步：平均数 x̄ ≈ Σ 频率 × 组中值；方差 s² ≈ Σ 频率 × (组中值 − 平均数)²',
    '第四步：中位数与百分位数由「累计频率首次达到相应比例」确定所在组，再线性插值估读',
    '第五步：自查——平均数、中位数都必须落在数据总体区间内',
  ]}
  tip="方差一步也不能少：必须先用第三步的平均数，才能算第四步的偏差平方。"
/>

<Callout type="formula" title="一组可复用的自检不等式">

$$
\text{最小值} \le \bar{x} \le \text{最大值},\qquad \text{最小值} \le M_{\text{中位数}} \le \text{最大值}
$$

任何估计值越界，说明权重（频率）取错或组中值用错。

</Callout>

## 五、模型五：线性回归与残差

<SolutionSteps
  model="回归估计模型"
  steps={[
    '第一步：算样本量 n 与两个样本均值 x̄、ȳ',
    '第二步：算三个离差平方和 S(xy) = Σ(xi − x̄)(yi − ȳ)、S(xx) = Σ(xi − x̄)²、S(yy) = Σ(yi − ȳ)²（展开式见下方「公式」框）',
    '第三步：b̂ = S(xy) / S(xx)、â = ȳ − b̂·x̄，写出回归方程 ŷ = b̂x + â（符号式见下方「公式」框）',
    '第四步：把样本均值点 (x̄, ȳ) 代回回归方程验证（必过），再代入待预测的 x 求 ŷ',
    '第五步：若题目问相关强度，用 r = S(xy) / √(S(xx)·S(yy))，并用 r² 解释拟合程度',
  ]}
  tip="b̂ 的分母只能是 S(xx)（x 的离散程度）；写成 S(yy) 是最常见的方向性错误，可用「过 (x̄, ȳ)」这一条反查。"
/>

<Callout type="formula" title="回归系数与相关系数的定义式">

三个离差平方和与离差平方和的积：

$$
S_{xx} = \sum_{i=1}^{n}(x_i - \bar{x})^2,\qquad
S_{yy} = \sum_{i=1}^{n}(y_i - \bar{y})^2,\qquad
S_{xy} = \sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})
$$

回归系数与相关系数：

$$
\hat{b} = \frac{S_{xy}}{S_{xx}},\qquad \hat{a} = \bar{y} - \hat{b}\,\bar{x},\qquad
r = \frac{S_{xy}}{\sqrt{S_{xx}\,S_{yy}}}
$$

</Callout>

<Callout type="memory" title="回归三条必记">

1. 回归直线**必过** $(\bar{x}, \bar{y})$；
2. $\hat{b}$ 的符号由 $S_{xy}$ 决定，$S_{xy} > 0$ 时两变量正相关；
3. $\lvert r \rvert$ 判线性相关强弱，$r^2$ 判拟合好坏，$r^2$ 越接近 1 拟合越好。

</Callout>

## 六、模型六：独立性检验

<SolutionSteps
  model="卡方独立性检验模型"
  steps={[
    '第一步：把两个分类变量列成 2×2 列联表，算出 a、b、c、d 与总人数 n',
    '第二步：代卡方公式 χ² = n(ad−bc)² / [(a+b)(c+d)(a+c)(b+d)]（分式形式见下方「公式」框）',
    '第三步：与临界值 3.841、6.635、10.828 比较，确定把握水平档位',
    '第四步：按固定句式写结论，超过哪一档就写 95%、99% 或 99.9% 的把握',
    '第五步：自查——χ² 偏小时只能说「没有充分证据认为有关联」',
  ]}
  tip="先算 χ² 再看表；不要先看数据「看着像有关」就写结论，检验的门槛是固定的。"
/>

<Callout type="memory" title="口诀速记">

1. **列全体、数有利、写比值**：古典概型三步，分母不漏项。
2. **先判互斥再相加**：不互斥要减交集。
3. **至少 / 至多用对立**：先写白话再算公式。
4. **互斥不是独立**：一个说「不能同时」，一个说「互不影响」。
5. **顺序变用排列、顺序不变用组合**：分类相加、分步相乘。
6. **放回二项、不放回组合**：期望相同、方差不同。
7. **方差分母是 $n$**：$n-1$ 是大学的写法。
8. **正态看 $\mu$ 与 $\sigma$**：对称轴是 $\mu$，$\sigma$ 越大越矮胖。
9. **直方图面积是频率**：纵轴是频率除以组距。
10. **回归必过均值点**：$\hat{b} = S_{xy}/S_{xx}$。
11. **检验照抄句式**：$\chi^2$ 小只能写「没有充分证据」。

</Callout>

## 七、检查清单（交卷前 30 秒）

<SolutionSteps
  model="概率与统计检查清单"
  steps={[
    '样本空间：等可能吗？全列了吗？分子分母同口径吗？概率在 0 与 1 之间吗？',
    '相加处：两个事件互斥吗？「至少」用的是对立事件吗？对立事件与原事件恰好互补吗？',
    '条件概率：分母是 P(A) 吗？P(A) > 0 吗？独立性只验了一个等式就下结论了吗？',
    '全概率公式：分的那一组事件互斥且并集为全集吗？',
    '排列组合：有序还是无序判对了吗？限制条件（相邻、不站某位、至少）处理了吗？',
    '分布模型：放回还是不放回看清了吗？分布列各概率之和为 1 吗？',
    '正态分布：μ 与 σ 写对了吗？不等号方向随对称点一起翻转了吗？取的是 0.6827 还是 0.9545？',
    '方差：分母是 n 吗？平均数先算出来了吗？',
    '直方图：纵轴是频率除以组距吗？平均数用组中值算的吗？结果落在数据范围内吗？',
    '回归：b̂ 的分母是 S(xx) 吗？回归直线过 (x̄, ȳ) 吗？r 与 r² 的说法分清了吗？',
    '检验：χ² 的分母四项齐全吗？结论的把握水平不超过实际档位吗？有没有写成「无关」？',
  ]}
  tip="前四条保证概率概念不串味，中间三条保证统计量算对，最后两条保证回归与检验的表述规范。"
/>
