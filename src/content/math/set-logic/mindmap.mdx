# 集合与常用逻辑用语

## 集合的概念
### 三性
- 确定性
- 互异性
- 无序性
### 表示法
- 列举法
- 描述法
- 图示法（Venn）
### 记号
- a ∈ A
- a ∉ A
- ⌀

## 集合的关系
### 相等 A = B
- 充要：A ⊆ B 且 B ⊆ A
### 子集 A ⊆ B
- 全称表述：∀x ∈ A，x ∈ B
### 真子集 A ⊊ B
- 追加条件 A ≠ B
### 空集的地位
- 是任何集合的子集
- 集合非空时才是真子集
- ⌀ ⊊ ⌀ 不成立
### 子集计数
- 子集 2ⁿ
- 真子集 2ⁿ - 1
- 非空真子集 2ⁿ - 2

## 集合的运算
### 交集 A ∩ B
- 图形：重叠部分
- 代数：解不等式组
### 并集 A ∪ B
- 图形：合并部分
- 代数：取最松条件
### 补集 ∁ᵤA
- 必须先有全集 U
- 逐端点取反
### 运算律
- 分配律
- 结合律
- 幂等律 A ∪ A = A
- 吸收律
#### 德摩根定律
- ∁(A ∪ B) = ∁A ∩ ∁B
- ∁(A ∩ B) = ∁A ∪ ∁B
### 特殊关系
- B ⊆ A 时 A ∩ B = B
- B ⊆ A 时 A ∪ B = A

## 数集与不等式
### 区间记号互化
- x > a → (a, +∞)
- a ≤ x < b → [a, b)
- |x - a| ≤ r → [a-r, a+r]
- |x - a| < r → (a-r, a+r)
### 关系翻译
- A ∩ B = ∅ ⇔ A ⊆ ∁ᵤB
- A ∪ B = U ⇔ ∁A ∩ ∁B = ∅
- A ⊆ B ⇔ 恒成立问题
### 含参讨论
- 先判集合是否为空
- 判别式 Δ
- 端点取舍看开闭

## 逻辑用语
### 联结词
- 且 p ∧ q
- 或 p ∨ q（相容或）
- 非 ¬p
### 真值表
- 与：同真才真
- 或：同假才假
- 非：真假颠倒
### 充分必要条件
- p ⇒ q：p 充分
- q ⇒ p：q 必要
- 充要 ⇔：两向皆成立
- 充分不必要
- 必要不充分
- 既不充分也不必要
### 判定法
- 范围包含方向
- 举反例判否

## 四种命题
### 原命题 p ⇒ q
### 逆命题 q ⇒ p
### 否命题 ¬p ⇒ ¬q
### 逆否命题 ¬q ⇒ ¬p
### 等价关系
- 原命题 ⇔ 逆否命题
- 逆命题 ⇔ 否命题
#### 改证逆否三步
- 否定结论
- 交换位置
- 否定条件

## 量词
### 全称量词 ∀
- 任意、每一个、所有
### 存在量词 ∃
- 存在、有、至少一个
### 命题的否定
- 量词对调 ∀ ⇔ ∃
#### 结论取反号
- ≤ ⇔ >
- < ⇔ ≥
- 等号绝不保留
