## 一、零根法：一切乘积型不等式的总钥匙

凡是能整理成「若干个一次因式的乘积 $\gtrless 0$」的不等式（分式型、分式套、根式型几乎都能整理过来），一律走零根法。

<SolutionSteps
  model="零根法通解模型"
  steps={[
    '第一步：整理成乘积型。分式先同乘分母的平方变成 f(x)·g(x) ≷ 0（记下 g(x) ≠ 0 的限制），根式用平方消去，务必保证没有增根',
    '第二步：因式分解，求出全部实零点 x₁ < x₂ < …（重根只算一次，并注意重根处的不等号成立情况）',
    '第三步：按不等号定形——大于取两边、小于取中间、等于取单点',
    '第四步：与定义域取交集，剔除使分母为零或使被平方式非负性被破坏的点',
  ]}
  tip="重根是最高频的坑：f(x) = (x-1)² > 0 的解集是 x ≠ 1，而不是 x < 1 或 x > 1。根按奇偶次分裂符号区间，重根只裂成两段且两段同号。"
/>

<Callout type="formula" title="零根法的符号表">

$$
\begin{aligned}
(x-x_1)(x-x_2) &> 0 \iff x < x_1 \ \text{或}\ x > x_2 \\
(x-x_1)(x-x_2) &< 0 \iff x_1 < x < x_2 \\
(x-x_1)^2 &> 0 \iff x \ne x_1 \\
(x-x_1)^2 &< 0 \iff x \in \varnothing
\end{aligned}
$$

三次及以上（三个零点）时规律变成「大于取最外两段与中间段」：符号随根的个数每过一个根变号一次。

</Callout>

## 二、基本不等式三步法

<SolutionSteps
  model="基本不等式求最值三步法"
  steps={[
    '一取等：判断能不能用——两项是否都为正？定义域是什么？只要有一项可能取到 0 或负值，立即改用配方或求导',
    '二凑配：凑成两数之和。分式型用 a²/x + b²/y ≥ (a+b)²/(x+y)，倒数型用 A·x + B/x ≥ 2√(AB)',
    '三验证：解出取等条件 x₀，检验 x₀ 是否落在定义域内；在，就把下界当最小值',
    '补一步：题目问最大值时，另用单调性或端点比较，不能用同一条不等式',
  ]}
  tip="写完在草稿纸最上方抄一遍定义域，并画一个圈提醒自己最后要回来验证取等点。"
/>

<Callout type="formula" title="凑配的三种母版">

$$
A x + \frac{B}{x} \ge 2\sqrt{AB}\ (x>0),\quad A, B > 0
$$

$$
\frac{a^2}{x} + \frac{b^2}{y} \ge \frac{(a+b)^2}{x+y}\ (x, y>0)
$$

$$
\frac{a}{x} + \frac{b}{y} \ge \frac{(\sqrt a + \sqrt b)^2}{x+y}\ (a, b, x, y > 0)
$$

第二、三式的价值在于：原来分母是 $x$ 与 $y$ 两个不同量，凑完之后分母变成 $x+y$（**定值**），整个式子只依赖一个和。

</Callout>

## 三、三方关系定位根的位置

解二次不等式时若**只给一个根**，不必用求根公式，可以靠「函数值符号 + 韦达定理」把另一个根定出来。

<SolutionSteps
  model="用函数值定位根的位置"
  steps={[
    '第一步：算一个特殊点的函数值（如 f(0)=c、f(1)=a+b+c），据此判断特殊点在抛物线的上方还是下方',
    '第二步：结合开口方向，判断这一特殊点在两根之间还是在两根之外，从而确定已知根与未知根的相对位置',
    '第三步：用韦达定理 x₁·x₂ = c/a（c = 0 时改用 x₁ + x₂ = -b/a）算出另一个根',
    '第四步：两根确定后按「大于取两边、小于取中间」写解集，并回代特殊点复核',
  ]}
  tip="c = 0 时 f(0) = 0，说明 0 就是根，用求和关系 x₁ + x₂ = -b/a 定另一个根最快。"
/>

**示例**：$f(x) = x^2 - 2x - 3$，已知一根为 $x = 3$。$f(0) = -3 < 0$，抛物线开口向上，$0$ 点在 $x$ 轴下方，必在两根之间，故另一根 $< 0$。由 $x_1 \cdot 3 = \frac{-3}{1} = -3$ 得 $x_1 = -1$。于是 $f(x) > 0$ 的解集为 $x < -1$ 或 $x > 3$。

## 四、绝对值不等式的两种处理

<SolutionSteps
  model="绝对值不等式处理模型"
  steps={[
    '第一步：判断是「绝对值与常数比」还是「两个绝对值互相比」，两者走不同通道',
    '第二步：与常数比时用夹与散——|f(x)| ≤ a 化成 -a ≤ f(x) ≤ a；|f(x)| ≥ a 化成 f(x) ≤ -a 或 f(x) ≥ a（a ≥ 0）',
    '第三步：两个绝对值比时两边同平方（非负数平方保序），化成 f²(x) > g²(x)，再因式分解 f²-g² = (f+g)(f-g) 交给零根法',
    '第四步：写区间时逐端点核对开闭，含等号的端点用闭括号',
  ]}
  tip="a 的符号先判：a < 0 时 |f(x)| ≤ a 无解，这是选择题的常见陷阱选项来源。"
/>

<Callout type="memory" title="绝对值解集的几何图景">

$|x - a|$ 是数轴上点 $x$ 到点 $a$ 的**距离**。

- $\lvert x-a\rvert \le b$：以 $a$ 为圆心、$b$ 为半径的**闭圆盘**，即闭区间 $[a-b,\ a+b]$；
- $\lvert x-a\rvert < b$：开区间 $(a-b,\ a+b)$；
- $\lvert x-a\rvert \ge b$：圆盘**外侧**，含端点，两条射线；
- $\lvert x-a\rvert > b$：圆盘外侧，不含端点。

「闭内开外」的记法：**小于号带端点（闭），大于号也带端点（闭）但位置在外；只有当中间是严格不等号时端点才丢弃。** 记忆抓手是「$=$ 永远意味着取到端点」。

</Callout>

## 五、含参二次不等式的分类讨论

<SolutionSteps
  model="含参二次不等式讨论模型"
  steps={[
    '第一步（最易漏）：写「当 a = 0 时」，降为一次不等式 bx + c ≷ 0，按 b 的符号求出解集',
    '第二步：写「当 a ≠ 0 时」，令 Δ = b² - 4ac，按 Δ < 0、Δ = 0、Δ > 0 三行展开',
    '第三步：每行内部再按 a 的符号与不等号方向决定取两边还是取中间',
    '第四步：把各支解集取并集，最后统一写成区间或集合的并',
  ]}
  tip="第一行哪怕只写一句结论也值步骤分。含参二次不等式不做 a = 0 的讨论，分类讨论分整块丢掉。"
/>

<Callout type="formula" title="a = 0 那一支的完整结论">

对 $bx + c > 0$：

| 条件 | 解集 |
|------|------|
| $b > 0$ | $x > -\dfrac{c}{b}$ |
| $b < 0$ | $x < -\dfrac{c}{b}$ |
| $b = 0$ 且 $c > 0$ | $\mathbb{R}$ |
| $b = 0$ 且 $c \le 0$ | $\varnothing$ |

记忆抓手：**$b \ne 0$ 时解集永远是半直线，不会为空**；只有 $b = 0$ 才可能「全解」或「无解」。所以看到「$a = 0$」那一支，只需三行就能写完。

</Callout>

## 六、恒成立与分离参数模型

<SolutionSteps
  model="恒成立与分离参数模型"
  steps={[
    '第一步：先分辨是「对一切实数」还是「在给定区间 D 上」——前者是整体性质，后者是局部性质',
    '第二步：整体恒成立时用双重条件：二次项系数 > 0 且 Δ 严格小于 0（不等号含等号则用 Δ ≤ 0）',
    '第三步：区间恒成立时优先分离参数，把 λ 提出来得到 λ ≥ f(x)，然后求 f(x) 在 D 上的最大值',
    '第四步：验证取得最大值的点 x₀ 确实落在 D 内；若 D 是开区间且最大值取不到，要写明只有下确界',
  ]}
  tip="「恒成立」是全称命题 → 取最大值；「有解」是存在命题 → 取最小值。方向反了答案会整体错位。"
/>

<Callout type="formula" title="三个必背的恒成立结论">

$$
ax^2+bx+c > 0 \ \ (\forall x \in \mathbb{R}) \iff a > 0 \ \text{且}\ b^2-4ac < 0
$$

$$
ax^2+bx+c \ge 0 \ \ (\forall x \in \mathbb{R}) \iff a > 0 \ \text{且}\ b^2-4ac \le 0
$$

$$
x^2-2x+a \ge 0 \ \ (\forall x \in [-1,3]) \iff a \ge \max_{[-1,3]}\left(1-(x-1)^2\right) = 1
$$

第三条是分离参数法的样板：原式整理成 $a \ge 2x - x^2$，在区间上找右端的最大值 $1$（$x = 1 \in [-1,3]$），故 $a \ge 1$。

</Callout>

## 七、检查清单（交卷前 30 秒）

<SolutionSteps
  model="不等式检查清单"
  steps={[
    '定义域：分式不等式写了定义域吗？解集与定义域取交集了吗？分母为零的点剔除了吗？',
    '开口方向：二次不等式里 a 的符号看清了吗？口诀用的是 a > 0 的版本吗？',
    '判别式与重根：Δ 的正负算对吗？根有重根时符号段数是否按奇偶分？',
    '端点开闭：每个区间的括号与原不等号含不含等号一致吗？取等点用实心还是空心？',
    '基本不等式：两项真的都为正吗？取等点落在定义域内吗？问的是最大值时是否改用了单调性？',
    '绝对值：右端常数 a ≥ 0 吗？是「夹」成一段还是「散」成两支？两个绝对值比较时是否同平方了？',
    '分类讨论：含参二次不等式写了「当 a = 0 时」这一支吗？各支解集取的是并集还是交集？',
    '恒成立：开口方向条件写了吗？严格与非严格的不等号与 Δ 的对应是否用对？',
    '量词方向：分离参数时确认过是「恒成立取最大」还是「有解取最小」吗？',
  ]}
  tip="前四条能消灭解集书写类失分，中间三条覆盖最值与绝对值，后两条管住解答题的分类与量词。"
/>

<Callout type="memory" title="口诀速记">

1. **一取等、二凑配、三验证**：基本不等式三步，一步都不能省。
2. **一正、二定、三相等**：两个条件为正、和为定值或积为定值、两项相等。
3. **大于取两边，小于取中间，等号单点**：零根法核心口诀，前提是 $a > 0$。
4. **a 变号两句对调**：$a < 0$ 时「取两边」与「取中间」互换。
5. **不乘分母乘平方**：$\frac{f}{g} \gtrless 0 \iff f \cdot g \gtrless 0$ 且 $g \ne 0$，方向永不变。
6. **闭内开外，$=$ 取端点**：绝对值不等式的端点开闭判据。
7. **绝对值比绝对值，同平方**：平方非负保序，比去绝对值可靠。
8. **恒成立双条件：开口向上 + 无零点**：$\Delta$ 严格与非严格要与不等号含不含等号配套。
9. **恒成立取最大，有解取最小**：分离参数法的量词方向。
10. **$a = 0$ 必先写**：含参二次不等式的第一行。

</Callout>
