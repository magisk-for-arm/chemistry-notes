# 不等式

## 基本不等式
### 定理
#### a > 0，b > 0 时 √(ab) ≤ (a + b) / 2
#### 等号条件 a = b
### n 项推广
#### (a₁a₂…aₙ) 开 n 次方 ≤ (a₁ + a₂ + … + aₙ) / n
### 三个前提
#### 两项都为正
#### 是和的形式
#### 取等点在定义域内
### 倒数型
#### x + 1/x ≥ 2（x > 0）
#### x + 1/x ≤ -2（x < 0）
#### (x + 1/x)² ≥ 4（x ≠ 0）
### 注意
#### 不能对负数套用
#### 下界 ≠ 最小值

## 均值不等式变形链
### 平方型
#### a² + b² ≥ 2ab
#### (a + b)² ≥ 4ab
### 倒数型
#### 1/a + 1/b ≥ 4 / (a + b)
#### (a + 1/a)² ≥ 4
### 柯西型
#### a²/x + b²/y ≥ (a + b)² / (x + y)
#### a/x + b/y ≥ (√a + √b)² / (x + y)
### 凑配的价值
#### 分母由 x、y 变成 x + y
#### 得到定值分母

## 基本不等式三步法
### 一取等
#### 两项是否恒为正
#### 定义域是什么
#### 一项非正则放弃
### 二凑配
#### Ax + B/x 母版
#### a²/x + b²/y 母版
#### 分母必须化为定值
##### 等号条件 a/x = b/y
### 三验证
#### x₀ 是否落在定义域内
#### 落在内 → 下界即最小值
#### 落在外 → 只能给下确界
#### 闭区间还需比较端点值
##### 落在外时无最小值
### 补一步
#### 问最大值改用单调性
#### 作差或求导定单调区间
##### 基本不等式只能给下界

## 一元二次不等式
### 三个角色
#### 不等式 ax² + bx + c ≷ 0
#### 二次函数 f(x) = ax² + bx + c
#### 抛物线 y = f(x)
### 解法
#### 因式分解 a ≠ 0
#### 配方 a = 1
#### 求根公式（分式根）
#### 图像法
### 三查
#### 查 a 的符号（开口方向）
#### 查 Δ 的正负（交点个数）
#### 查等号（实心点 / 空心圈）
### 口诀
#### 大于取两边
#### 小于取中间
#### 等号取单点
#### a < 0 时两句对调
### 三方关系
#### 解集 = 抛物线在轴上方或下方的横坐标
#### a > 0 且 Δ < 0 ⟺ 恒大于 0
#### a > 0 且 Δ = 0 ⟺ 除切点外恒大于 0
#### a < 0 且 Δ < 0 ⟺ 无解
#### a < 0 且 Δ = 0 ⟺ 只有切点满足
### 韦达定理
#### x₁ + x₂ = -b / a
#### x₁ · x₂ = c / a
#### 由已知一根定另一根
#### c = 0 时改用求和关系
##### x₁ = c / (a · 已知根)
##### 两条件要同时成立
### 定位根的位置
#### 算 f(0) = c 的符号
#### 判断特殊点在两根之内还是之外
#### 代入韦达关系定另一根
##### 开口向上时 f(0) < 0 ⟹ 0 在根之间
##### 开口向下时结论相反

## 绝对值不等式
### 几何意义
#### |x - a| 是点到 a 的距离
#### 闭内开外
#### = 一定取到端点
### 四个结论
#### |x - a| ≤ b ⟹ a - b ≤ x ≤ a + b
#### |x - a| < b ⟹ a - b < x < a + b
#### |x - a| ≥ b ⟹ x ≤ a - b 或 x ≥ a + b
#### |x - a| > b ⟹ x < a - b 或 x > a + b
### 与常数比
#### 夹：-b ≤ f(x) ≤ b
#### 散：f(x) ≤ -b 或 f(x) ≥ b
### 绝对值比绝对值
#### 两边同平方
#### 平方非负保序
#### 因式分解 f² - g²
#### 交给零根法
### 边界
#### b ≤ 0 时先判符号
#### 提取公因数后配方

## 分式不等式
### 核心禁令
#### 禁止直接同乘分母
#### 分母符号未知会变号
### 正确通道一
#### 同乘 g²(x) > 0
#### f/g ≷ 0 ⟺ f · g ≷ 0 且 g ≠ 0
### 正确通道二（讨论法）
#### 分子分母同为正
#### 分子分母同为负
#### 同为负这一支最易漏
### 零根法
#### 搬：通分成分母为常数
#### 数：全部实零点从小到大排
#### 判：两边 / 中间 / 单点
#### 剔：去掉分母为零的点
### 含 ≤ 与 ≥ 时
#### 检查解集内部是否含禁止点

## 含参讨论
### 固定起手式
#### 第一行：当 a = 0 时
#### 第二行：当 a ≠ 0 时令 Δ = b² - 4ac
### a = 0 那一支
#### b > 0 → x > -c/b
#### b < 0 → x < -c/b
#### b = 0 且 c > 0 → 全体实数
#### b = 0 且 c ≤ 0 → 无解
### a ≠ 0 的三行
#### Δ < 0：a > 0 恒成立，a < 0 无解
#### Δ = 0：a > 0 去掉切点，a < 0 只有切点
#### Δ > 0：按 a 与不等号定两边或中间
### 收尾
#### 各支解集取并集
#### 统一写成区间

## 恒成立与分离参数
### 全体实数恒成立
#### ax² + bx + c > 0 ⟺ a > 0 且 Δ < 0
#### ax² + bx + c ≥ 0 ⟺ a > 0 且 Δ ≤ 0
#### ax² + bx + c < 0 ⟺ a < 0 且 Δ < 0
### 双重条件
#### 开口方向定符号朝哪边
#### Δ 定有没有零点
#### 严格与非严格要配套
### 区间恒成立
#### 分离参数：λ ≥ f(x)
#### 恒成立 = 全称 → 取最大值
#### 有解 = 存在 → 取最小值
#### 验证取值点落在区间内
#### 开区间取不到则写下确界
### 分离参数的前提
#### 参数能一次项分离
#### 分母符号已知
#### 最大值能取到

## 常见陷阱
### 不看正负就用基本不等式
### 取等点不在定义域却答最小值
### 把下界当最大值
### 不看开口方向套口诀
### 分式不等式直接同乘分母
### 忘记剔除分母为零的点
### 含参漏掉 a = 0
### 绝对值两边同去绝对值
### 恒成立只判 Δ
### 分离参数忘记取最大值
