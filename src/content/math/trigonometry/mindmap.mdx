# 三角函数与解三角形

## 弧度制
### 定义
- 弧长等于半径的圆心角记作 1 弧度
### 换算基准
- 180° = π rad
- 弧度 = 角度 × π/180
### 特殊角对照
- 30° ↔ π/6
- 45° ↔ π/4
- 60° ↔ π/3
- 90° ↔ π/2
- 120° ↔ 2π/3
- 150° ↔ 5π/6
- 180° ↔ π
- 360° ↔ 2π
### 意义
- 周期才干净地等于 2π
- 四条象限线把圆均分成 8 份，每份 π/4

## 三角函数的定义
### 单位圆定义
- 角 α 终边交单位圆于 P(x, y)
- sinα = y
- cosα = x
- tanα = y/x
### 定义域
- sin、cos：全体实数
- tan：α ≠ π/2 + kπ
### 值域
- sin、cos：[-1, 1]
- tan：全体实数

## 符号：象限
### 第一象限 0 < α < π/2
- sin 正、cos 正、tan 正
### 第二象限 π/2 < α < π
- sin 正、cos 负、tan 负
### 第三象限 π < α < 3π/2
- sin 负、cos 负、tan 正
### 第四象限 3π/2 < α < 2π
- sin 负、cos 正、tan 负
### 口诀
- 一全正，二正弦，三正切，四余弦
### 可靠判据
- 画单位圆：x 定 cos，y 定 sin，同号定 tan

## 同角关系与大小比较
### 基本关系
- sin²α + cos²α = 1
- tanα = sinα / cosα（cosα ≠ 0）
- sinα cosα = ½ sin2α
### 象限符号判断法
- 第一步用关系式算绝对值
- 第二步按象限贴符号
- 开方结果必带 ±
### 大小比较
- (sinα - cosα)² = 1 - sin2α
- sin2α > 0 时两者之差绝对值小于 1
- |sin2α| = 1 时 |sinα| = |cosα|
- sinα ± cosα = √2 sin(α ± π/4)

## 诱导公式
### 规律
- 奇变偶不变
- 符号看象限
### 常用式
- sin(kπ + α) = (-1)ᵏ sinα
- cos(kπ + α) = (-1)ᵏ cosα
- sin(π/2 - α) = cosα
- cos(π/2 - α) = sinα
- sin(π/2 + α) = cosα
- cos(π/2 + α) = -sinα
### 使用顺序
- 符号看的是整式的象限
- 先把 α 化到 0 < α < π/2
- 符号不确定时保留未化简形式

## 图像与性质
### 四参数
- A 振幅、B 上下平移、ω 频率、φ 初相
### 周期
- T = 2π / |ω|
- 与 A、B、φ 无关
### 值域
- [B - |A|, B + |A|]
- 最大值 A + B
- 最小值 B - A
### 五点法
- ωx + φ = 0 → y = B
- ωx + φ = π/2 → y = B + A
- ωx + φ = π → y = B
- ωx + φ = 3π/2 → y = B - A
- ωx + φ = 2π → y = B
### 对称轴
- ωx + φ = π/2 + kπ
- 过极值点的竖直线
### 对称中心
- ωx + φ = kπ
- 纵坐标恒为 B
### 单调区间
- 增：ωx+φ ∈ [-π/2+2kπ, π/2+2kπ]
- 减：ωx+φ ∈ [π/2+2kπ, 3π/2+2kπ]
- 结果写成闭区间
### 平移
- 向右 m 个单位：φ 改成 φ - ωm
- 向左 m 个单位：φ 改成 φ + ωm
- 向上 m 个单位：只改 B

## 三角恒等变换
### 二倍角
- sin2α = 2 sinα cosα
- cos2α = 2cos²α - 1
- cos2α = 1 - 2sin²α
- cos2α = cos²α - sin²α
- tan2α = 2tanα / (1 - tan²α)
### 降幂
- sin²α = (1 - cos2α) / 2
- cos²α = (1 + cos2α) / 2
### 三次幂
- sin³α = ¾ sinα - ¼ sin3α
- cos³α = ¾ cosα + ¼ cos3α
### 辅助角公式
- a sinx + b cosx = √(a²+b²) sin(x + φ)
- φ 与系数对 (a, b) 同象限
- 最大值 √(a²+b²)，最小值 -√(a²+b²)
### 使用原则
- 见平方降幂
- 见乘积升幂
- 最后用 sin²+cos²=1 约分

## 正弦定理与余弦定理
### 正弦定理
- a / sinA = b / sinB = c / sinC = 2R
- a = 2R sinA
- S = abc / (4R)
### 余弦定理
- c² = a² + b² - 2ab cosC
- a² = b² + c² - 2bc cosA
- b² = a² + c² - 2ac cosB
### 面积公式
- S = ½ ab sinC
- S = ½ bc sinA
- S = ½ ca sinB
- 角必须是两条边的夹角
### 形状判据
- cosC = (a²+b²-c²) / (2ab)
- a²+b² > c² → C 锐角
- a²+b² = c² → C = 90°
- a²+b² < c² → C 钝角
- 判断整体形状先找最长边

## 解三角形三类题型
### 已知两角一边
- 先用 A+B+C = 180° 求第三角
- 用正弦定理求边
- 唯一解
### 已知两边及夹角
- 找准夹角是两条边的公共顶点
- 用余弦定理求第三边
- 再用正弦定理或余弦定理求角
- 唯一解
### 已知两边及一对角（SSA）
- t = b sinA / a
- t > 1 无解
- t = 1 一解，B = 90°
- t < 1 两个候选角
- 逐一验 A + B < 180°
- 高低判据：锐角看 h = b sinA
- 长短判据：直角钝角看 a 与 b
### 已知三边
- 用余弦定理反求三个角
- 再求面积

## 实际应用
### 测高
- 过目标作地面垂线
- tanθ = 高 / 水平距离
### 测河宽
- 岸上取两点，连线平行河岸
- 同侧测量，远离点的内角 = 180° - 仰角
### 航向问题
- 方位角与偏角拆成两个角
- 首尾相连构成三角形
### 四边形
- 作对角线拆成两个三角形
- 公共对角线列两个方程消元

## 常见陷阱
### 弧度角度混用
### 开方丢正负号
### 象限符号记反
### 诱导公式按原角定符号
### 同正弦值只写一个角
### 周期漏绝对值
### 平移改错对象
### 对称轴与对称中心混淆
### 面积公式边角不对应
### SSA 漏讨论两解
### 两角一边误用余弦定理

## 解题方法
### 化归模型
- 统一单位
- 拆 kπ 改系数
- 拆 kπ/2 改函数名
- 最后补符号
### 五点法模型
- 读四参数
- 求周期
- 算五个点
- 判轴与心
### 解三角形模型
- 一判题型
- 二写定理完整形式
- 三列候选验范围
- 四结果写规范
### 实际建模模型
- 画图标角
- 仰角翻成夹角
- 落成三角形
- 量级检验
### 检查清单
- 单位是否统一
- 符号是否按象限
- 候选角是否列全
- 周期是否取绝对值
- 定理是否选对
- 两解是否验完
