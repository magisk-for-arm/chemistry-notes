## 一、坐标化模型（一切向量题的入口）

平面向量的题目分两类：**给几何图形求结论**、**给坐标算结论**。前一类一律先翻译成坐标。

<SolutionSteps
  model="平面向量坐标化模型"
  steps={[
    '第一步 建系：平面几何题先建平面直角坐标系；若题干已给点坐标就直接用',
    '第二步 取向量：每个向量都按「终点坐标减起点坐标」写出，不看图形',
    '第三步 定基底：把题目给的向量（多半是 三角形 ABC 的两条边）当作基底，或直接用 x 轴 y 轴单位向量',
    '第四步 分解：求某个向量的坐标，就是把它写成 x e 加 y j 再读出 x 与 y',
    '第五步 运算：加减乘逐分量算，判定平行或垂直时改用行列式或点积',
  ]}
  tip="基底分解有唯一解的前提是两个基底向量不共线。先算行列式，若为零则分解不唯一，要回到题目条件去找漏掉的条件。"
/>

<Callout type="formula" title="基底分解的两种解法">

设 $\vec a = x \vec e_1 + y \vec e_2$。用坐标写就是解**二元一次方程组**：

$$
\begin{cases} x_1 x + y_1 y = u \\ x_2 x + y_2 y = v \end{cases}
$$

行列式 $\Delta = x_1y_2 - x_2y_1$。$\Delta \ne 0$ 时由克拉默法则 $x = \frac{uy_2 - v y_1}{\Delta}$，$y = \frac{x_1 v - x_2 u}{\Delta}$；$\Delta = 0$ 时无解或无穷解。

</Callout>

## 二、数量积求角模型

<SolutionSteps
  model="数量积求夹角模型"
  steps={[
    '第一步 求点积：坐标式 x1x2 加 y1y2，或定义式 模 a 乘 模 b 乘 cos θ',
    '第二步 求两个模长：各自开根，注意模长非负',
    '第三步 代公式：cos θ 等于点积除以两个模长的乘积',
    '第四步 定锐钝：看点积的正负，正为锐角、零为直角、负为钝角',
    '第五步 验算：结果必须落在 -1 到 1 之间，超出立刻回查',
  ]}
  tip="只要求「求夹角」时分子不能加绝对值；要求「两向量所成角的余弦值」也一样。只有题目明说「锐角」才可以放心取绝对值。"
/>

<Callout type="memory" title="由点积直接判形状的三条结论">

| 点积的值 | 几何结论 |
|----------|----------|
| $= 0$ | 两向量**垂直** |
| $> 0$ | 夹角为**锐角**；若同时平行（同向）则为同向 |
| $< 0$ | 夹角为**钝角**；若同时平行则为反向 |
| $= \lvert\vec a\rvert\lvert\vec b\rvert$ | 同向平行 |
| $= -\lvert\vec a\rvert\lvert\vec b\rvert$ | 反向平行 |

这五条能直接代替大部分计算。$\vec{AB}\cdot\vec{AC} = 0$ 就等于「角 $A$ 是直角」，$\vec{AB}\cdot\vec{AC} < 0$ 就等于「角 $A$ 是钝角」。

</Callout>

## 三、几何证明模型（平行与垂直）

<SolutionSteps
  model="向量法证明平行或垂直模型"
  steps={[
    '第一步 写位置向量：把要用到的点都表示成 OA、OB、OC 的线性组合（中点、重心按公式拆）',
    '第二步 翻译结论：平行翻译成「存在实数 λ 使两向量成倍数」或「行列式为零」；垂直翻译成「点积为零」',
    '第三步 算：按加减法则求出目标向量的坐标，再代入判据',
    '第四步 收口：写「由……判定，得两直线平行（或垂直）」',
  ]}
  tip="证平行时用平行四边形对角线关系：若 AC 与 BD 是对角线且互相平分，则四边形 ABCD 是平行四边形，这是最省事的判据。"
/>

<Callout type="formula" title="中位线与垂直平分线的向量式">

**中位线**：$D, E$ 分别是 $AB, AC$ 的中点，则

$$
\vec{DE} = \vec{AE} - \vec{AD} = \frac{1}{2}\vec{AC} - \frac{1}{2}\vec{AB} = \frac{1}{2}\left(\vec{AC} - \vec{AB}\right) = \frac{1}{2}\vec{BC}
$$

所以 $DE \parallel BC$ 且 $DE = \frac{1}{2}BC$。**关键动作是「同起点的两向量相减等于终点之差」**。

**等腰三角形底边中线**：设 $D$ 是 $BC$ 的中点，由 $\vec{DC} = -\vec{DB}$ 与 $\vec{AB} = \vec{AD} + \vec{DB}$ 得

$$
AB^2 - AC^2 = \left|\vec{AD} + \vec{DB}\right|^2 - \left|\vec{AD} - \vec{DB}\right|^2 = 4\vec{AD}\cdot\vec{DB}
$$

而 $AB = AC$ 使左边为零，故 $\vec{AD}\cdot\vec{DB} = 0$，即 $AD \perp BD$，也就是 $AD \perp BC$。这个「$(\vec a + \vec b)^2 - (\vec a - \vec b)^2 = 4\vec a\cdot\vec b$」的平方差技巧，在等腰、直角、垂直平分三类问题中反复出现。

</Callout>

## 四、解三角形模型

<SolutionSteps
  model="余弦定理与解三角形模型"
  steps={[
    '第一步 标方向：写出 a 等于 BC、b 等于 CA、c 等于 AB，并在草稿上标箭头方向',
    '第二步 闭合：由 a 加 b 加 c 等于零得 c 等于负 a 减 b',
    '第三步 取模平方：c 的平方等于 a 的平方加 b 的平方加 2 a 点乘 b',
    '第四步 算点积：a 与 b 的夹角是 pi 减 C，故点积等于 ab cos(pi 减 C) 等于负 ab cos C',
    '第五步 收式：c 的平方等于 a 的平方加 b 的平方减 2ab cos C',
    '第六步 求解：由 cos C 等于 a 的平方加 b 的平方减 c 的平方 再除以 2ab 求夹角，或直接解出未知边',
  ]}
  tip="第四步的负号是全题唯一的坑。算完用三角形不等式自检：a、b、c 必须满足两边之差小于第三边、小于两边之和。"
/>

<Callout type="formula" title="余弦定理的三种变形">

$$
c^2 = a^2 + b^2 - 2ab\cos C
\quad\Longleftrightarrow\quad
\cos C = \frac{a^2 + b^2 - c^2}{2ab}
$$

$$
\cos A = \frac{b^2 + c^2 - a^2}{2bc}, \qquad
\cos B = \frac{a^2 + c^2 - b^2}{2ac}
$$

**角与边的对应不能错**：$\cos A$ 的分子里缺的是 $a^2$（$a$ 是角 $A$ 的对边）。判断「哪个角是直角」看哪个分子的值为零：$a^2 + b^2 = c^2$ 说明 $C = 90^\circ$。

</Callout>

## 五、复数代数运算模型

<SolutionSteps
  model="复数运算模型"
  steps={[
    '第一步 规范：把每个复数写成 a 加 bi 的标准形式，i 的平方一律替换成 -1',
    '第二步 i 的幂：指数除以 4 取余数，映射到 1、i、-1、-i',
    '第三步 运算：加减按分量；乘法按「实乘实减虚乘虚，虚乘实加实乘虚」',
    '第四步 除法：分子分母同乘分母的共轭，分母化为 c 的平方加 d 的平方',
    '第五步 整理：合并同类项，写成 a 加 bi 的标准形式',
    '第六步 验算：除法题把结果乘回原分母，或用虚部对数法核对',
  ]}
  tip="「实乘实减虚乘虚，虚乘实加实乘虚」这十六字比背展开式可靠：共轭的虚部是负的，所以乘的时候虚部交叉项一正一负。"
/>

<Callout type="tip" title="待定系数法：处理「对一切 z 恒成立」的复数条件">

若条件形如「对一切非零复数 $z$，$\dfrac{az+b}{cz+d} = m + ni$（$m, n$ 为实数）恒成立」，直接去分母：

$$
az + b = (m + ni)(cz+d) = (mc - nd) + (md + nc) i
$$

左边的实部恒为 $a$、虚部恒为 $0$，于是得到关于 $m, n$ 的方程组，与已知的 $a, b, c, d$ 联立即可。这类题**不要真的去乘共轭**，比较系数能省一半步骤。

</Callout>

## 六、复平面几何模型

<SolutionSteps
  model="复平面几何模型"
  steps={[
    '第一步 设元：设 z 等于 x 加 y i，把几何条件翻译成 x 与 y 的方程',
    '第二步 去根号：遇到模长条件就把两边平方（模长非负，平方不丢信息）',
    '第三步 化简：整理成直线、圆或圆锥曲线的标准形式',
    '第四步 判别：与标准形式对照，指出轨迹是什么、在什么范围内',
    '第五步 结论：写清楚「点的轨迹是……（注明是否含端点、是否为空集）」',
  ]}
  tip="模长条件直接对应距离：|z| 等于 2 就是 x 的平方加 y 的平方等于 4（圆）；|z 减 w| 等于给定常数就是以 w 对应点为圆心的圆。"
/>

<Callout type="formula" title="三个对称与两个距离">

| 几何表述 | 复数表达 |
|----------|----------|
| 关于**实轴**对称 | $z \mapsto \overline z$ |
| 关于**虚轴**对称 | $z \mapsto -\overline z$ |
| 关于**原点**对称 | $z \mapsto -z$ |
| 点 $Z$ 到原点的距离 | $\lvert z\rvert = \sqrt{a^2+b^2} \ge 0$ |
| 两点 $Z_1, Z_2$ 的距离 | $\lvert z_1 - z_2\rvert = \sqrt{(a_1-a_2)^2+(b_1-b_2)^2}$ |

</Callout>

## 七、检查清单（交卷前 30 秒）

<SolutionSteps
  model="平面向量与复数检查清单"
  steps={[
    '向量方向：每个向量的坐标都是「终点减起点」吗？相减的两个向量归位了吗？',
    '模长非负：所有模长结果检查过有没有负号？系数带了绝对值吗？',
    '判据用对：问平行用减号、问垂直用加号？行列式和点积没搞混？',
    '平方写法：有没有写出 vec a 的平方这种非法式子？平方都写成模的平方了吗？',
    '夹角公式：分母是模长的乘积还是写成了和？分子保留了符号吗？结果落在 -1 到 1 之间吗？',
    '三角形公式：中点的分母是 2、重心是 3、内心的分母是周长，有没有串？',
    '余弦定理：点积的负号写了吗？算出的边长满足三角形不等式吗？角的字母与对边是否对应？',
    '复数分类：问纯虚数时有没有补上「虚部不为零」？0 归到实数那边了吗？',
    '复数运算：除法同乘的是分母的共轭吗？分母化成正的实数了吗？结果形式是 a 加 bi 吗？',
    '复平面：对称关系配对了吗（实轴取共轭、原点取相反数、虚轴取负共轭）？',
  ]}
  tip="前四条管住向量小题，中间三条管住解答题，最后三条管住复数。失分最多的其实是「判据用对」和「除法同乘共轭」这两条。"
/>

<Callout type="memory" title="口诀速记">

1. **终点减起点**，起点不同先归位。
2. **模长非负**，系数带绝对值。
3. **平行写减、垂直写加**；平行含反向。
4. **平方必带模**：$\lvert\vec a\rvert^2 = x^2 + y^2$。
5. **夹角分母是积，分子保留号**，结果落在 -1 到 1。
6. **点积正锐、零直、负钝**；平行时正为同向、负为反向。
7. **两点分母 2，三点分母 3，内心分母周长**。
8. **a 与 b 夹 pi 减 C，点积带负号**。
9. **i 的幂四周期：一 i 负一 负 i**。
10. **除法同乘共轭，实乘实减虚乘虚、虚乘实加实乘虚**。
11. **纯虚数虚部不为零，零是实数**。
12. **实轴取共轭、原点取相反数、虚轴取负共轭**。

</Callout>
