# 平面向量与复数

## 向量的概念
### 三要素
- 大小
- 方向
- 自由向量：与起点终点无关
### 基本概念
- 零向量：模为零，方向任意
- 单位向量
- 相等向量：等长且同向
- 共线向量：同向或反向
### 记号
- a
- 箭头 AB
- 模 a

## 向量的线性运算
### 加法
- 三角形法则：首尾相接
- 平行四边形法则：同起点，作用于对角线
- 加法交换律与结合律
- 零向量是运算的单位元
### 减法
- a − b = a + b 的相反向量
- 起点相同：a − b = 终点之差
- 减法没有交换律
### 数乘
- 系数为正时同向
- 系数为负时反向
- 系数为零时得零向量
- 模：|λa| = |λ||a|
- a = λb ⟺ a 与 b 共线（b ≠ 0）
### 运算法则
- 数乘对加法可分配
- 数乘对数乘可结合

## 数量积
### 定义
- 定义式：a · b = |a||b|cos θ
- 坐标式：a · b = x₁x₂ + y₁y₂
- 结果是一个实数，不是向量
### 几何意义
- 投影意义：a · b = |a| ×（b 在 a 方向上的投影）
- a 与 b 的夹角范围 0 到 π
### 性质
- 交换律
- 分配律
- a · a = |a|²
- |a|² = x² + y²
- 点积为正对应锐角
- 点积为零对应直角
- 点积为负对应钝角
### 夹角公式
- cos θ = (a · b) / (|a||b|)
- 分子保留符号，结果落在 -1 到 1
### 判定
- 垂直：点积为零
- 垂直：x₁x₂ + y₁y₂ = 0
- 平行：行列式为零
- 平行：x₁y₂ − x₂y₁ = 0
- 平行包含反向

## 基底与坐标
### 平面向量基本定理
- 两个不共线向量作基底
- 任意向量可唯一表示
- 坐标形式：a = xe₁ + ye₂
- 标准基底：x 轴与 y 轴单位向量
### 唯一性的条件
- 行列式不为零
- 行列式为零时无解或无穷多解
### 解法
- 令 a = λb + μc，化为二元一次方程组
- 克拉默法则

## 向量在三角形中的应用
### 位置向量公式
- 中点：M = (A + B)/2
- 重心：G = (A + B + C)/3
- 内心：对边长加权，分母是周长
- 外心：到三个顶点等距
### 面积公式
- 二维叉积：|a × b| = ½|x₁y₂ − x₂y₁|
- 夹角形式：|a × b| = ½|a||b| sin θ
### 证明平行
- 中位线向量 = ½ 第三边向量
- 对角线互相平分则为平行四边形
- 判定式：行列式为零
### 证明垂直
- 判定式：点积为零
- 等腰三角形底边中线垂直底边
(a + b)² − (a − b)² = 4a · b
### 解三角形
- 闭合式：a + b + c = 0
- 两边取模的平方即得余弦定理
- 夹角是 π − C，故点积带负号
- 三角形不等式自检

## 复数的概念
### 虚数单位
- i² = −1
### 一般形式
- z = a + bi
- 实部 a
- 虚部 b
### i 的幂
- 周期为四
- i^(4k) = 1，周期为 4
- 余一得 i
- 余二得 -1
- 余三得 -i
### 分类
- 实数：虚部为零
- 纯虚数：实部为零且虚部不为零
- 虚数：虚部不为零
- 零是实数，不是纯虚数
### 相等条件
- 实部相等且虚部相等

## 复数的四则运算
### 加减法
- 按分量加减
### 乘法
- 实乘实减虚乘虚
- 虚乘实加实乘虚
### 除法
- 同乘分母的共轭
- 分母化为 c² + d²
- 分子实部为 ac + bd
- 分子虚部为 bc − ad
### 运算律
- 加减与乘可交换
- 乘法有分配律
- 减法无交换律
### 恒等式
- i² = −1
- i + (−i) = 0
- 0 乘任何复数仍为 0

## 共轭复数
### 定义
- 共轭：z̄ = a − bi
- 实部不变，虚部变号
### 三个公式
- z + z̄ = 2a（实部）
- z − z̄ = 2bi（虚部）
- z · z̄ = |z|²
### 与相反数的区别
- 共轭只变虚部
- 相反数两项都变号

## 复平面的几何意义
### 复平面的建立
- 横轴为实轴
- 纵轴为虚轴
- 点对应复数
### 模与距离
- |z| = √(a² + b²)
- 模恒非负，是到原点的距离
- |z₁ − z₂| 即复平面上两点的距离
### 三个对称
- 关于实轴：取共轭
- 关于虚轴：取负共轭
- 关于原点：取相反数
### 轨迹方程
- |z| = 定值 ⟺ 以原点为心的圆
- 两模相等是线段垂直平分线
- 模的差是双曲线
- 模的和是椭圆
