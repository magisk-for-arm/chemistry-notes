# 数列

## 等差数列
### 定义
- 相邻两项之差为常数
- a(n+1) - a(n) = d
### 公式
- 通项 a(n) = a₁ + (n-1)d
- 和 S(n) = n(a₁ + a(n)) / 2
- 和 S(n) = n[2a₁ + (n-1)d] / 2
- 和的结构 (d/2)n² + (a₁ - d/2)n
- 无常数项
### 常用变形
- a(2n) = a₁ + (2n-1)d
- 奇数项与偶数项各成等差数列
- 奇数项公差 2d
- S(2n) = 2S(n) + n²d
- S(2n+1) = S(2n) + a(2n+1)
### 判型信号
- 常数差
- S(n) 是无常数项的二次式

## 等比数列
### 定义
- 相邻两项之比为常数
- 各项均不为 0
- a(n+1) / a(n) = q
### 公式
- 通项 a(n) = a₁q^(n-1)
- 和 S(n) = a₁(1 - qⁿ) / (1 - q)
- q = 1 时 S(n) = na₁
- 和的结构 a₁/(1-q) - a₁/(1-q)·qⁿ
- 常数项与指数项系数互为相反数
### 常用变形
- a(2n) = a₁q^(2n-1)
- 奇数项与偶数项各成等比数列
- 奇数项公比 q²
- S(2n) = a₁(1+q)(1 + q² + … + q^(2n-2))
### 判型信号
- 常数比
- S(n) 形如 A·Cⁿ + B

## 由 S(n) 求通项
### 相减法
- a₁ = S₁（首项单写）
- a(n) = S(n) - S(n-1)，仅对 n ≥ 2 成立
- 大标减小标得后一项
- S(n+1) - S(n) = a(n+1)
### 指数型要同底数
- S(n) = 3ⁿ - 1 → a(n) = 2·3^(n-1)
- 约掉公因子 q
### 验证
- 把 n = 1 代回通项与 a₁ 比对
- 用 S₂ = a₁ + a₂ 核对
- 把 a(n) 代回求和公式看是否还原
### 分段写的情形
- S(n) 含常数项
- 形式上取 n = 0 不为 0
- 截距非零则首项与通项不一致

## 判型模型
### 通道一：看形式
- 无常数项二次式 → 等差
- A·Cⁿ + B → 等比，公比 C
### 通道二：算比值
- (a(n+1) - a(n)) / a(n)
- 等价于 (S(n+1) - S(n)) / (S(n) - S(n-1))
#### S(n) 为分式根式时用这条
- 分子分母能约掉公因子
### 三项判等差是充分的
- a₂ - a₁ = a₃ - a₂ 即可定案
#### 判等比要多验一项
- 通项唯一确定三项

## 求和武器一：错位相减
### 适用信号
- 等差乘等比
- k·xᵏ
- k·qᵏ
- 2ᵏ
- k²
### 四句口诀
- 原式写一遍
- 加权写一遍
- 上减下成等比
- 末项单独算
### 系数列的形状
- 1, 1, 1, …, 1, -n
#### 末尾 -n·x^(n+1) 最易丢
- 是两行相减的「唯一例外」位
### 通用结论
- Σ k·xᵏ = [x - (n+1)x^(n+1) + nx^(n+2)] / (1-x)²
- x = 2 时 Σ k·2ᵏ = (n-1)·2^(n+1) + 2
### 自检
- 数两遍系数列与幂次列
#### 用 n = 1、n = 2 核对
- 也可套通用式交叉验证

## 求和武器二：裂项相消
### 适用信号
- 分母可裂成 (an+b)(an+b+a)
- 两个因式一次项系数相同
### 通式
- 1/[(an+b)(an+b+a)] = (1/a)(1/(an+b) - 1/(an+b+a))
### 常用实例
- 1/[n(n+1)] = 1/n - 1/(n+1)
- 1/[n(n+2)] = (1/2)(1/n - 1/(n+2))
- 1/[(2n-1)(2n+1)] = (1/2)(1/(2n-1) - 1/(2n+1))
### 求和结果
- Σ 1/[n(n+1)] = N/(N+1)
- Σ 1/[(2n-1)(2n+1)] = N/(2N+1)
### 自检
- 写完立刻通分验系数
- 取 N = 1 代回原式

## 求和武器三：并项分组
### 适用信号
- 题目给 S(2n) 或 S(2n+1)
- 求和式含 (-1)ⁿ
### 等差拆项
- S(2n) = 2S(n) + n²d
- S(2n+1) = S(2n) + a(2n+1)
### 等比拆项
- S(2n) = a₁(1+q)(1 + q² + … + q^(2n-2))
- 括号内公比 q²，共 n 项
### 易错
- 新数列公差是 2d
- 新数列公比是 q²
- 别把 a₁ 漏掉

## 递推与构造
### 一阶线性型
- a(n+1) = p·a(n) + q
- 设 b(n) = a(n) + λ
- λ(p-1) = q
- λ = q / (p-1)
- p = 1 时退化为等差
- 造句：a(n)+λ 成等比数列
### 分式型
- a(n+1) = [p·a(n) + q] / [r·a(n) + s]
- 不动点方程 r·x² + (s-p)x - q = 0
- 两根 α ≠ β
- 造比值 (a(n)-α)/(a(n)-β)
- 公比 (rα-s)/(rβ-s)
### 二阶线性型
- a(n+2) = p·a(n+1) + q·a(n)
- 特征方程 x² - px - q = 0
- 根 α、β
- a(n) = A·α^(n-1) + B·β^(n-1)
- 用 a₁、a₂ 定 A、B
### 统一收尾
- 写出「构造出的数列是等比的」
- 前两项验算
- 代回递推关系检查

## 跨章综合
### 与函数导数
- S(n) 看作关于 n 的函数
- 差分思想
- S(n+1) - S(n) = a(n+1)
- a(n+1) > 0 则 S(n) 增
- a(n+1) < 0 则 S(n) 减
- 求最值要先找转折点
### 与不等式
- 由增减性反推参数范围
- 转折点 a(n+1) = 0
- 整数性要检查最值点是否取到
### 与解析几何
- 交点个数 = 方程根的个数
- 转成关于 a(n) 的方程
### 与极限
- |q| < 1 时 S(n) → a₁/(1-q)
- 0 < q < 1 且 a₁ > 0 时单调趋近上限
- 上限取不到
