## 一、两类基本数列

| | 等差数列 | 等比数列 |
|---|---------|---------|
| **定义** | 任意相邻两项之差为常数 | 任意相邻两项之比为常数（各项均不为 0） |
| **核心特征** | $a_{n+1} - a_n = d$ | $\dfrac{a_{n+1}}{a_n} = q$ |
| **通项** | $a_n = a_1 + (n-1)d$ | $a_n = a_1 q^{n-1}$ |
| **前 $n$ 项和** | $S_n = \dfrac{n\left(a_1 + a_n\right)}{2} = \dfrac{n}{2}\left[2a_1 + (n-1)d\right]$ | $S_n = \dfrac{a_1\left(1 - q^n\right)}{1 - q}\ (q \ne 1)$；$q = 1$ 时 $S_n = na_1$ |
| **和的结构** | $S_n = \dfrac{d}{2}n^2 + \left(a_1 - \dfrac{d}{2}\right)n$（**无常数项**的二次式） | $S_n = \dfrac{a_1}{1-q} - \dfrac{a_1}{1-q}q^n$（一个常数减一个指数式） |
| **常见变形** | $a_{2n} = a_1 + (2n-1)d$，奇偶项各成等差数列 | $a_{2n} = a_1 q^{2n-1}$，奇偶项各成等比数列 |

> **「和的结构」这一行是本知识点最有价值的观察**：$S_n$ 的函数形式直接反读出 $\{a_n\}$ 的类型。$S_n$ 是无常数项的二次式 ⟹ $\{a_n\}$ 等差；$S_n = A - B\cdot C^{\,n}$ 型 ⟹ $\{a_n\}$ 等比。后面所有「由 $S_n$ 判断数列类型」的题都靠这一行。

<Callout type="note" title="三个符号不能混">

$d$ 是**公差**（可以为正、为负、为零）；$q$ 是**公比**（任何实数都可以，但全为 0 的常数列既不是等比也不是需要单独讨论的等差退化情形）。$d = 0$ 的常数列**既是**等差数列，公差为零。

</Callout>

## 二、由前 n 项和求通项：相减法

**核心恒等式**（$n \ge 2$）：

$$
a_n = S_n - S_{n-1}
$$

$$
a_1 = S_1
$$

> **$n \ge 2$ 这个限制是「相减法」唯一的陷阱**。把 $S_n - S_{n-1}$ 写成含 $n$ 的表达式后，它对 $n = 1$ 是否成立，要看 $S_0$ 的形式值是否恰好为 $0$。稳妥做法永远是：**先单独写一行 $a_1 = S_1$，再用相减法处理 $n \ge 2$，最后用 $S_2 = a_1 + a_2$ 验算一次。**

**示例一（$S_n$ 是二次式）**：$S_n = 2n^2 - 3n + 5$。

$$
a_1 = S_1 = 2 - 3 + 5 = 4
$$

$$
a_n = S_n - S_{n-1} = (2n^2 - 3n + 5) - \left[2(n-1)^2 - 3(n-1) + 5\right] = 4n - 5 \quad (n \ge 2)
$$

但把 $n = 1$ 代入 $4n - 5$ 得 $-1 \ne a_1 = 4$。原因正是 $S_0$ 的形式值 $= 5 \ne 0$。所以 $a_1 = 4$，$a_n = 4n - 5\ (n \ge 2)$，**这个数列从第二项起才等差**，不能写成一个统一的通项。

**示例二（$S_n$ 无常数项）**：$S_n = 2n^2 - n$。

$$
a_1 = S_1 = 1,\qquad a_n = 4n - 3 \ (n \ge 2)
$$

此时 $4 \times 1 - 3 = 1 = a_1$ 恰好吻合，说明 $S_0$ 的形式值为 $0$，通项可统一写成 $a_n = 4n - 3$。代入验证：$S_2 = 8 - 2 = 6$，$a_1 + a_2 = 1 + 5 = 6$，成立。

**示例三（$S_n$ 是指数式）**：$S_n = 3^n - 1$。

$$
a_1 = S_1 = 2,\qquad a_n = 3^n - 1 - 3^{n-1} + 1 = 2\cdot 3^{n-1} \ (n \ge 2)
$$

$2 \cdot 3^0 = 2 = a_1$ 吻合，故 $\{a_n\}$ 是等比数列，$a_1 = 2$，$q = 3$。

## 三、由前 n 项和判断数列的类型

给出一个 $S_n$ 的表达式，要回答「$\{a_n\}$ 是等差还是等比」或「求 $q$」，有三条通道。

<Callout type="formula" title="三条判断通道">

**通道一：看 $S_n$ 的函数形式。** 无常数项的二次式 $An^2 + Bn$（$A \ne 0$）⟹ 等差，$d = 2A$；$An^2 + Bn$ 但 $A = 0$ ⟹ 常值数列；形如 $A \cdot C^{\,n} + B$（$A \ne 0$、$C \ne 1$）⟹ 等比，公比就是 $C$。

**通道二：算前几项看规律。** 由 $a_1 = S_1$、$a_2 = S_2 - S_1$、$a_3 = S_3 - S_2$ 算出三项，检查 $a_2 - a_1$ 与 $a_3 - a_2$ 是否相等，或 $\frac{a_3}{a_2}$ 与 $\frac{a_2}{a_1}$ 是否相等。**三项验证对等差是充分的**（若 $a_2-a_1 = a_3-a_2$ 则 $\{a_n\}$ 等差）；对等比则再取 $a_4$ 确认一次。

**通道三：构造比值恒定。** 令 $b_n = S_n - S_{n-1} = a_n$，看

$$
\frac{a_{n+1}}{a_n} = \frac{S_{n+1} - S_n}{S_n - S_{n-1}}
$$

是否为常数。分式型 $S_n$ 题用这条最快，因为分子分母因式分解后常约掉公因子。

</Callout>

**反向应用**（$S_n$ 已知为等差或等比数列的前 $n$ 项和）同样重要：

$$
S_n = \frac{d}{2}n^2 + \left(a_1 - \frac{d}{2}\right)n \quad\Longrightarrow\quad
\begin{cases}
n^2 \text{ 的系数} = \dfrac{d}{2} \\[6pt]
n \text{ 的系数} = a_1 - \dfrac{d}{2}
\end{cases}
$$

由这两个系数**分别**解出 $d$ 与 $a_1$，再看是否自洽。同一结论也可从 $S_{n+1} - S_n = a_{n+1}$ 出发，代入 $S_1 = a_1$ 与 $S_2 = a_1 + a_2$ 联立求解。

## 四、求和的三把武器

前 $n$ 项和除等差等比公式外，另有三种必须掌握的手法。

<Callout type="formula" title="武器一：错位相减法">

适用于「等差（或等比）数列 **乘以** 另一个等比（或等差）数列」的求和。做法：把 $S$ 写一遍，**乘 $q$（或 $d$）后再写一遍**，上下相减让中间一串「同类项」合并成等比（或等差）数列。

$$
\sum_{k=1}^{n} k x^k = \frac{x - (n+1)x^{n+1} + n x^{n+2}}{(1 - x)^2}\quad (x \ne 1)
$$

特例 $x = 2$ 值得背下来：$\displaystyle\sum_{k=1}^{n} k\cdot 2^k = (n-1)\,2^{n+1} + 2$。

</Callout>

**武器一的完整演算**（$\sum_{k=1}^{n} k\cdot 2^k$）：

$$
\begin{aligned}
S &= 1\cdot 2 + 2\cdot 2^2 + 3\cdot 2^3 + \cdots + (n-1)\cdot 2^{n-1} + n\cdot 2^n \\
2S &= 1\cdot 2^2 + 2\cdot 2^3 + 3\cdot 2^4 + \cdots + (n-1)\cdot 2^n + n\cdot 2^{n+1}
\end{aligned}
$$

相减（第一行减第二行）得

$$
-S = 2 + 2^2 + 2^3 + \cdots + 2^n - n\cdot 2^{n+1} = \left(2^{n+1} - 2\right) - n\cdot 2^{n+1}
$$

$$
S = 2 + (n-1)\cdot 2^{n+1}
$$

代 $n = 1$ 验算：$(1-1)\cdot 2^2 + 2 = 2 = 1 \times 2$，成立；代 $n = 3$：$2\cdot 2^4 + 2 = 34$，而 $2 + 8 + 24 = 34$，成立。

<Callout type="formula" title="武器二：裂项相消法">

把一项拆成两项之差，使中间项两两抵消，只剩首尾各一项。

$$
\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}
\qquad
\frac{1}{n(n+2)} = \frac{1}{2}\left(\frac{1}{n} - \frac{1}{n+2}\right)
\qquad
\frac{1}{(2n-1)(2n+1)} = \frac{1}{2}\left(\frac{1}{2n-1} - \frac{1}{2n+1}\right)
$$

通式：$\dfrac{1}{(an+b)(an+b+a)} = \dfrac{1}{a}\left(\dfrac{1}{an+b} - \dfrac{1}{an+b+a}\right)$。

求和结果：

$$
\sum_{n=1}^{N} \frac{1}{n(n+1)} = 1 - \frac{1}{N+1} = \frac{N}{N+1},
\qquad
\sum_{n=1}^{N} \frac{1}{(2n-1)(2n+1)} = \frac{1}{2}\left(1 - \frac{1}{2N+1}\right) = \frac{N}{2N+1}
$$

**每一条裂项式都必须在 $n = 1$ 处代回原式验算一次**——系数漏乘 $\frac12$ 是最高频的算错。

</Callout>

<Callout type="formula" title="武器三：并项分组法">

把数列按「相邻两项配成一组」或「奇偶项配成一组」，让每组的和（或每组的均值）本身构成新数列，再用基本公式求和。

$$
S_{2n} = 2\left(a_1 + a_3 + \cdots + a_{2n-1}\right) + nd = 2S_n + n^2d,\qquad
S_{2n+1} = S_{2n} + a_{2n+1}
$$

**后一个等式 $S_{2n} = 2S_n + n^2d$ 是「隔项求和」的标准结论**，验证：$a_1 = 1$、$d = 2$、$n = 2$ 时 $S_4 = 1+3+5+7 = 16$，而 $2S_2 + 4\cdot 2 = 2\cdot 4 + 8 = 16$，成立；$n = 1$ 时 $2S_1 + d = 2+2 = 4 = a_1 + a_2$，成立。

$$\text{等比型：}\quad S_{2n} = (1 + q) + (q^2 + q^3) + \cdots + (q^{2n-2} + q^{2n-1}) = (1 + q)\left(1 + q^2 + \cdots + q^{2n-2}\right)$$

括号内是公比为 $q^2$ 的等比数列，共 $n$ 项，直接套等比求和公式。**「$S_{2n}$ 拆成 $2$ 倍的奇数项和」是本知识点使用频率最高的一次拆项**，务必手到即用。

</Callout>

## 五、递推数列求通项：构造法

高考递推题几乎全部可以用「**配平**」化成等差或等比。三种类型各有固定配法。

### 1. 一阶线性型：构造等比

$a_{n+1} = pa_n + q$。目标是把它写成 $b_{n+1} = p\,b_n$，其中 $b_n = a_n + \lambda$。展开右边：

$$
p(a_n + \lambda) = pa_n + p\lambda
$$

与 $a_{n+1} + \lambda = pa_n + q + \lambda$ 比较常数项，要求 $p\lambda = q + \lambda$，即

$$
\lambda = \frac{q}{p-1}\quad (p \ne 1)
$$

**示例**：$a_{n+1} = 2a_n + 3$，$a_1 = 1$。$\lambda = \frac{3}{2-1} = 3$，于是 $a_{n+1} + 3 = 2(a_n + 3)$，即 $\{a_n + 3\}$ 是公比为 $2$ 的等比数列。所以

$$
a_n + 3 = (a_1 + 3)\cdot 2^{n-1} = 4\cdot 2^{n-1} \quad\Longrightarrow\quad a_n = 2^{n+1} - 3
$$

验证：$a_1 = 4 - 3 = 1$，成立；$a_2 = 2\cdot 1 + 3 = 5$，而 $2^3 - 3 = 5$，成立；$a_3 = 2\cdot 5 + 3 = 13$，而 $2^4 - 3 = 13$，成立。

> $p = 1$ 时退化为 $a_{n+1} = a_n + q$，即 $a_n = a_1 + (n-1)q$，是等差数列，**不需要配平**。

### 2. 分式型：不动点法

$a_{n+1} = \dfrac{pa_n + q}{ra_n + s}$。令 $x$ 为「不动点」，即 $x = \dfrac{px + q}{rx + s}$，整理得特征方程

$$
r x^2 + (s - p)x - q = 0
$$

设其两根为 $\alpha$ 与 $\beta$（$\alpha \ne \beta$）。则 $a_n - \alpha$ 与 $a_n - \beta$ 都满足同一递推，**相减相除**可得

$$
\frac{a_{n+1} - \alpha}{a_{n+1} - \beta} = \frac{r\alpha - s}{r\beta - s}\cdot \frac{a_n - \alpha}{a_n - \beta}
$$

于是 $\left\{\dfrac{a_n - \alpha}{a_n - \beta}\right\}$ 是等比数列，直接用等比通项与求和。

**示例**：$a_{n+1} = \dfrac{2a_n + 1}{a_n + 2}$，$a_1 = 0$。特征方程 $x^2 + (2-2)x - 1 = 0$，即 $x^2 = 1$，取 $\alpha = 1$、$\beta = -1$，系数 $\frac{r\alpha - s}{r\beta - s} = \frac{1 - 2}{-1 - 2} = \frac13$。令 $b_n = \dfrac{a_n - 1}{a_n + 1}$，则 $b_{n+1} = \frac13 b_n$，$b_1 = \frac{0-1}{0+1} = -1$，故

$$
b_n = -\frac{1}{3^{n-1}} \quad\Longrightarrow\quad a_n = \frac{3^{n-1} - 1}{3^{n-1} + 1}
$$

验证：$a_1 = \frac{1-1}{1+1} = 0$，成立；$a_2 = \frac{2\cdot 0 + 1}{0+2} = \frac12$，而 $\frac{3-1}{3+1} = \frac12$，成立；$a_3 = \frac{2\cdot\frac12 + 1}{\frac12 + 2} = \frac{2}{2.5} = \frac45$，而 $\frac{9-1}{9+1} = \frac45$，成立。

### 3. 二阶线性型：特征根法

$a_{n+2} = p\,a_{n+1} + q\,a_n$。特征方程

$$
x^2 - px - q = 0
$$

设两根为 $\alpha$、$\beta$，则

$$
a_n = A\alpha^{n-1} + B\beta^{n-1}
$$

$A$、$B$ 由 $a_1$、$a_2$ 两个初值解出。**先解特征方程、再用初值定系数**，两步都不可跳。

**示例**：$a_{n+2} = 3a_{n+1} - 2a_n$，$a_1 = 1$，$a_2 = 3$。特征方程 $x^2 - 3x + 2 = 0$，根为 $1$ 与 $2$，故 $a_n = A + B\cdot 2^{n-1}$。由 $a_1 = 1$ 得 $A + B = 1$；由 $a_2 = 3$ 得 $A + 2B = 3$，解得 $B = 2$，$A = -1$，于是 $a_n = 2^n - 1$。验证：$a_3 = 3\cdot 3 - 2\cdot 1 = 7 = 2^3 - 1$，成立；$a_4 = 3\cdot 7 - 2\cdot 3 = 15 = 2^4 - 1$，成立。

## 六、数列与其他章节的综合

数列是高考解答题的**压轴载体**，常见的三条综合路线：

| 综合方向 | 转化动作 | 典型问法 |
|---------|---------|---------|
| **与函数、导数** | 把 $S_n$ 当作关于 $n$ 的函数；$a_{n+1} = S_{n+1} - S_n$ 就是**差分**，对应导数的增量思想 | 求 $S_n$ 的最大值、最小值；求 $S_n$ 的极限 |
| **与不等式** | $a_{n+1} = S_{n+1} - S_n$ 的符号决定 $S_n$ 的增减；等比中 $q - 1$ 决定增减 | $S_n$ 单调递增 / 有最大值，求参数范围 |
| **与解析几何** | 直线与曲线的交点个数 = 关于 $a_n$ 的方程的根的个数 | 由交点个数反推首项、公比的取值范围 |

<Callout type="formula" title="增减性的统一判据">

$$
S_{n+1} - S_n = a_{n+1}
$$

所以 $S_n$ 的增减完全由 $a_{n+1}$ 的符号决定：

- **等差**：$a_{n+1} = a_1 + nd$。$d > 0$ 时 $S_n$ 恒增；$d < 0$ 时看 $a_{n+1}$ 何时变号，转折点即为最小值位置。
- **等比**：$a_{n+1} = a_1 q^n$。$|q| > 1$ 且首项为正时恒增；$0 < q < 1$ 且首项为正时 $S_n$ 有上界（趋于 $\frac{a_1}{1-q}$）但不取到。

**示例**：等差数列 $a_1 = -11$，$d = 2$，求 $S_n$ 的最小值。$a_n = -11 + (n-1)\cdot 2 = 2n - 13$。由 $a_6 = -1 < 0$、$a_7 = 1 > 0$ 知 $S_n$ 先减后增，最小值在 $n = 6$ 处取到：

$$
S_6 = \frac{6\left(a_1 + a_6\right)}{2} = \frac{6(-11 + (-1))}{2} = -36
$$

验证：$S_5 = \frac{5(-11 + (-3))}{2} = -35 > -36$，成立；$S_7 = S_6 + a_7 = -36 + 1 = -35 > -36$，成立。

</Callout>
