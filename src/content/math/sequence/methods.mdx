## 一、相减法：由前 n 项和求通项

<SolutionSteps
  model="相减法解题模型"
  steps={[
    '第一步：单独写一行 a₁ = S₁，作为首项的答案',
    '第二步：用 aₙ = Sₙ - Sₙ₋₁（注明 n ≥ 2）化简。若 Sₙ 是指数式，先把 Sₙ 与 Sₙ₋₁ 写成同底数形式再相减',
    '第三步：把 n = 1 代入第二步的结果，与 a₁ 比对。相等则可统一写成通项，不相等则分段写',
    '第四步：用 S₂ = a₁ + a₂ 验算一次（选验 S₁、S₂ 两项最省时）',
  ]}
  tip="判断能不能统一只看一件事：Sₙ 形式上取 n = 0 是不是 0。含常数项就必须分段写。"
/>

<Callout type="formula" title="两个模型算例">

**例：$S_n = 2n^2 - 3n + 5$。** $a_1 = S_1 = 4$；$a_n = S_n - S_{n-1} = 4n-5\ (n \ge 2)$；代入 $n=1$ 得 $-1 \ne 4$，故分段写。验算 $S_2 = 7$，$a_1+a_2 = 4+3 = 7$，成立。

**例：$S_n = 2n^2 - n$。** $a_1 = S_1 = 1$；$a_n = 4n-3\ (n \ge 2)$；代入 $n=1$ 得 $1 = a_1$，成立，故统一写 $a_n = 4n-3$。验算 $S_3 = 15$，$1+5+9 = 15$，成立。

两式只差一个常数项，结果却从「统一通项」变成「分段」，这就是常数项的全部杀伤力。

</Callout>

## 二、判型模型：由前 n 项和判断等差或等比

<SolutionSteps
  model="S_n 判型模型"
  steps={[
    '第一步：看 Sₙ 的函数形式。无常数项的二次式 An² + Bn（A ≠ 0）→ 等差；A·Cⁿ + B（C ≠ 1）→ 等比，公比就是 C',
    '第二步：形式不明显时，走通道二：算 a₁ = S₁、a₂ = S₂ - S₁、a₃ = S₃ - S₂',
    '第三步：判等差看 a₂ - a₁ = a₃ - a₂ 是否成立（对等差这是充分条件）；判等比看 a₂/a₁ = a₃/a₂ 是否成立，再取 a₄ 确认',
    '第四步：判出类型后写出完整依据（三项等差 / 四项等比），再回答题目所问，不要只写结论',
  ]}
  tip="「三项判等差」是充要的：若 a₂-a₁ = a₃-a₂，则等差数列的通项 aₙ = a₁+(n-1)d 唯一确定，三项一致即锁死。判等比必须多验一项。"
/>

<Callout type="formula" title="从形式直接反读参数">

**等差**：$S_n = \dfrac{d}{2}n^2 + \left(a_1 - \dfrac{d}{2}\right)n$。$n^2$ 系数得 $\dfrac d2$、$n$ 系数得 $a_1 - \dfrac d2$。

**等比**：$S_n = \dfrac{a_1}{1-q} - \dfrac{a_1}{1-q}q^n$。常数项与指数项系数**互为相反数**——这是最快的验算手段：若两个系数的绝对值不相等，就不是等比数列。

</Callout>

## 三、求和武器一：错位相减法

<SolutionSteps
  model="错位相减法模型"
  steps={[
    '第一步：识别信号——一个等差（或等比）数列乘另一个等比（或等差）数列，通项形如 k·xᵏ、k·qᵏ、2ᵏ、k²',
    '第二步：原式写一遍，加权后写一遍（乘 x 或乘 q），使两行的幂次错开一位',
    '第三步：上减下，使系数列变成 1, 1, 1, …, 1, -n 的等比（或等差）数列',
    '第四步：剩下的等比数列用求和公式，末尾的单项 -n·x^(n+1) 单独处理',
    '第五步：数两遍系数列与幂次列，再用 n = 1、n = 2 代回原式核对',
  ]}
  tip="末尾的 -n·x^(n+1) 是唯一「差值不为 1」的位置，抄写时最容易整项丢掉。"
/>

**完整演算**（$\sum_{k=1}^{n} k\cdot 2^k$）：

$$
\begin{aligned}
S &= 1\cdot 2 + 2\cdot 2^2 + 3\cdot 2^3 + \cdots + n\cdot 2^n \\
2S &= 1\cdot 2^2 + 2\cdot 2^3 + 3\cdot 2^4 + \cdots + n\cdot 2^{n+1} \\
-S &= 2 + 2^2 + \cdots + 2^n - n\cdot 2^{n+1} = \left(2^{n+1}-2\right) - n\cdot 2^{n+1} \\
S &= 2 + (n-1)\cdot 2^{n+1}
\end{aligned}
$$

<Callout type="memory" title="错位相减的口诀">

**「原式写一遍，加权写一遍，上减下成等比，末项单独算」**。

四句口诀对应四个动作，缺一句就会算错。最常被省掉的是最后一句——末尾的单项不是等比数列的一部分，必须单独加减。

</Callout>

## 四、求和武器二：裂项相消法

<SolutionSteps
  model="裂项相消法模型"
  steps={[
    '第一步：判断分母能否写成 (an+b)(an+b+a) 的形式——两个因式的一次项系数必须相同',
    '第二步：通分验系数，确定公因子 1/a：1/((an+b)(an+b+a)) = (1/a)·(1/(an+b) - 1/(an+b+a))',
    '第三步：写出前两行与后两行，把相消过程显式写出来（不要跳步），让抵消关系一目了然',
    '第四步：只剩首项与末项，化简成关于 n 的分式',
    '第五步：取 N = 1 代回原式核对（这一步能立刻抓出系数错误）',
  ]}
  tip="裂项式写完必须在 n = 1 处验算一次。漏乘 1/a 是本模型唯一的系统性错误。"
/>

**完整演算**（$\sum_{n=1}^{N}\dfrac{1}{n(n+1)}$ 与 $\sum_{n=1}^{N}\dfrac{1}{(2n-1)(2n+1)}$）：

$$
\sum_{n=1}^{N}\frac{1}{n(n+1)} = \left(1-\frac12\right) + \left(\frac12-\frac13\right) + \cdots + \left(\frac{1}{N}-\frac{1}{N+1}\right) = 1 - \frac{1}{N+1} = \frac{N}{N+1}
$$

$$
\sum_{n=1}^{N}\frac{1}{(2n-1)(2n+1)} = \frac12\left[\left(1-\frac13\right) + \left(\frac13-\frac15\right) + \cdots + \left(\frac{1}{2N-1}-\frac{1}{2N+1}\right)\right] = \frac12\left(1-\frac{1}{2N+1}\right) = \frac{N}{2N+1}
$$

验证：$N = 1$ 时前者 $\frac12$、后者 $\frac13$，与原式 $1/2$、$1/3$ 一致，成立。

## 五、求和武器三：并项分组法

<SolutionSteps
  model="并项分组法模型"
  steps={[
    '第一步：识别信号——题目给的是 S₂ₙ、S₂ₙ₊₁，或者求和式含 (-1)ⁿ、分母带 aₙ 的分式',
    '第二步：拆项。等差用 S₂ₙ = 2Sₙ + n²d；等比用 S₂ₙ = (1+q)(1+q²+…+q²ⁿ⁻²) 再乘 a₁',
    '第三步：对拆出的新数列用等差或等比公式求和（注意新数列的公差是 2d、公比是 q²）',
    '第四步：需要奇数项个数时再用 S₂ₙ₊₁ = S₂ₙ + a₂ₙ₊₁ 补一项',
  ]}
  tip="新数列的公差是 2d、公比是 q²，这一步最容易写成 d 和 q。"
/>

**完整演算**（等比数列求 $S_{2n}$）：

$$
S_{2n} = (a_1 + a_2) + (a_3 + a_4) + \cdots + (a_{2n-1} + a_{2n})
$$

$$
= a_1(1+q) + a_1q^2(1+q) + \cdots + a_1q^{2n-2}(1+q) = a_1(1+q)\left(1 + q^2 + q^4 + \cdots + q^{2n-2}\right)
$$

括号内是**首项 1、公比 $q^2$、共 $n$ 项**的等比数列，所以

$$
S_{2n} = a_1(1+q)\cdot\frac{1 - q^{2n}}{1 - q^2}\quad (q^2 \ne 1)
$$

验证 $a_1 = 1$、$q = 2$、$n = 1$：$(1+2)\cdot\frac{1-4}{1-4} = 3$，而 $S_2 = 1 + 2 = 3$，成立。验证 $n = 2$：$(1+2)(1+4) = 15$，而 $S_4 = 1+2+4+8 = 15$，成立。

**等差数列的对应结论**（同样常考）：

$$
S_{2n} = 2S_n + n^2 d,\qquad S_{2n+1} = S_{2n} + a_{2n+1} = 2S_n + n^2d + a_1 + 2nd
$$

验证 $a_1 = 1$、$d = 2$、$n = 2$：$S_4 = 2\cdot 4 + 4\cdot 2 = 16$（$1+3+5+7 = 16$）；$S_5 = 2\cdot 4 + 8 + 1 + 8 = 25$（$1+3+5+7+9 = 25$）；$n = 1$ 时 $S_2 = 2\cdot 1 + 2 = 4$，成立，$S_3 = 2 + 2 + 1 + 4 = 9$，成立。

## 六、递推数列的构造模型

<SolutionSteps
  model="递推配平模型"
  steps={[
    '第一步：分类。看递推右边是「纯倍数」（直接等比）、「倍数 + 常数」（构造等比）、「分式」（不动点）还是「二阶」（特征根）',
    '第二步：一阶型设 bₙ = aₙ + λ，展开比较常数项解出 λ(p-1) = q；同时写一句「p = 1 时另行讨论」',
    '第三步：分式型解不动点方程 r·x² + (s-p)x - q = 0 取两根 α、β，构造 (aₙ-α)/(aₙ-β)',
    '第四步：二阶型解特征方程 x² - px - q = 0 写 aₙ = Aα^(n-1) + Bβ^(n-1)，用 a₁、a₂ 定 A、B',
    '第五步：用前两项验算通项，并把递推关系代入检查一遍',
  ]}
  tip="不管哪一型，都要先写出「构造出来的数列是等比的」这句话，它是通向等比公式的桥。"
/>

<Callout type="formula" title="三个算例（含验算）">

**一阶型**：$a_{n+1} = 2a_n + 3$，$a_1 = 1$。$\lambda = \frac{3}{1} = 3$，$a_{n+1}+3 = 2(a_n+3)$，故 $a_n + 3 = 4\cdot 2^{n-1}$，$a_n = 2^{n+1}-3$。验 $a_2 = 5 = 2^3-3$，成立，$a_3 = 13 = 2^4-3$，成立。

**分式型**：$a_{n+1} = \frac{2a_n+1}{a_n+2}$，$a_1 = 0$。不动点方程 $x^2 - 1 = 0$，取 $\alpha = 1$、$\beta = -1$，系数 $\frac{r\alpha-s}{r\beta-s} = \frac{-1}{-3} = \frac13$。故 $\left\{\frac{a_n-1}{a_n+1}\right\}$ 是公比 $\frac13$、首项 $-1$ 的等比数列，$\frac{a_n-1}{a_n+1} = -\frac{1}{3^{n-1}}$，解得 $a_n = \frac{3^{n-1}-1}{3^{n-1}+1}$。验 $a_2 = \frac{2\cdot 0+1}{0+2} = \frac12 = \frac{3-1}{3+1}$，成立，$a_3 = \frac{2}{2.5} = \frac45 = \frac{9-1}{9+1}$，成立。

**二阶型**：$a_{n+2} = 3a_{n+1} - 2a_n$，$a_1 = 1$，$a_2 = 3$。特征方程 $x^2-3x+2=0$，根 $1$ 与 $2$。$a_n = A + B\cdot 2^{n-1}$，由 $A+B = 1$、$A+2B = 3$ 得 $B = 2$、$A = -1$，$a_n = 2^n - 1$。验 $a_3 = 7 = 2^3-1$，成立，$a_4 = 15 = 2^4-1$，成立。

</Callout>

## 七、检查清单（交卷前 30 秒）

<SolutionSteps
  model="数列检查清单"
  steps={[
    '判型：题目给的是等差还是等比？公差 d 与公比 q 有没有用反？（草稿上应写明「等差」或「等比」）',
    '公比：q 是否可能等于 1？含参求 q 时，全部根是否都代回原方程验算过？',
    '首项：由 Sₙ 求 aₙ 时，a₁ = S₁ 是否单独写了？相减式是否注明 n ≥ 2？n = 1 代回后通项与首项一致吗？',
    '下标：出现的 a₂ₙ、a₂ₙ₋₁、S₂ₙ₊₁ 代入时，下标是否整体替换了？（最易错是求 a₂ₙ 时仍写 Sₙ）',
    '求和公式：等差求和用 (n-1)d 还是 nd？与首末项平均式互验过吗？',
    '求和手法：错位相减后系数列与幂次列数过了吗？裂项后取首项验算系数了吗？',
    '分组：新数列的公差是 2d、公比是 q²，写对了吗？',
    '递推：配平量 λ（或不动点、特征根）解出来了吗？构造出的数列是等比这一点写出来了吗？',
    '结果验证：把通项代回原递推关系试一次；把 a(n) 逐项相加看是否还原出 S(n)；填空题用 n = 1 检验。',
  ]}
  tip="前三条管住概念与公式，中间三条管住求和运算，后三条管住递推与最终验证。"
/>

<Callout type="memory" title="口诀速记">

1. **相减法只管 $n \ge 2$，首项单写一行**：$a_1 = S_1$，$a_n = S_n - S_{n-1}$。
2. **大标减小标得后一项**：$S_{n+1} - S_n = a_{n+1}$。
3. **S 无常数项才等差**：含常数项时通项与首项不一致，必须分段写。
4. **公比等于 1 要单讨论**：$q = 1$ 时 $S_n = na_1$。
5. **解 q 必解全根**：二次方程两根都要，外加验 $q = 1$。
6. **错位相减数两遍**：系数列与幂次列各念一遍，再用小 $n$ 验算。
7. **裂项必验首项**：通分定系数 $1/a$，取 $n = 1$ 代回。
8. **奇项之和乘二**：$S_{2n} = 2(a_1 + a_3 + \cdots + a_{2n-1})$；$S_{2n+1} = S_{2n} + a_{2n+1}$。
9. **分组后公差 2d、公比 q²**：新数列的参数别忘了改。
10. **增减看 a(n+1)**：$S_{n+1} - S_n = a_{n+1}$，正增负减。

</Callout>
