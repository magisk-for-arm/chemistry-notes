## 一、铝单质：两性与铝热

银白色轻金属，密度小、熔点低；常温与氧气成致密氧化膜（**铝制品耐腐蚀的原因**）。四条主线：

<Callout type="formula" title="铝的化学性质四线">

- 与非金属：$4\ce{Al + 3O2 ->[\text{点燃}] 2Al2O3}$（加热时熔化不滴落——**氧化膜「托着」**，因 $\ce{Al2O3}$ 熔点远高于 $\ce{Al}$）；$\ce{S}$ 化 $\ce{Al2S3}$（唯一由单质直接化合且**只能干法制**的铝硫化物，水溶液中双水解不存在）；
- 与酸：非氧化性酸 $2\ce{Al + 6H+ = 2Al^3+ + 3H2 ^}$；**冷浓硫酸/浓硝酸中钝化**（与铁同款，故可用铝槽车运冷浓硫酸）；
- 与强碱：$2\ce{Al + 2OH- + 6H2O = 2[Al(OH)4]- + 3H2 ^}$（简写 $\ce{2Al + 2OH- + 2H2O = 2AlO2- + 3H2 ^}$）——氧化膜与产物膜都被碱溶掉，反应持续推进；铝**只与强碱溶液**反应，氨水不行；
- 铝热反应：$2\ce{Al + Fe2O3 ->[\text{高温}] Al2O3 + 2Fe}$，放热极烈、熔融铁流出——**焊接钢轨**、冶炼 $\ce{V}$、$\ce{Cr}$、$\ce{Mn}$ 等高熔点金属。

</Callout>

工业制铝：电解熔融氧化铝（冰晶石 $\ce{Na3AlF6}$ 作熔剂降熔点）：$2\ce{Al2O3(熔融) ->[电解][冰晶石] 4Al + 3O2 ^}$。

## 二、一张图看「铝三角」

$\ce{Al^3+}$、$\ce{[Al(OH)4]-}$（旧教材写作 $\ce{AlO2-}$）、$\ce{Al(OH)3}$ 三者两两转化：

<Callout type="memory" title="铝三角六条边（以 [Al(OH)₄]⁻ 为准）">

- $\ce{Al^3+ ->[少量碱] Al(OH)3 v ->[过量碱] [Al(OH)4]-}$；
- $\ce{[Al(OH)4]- ->[少量酸] Al(OH)3 v ->[过量酸] Al^3+}$；
- 对角线互促：$\ce{Al^3+ + 3[Al(OH)4]- = 4Al(OH)3 v}$（双水解归中，后面详细展开）；
- $\ce{Al2O3}$ 两头都能溶（两性氧化物），但**不能一步变 $\ce{Al(OH)3}$**（不溶于水，无对应水化通道）。

</Callout>

$\ce{Al(OH)3}$ 的两性电离：酸式 $\ce{Al(OH)3 + H2O <=> [Al(OH)4]- + H+}$、碱式 $\ce{Al(OH)3 <=> Al^3+ + 3OH-}$——两头都有出路，故强酸强碱通杀；受热分解 $2\ce{Al(OH)3 ->[\Delta] Al2O3 + 3H2O}$。

## 三、与碱/与酸的互滴与图像

<Callout type="formula" title="四种滴加、四段现象">

1. **$\ce{NaOH}$ 滴入 $\ce{AlCl3}$**：先白色沉淀增多（$\ce{Al^3+ + 3OH- -> Al(OH)3}$），后沉淀溶解殆尽（耗碱比 $3:1$）；
2. **$\ce{AlCl3}$ 滴入 $\ce{NaOH}$**：开始无沉淀（落点处碱过量，直接成 $\ce{[Al(OH)4]-}$），碱耗尽后突然出现白色沉淀并**不消失**（$\ce{Al^3+ + 3[Al(OH)4]- -> 4Al(OH)3 v}$）；
3. **盐酸滴入 $\ce{Na[Al(OH)4]}$ 液**：先沉淀后溶解（耗酸比 $1:3$）；
4. **$\ce{Na[Al(OH)4]}$ 滴入盐酸**：先无沉淀后生沉淀不消失。

图像题按「转折点消耗量之比 $3:1$（或 $1:3$）」核对，即得原液浓度关系。

</Callout>

- $\ce{Al^3+}$ + 氨水：$\ce{Al^3+ + 3NH3\cdot H2O = Al(OH)3 v + 3NH4+}$，**沉淀不溶于过量氨水**——制 $\ce{Al(OH)3}$ 的首选；
- $\ce{[Al(OH)4]-}$ 通 $\ce{CO2}$：$\ce{[Al(OH)4]- + CO2(足量) = Al(OH)3 v + HCO3-}$（酸式碳酸根收尾，与 $\ce{CO2}$ 量**无关**也写 $\ce{HCO3-}$ 是命题热点；少量 $\ce{CO2}$ 写 $\ce{CO3^2-}$ 亦对）；
- 双水解全家福（共存题）：$\ce{Al^3+}$ 与 $\ce{HCO3-/CO3^2-/AlO2-型/S^2-/ClO-/SiO3^2-}$、$\ce{[Al(OH)4]-}$ 与 $\ce{Al^3+/NH4+/Fe^3+}$ 均不能大量共存。

## 四、明矾与氢氧化铝的用途

明矾 $\ce{KAl(SO4)2\cdot 12H2O}$ 净水：$\ce{Al^3+}$ 水解成 $\ce{Al(OH)3}$ 胶体**吸附悬浮物**（不杀菌，与高铁酸钾、氯气不同档）；$\ce{Al(OH)3}$：胃酸剂（$\ce{Al(OH)3 + 3H+}$，比 $\ce{NaHCO3}$ 温和不产气不穿孔）、阻燃剂（分解吸热 + 出水汽）。

## 五、链接板块：镁及其化合物

镁银白色轻金属，三条线索：

- 与 $\ce{O2}$ 剧烈燃烧发**耀眼白光**（照明弹）：$2\ce{Mg + O2 ->[\text{点燃}] 2MgO}$；**能在 $\ce{CO2}$ 中燃烧**：$2\ce{Mg + CO2 ->[\text{点燃}] 2MgO + C}$（镁着火**禁用 $\ce{CO2}$ 灭火器**！）；也能在 $\ce{N2}$ 中燃烧成 $\ce{Mg3N2}$；
- 与水：冷水极缓（$\ce{Mg(HCO3)2}$ 型暂时硬水垢的成因），热水明显：$\ce{Mg + 2H2O ->[\Delta] Mg(OH)2 + H2 ^}$，滴酚酞变红；
- 特殊本领：$\ce{Mg}$ 能与 $\ce{NaHCO3}$ 溶液反应放出氢气与 $\ce{CO2}$（多数金属不能）。

化合物：$\ce{MgO}$ 高熔点耐火材料；$\ce{Mg(OH)2}$ 中强碱、**溶解度比 $\ce{MgCO3}$ 更小**——水垢里的镁以 $\ce{Mg(OH)2}$ 存在、锅炉除垢转化原理所在。

海水提镁六步（流程题常客）：贝壳烧 $\ce{CaCO3 -> CaO -> Ca(OH)2}$ → 沉淀 $\ce{Mg^2+}$ → 盐酸溶 $\ce{Mg(OH)2}$ → 蒸发结晶得 $\ce{MgCl2\cdot 6H2O}$ → **$\ce{HCl}$ 气流中脱水**（防 $\ce{MgCl2}$ 水解，与 $\ce{FeCl3}$ 同款考点）→ 电解熔融：$\ce{MgCl2(熔融) ->[电解] Mg + Cl2 ^}$（**不电解 $\ce{MgO}$**：熔点太高耗能大）。

## 六、金属冶炼：活动性决定方法

<Callout type="formula" title="三板斧对号入座">

- **电解法**（$\ce{K}$、$\ce{Ca}$、$\ce{Na}$、$\ce{Mg}$、$\ce{Al}$）：熔融氯化物或氧化物；
- **热还原法**（$\ce{Zn}$~$\ce{Cu}$）：$\ce{C}$/$\ce{CO}$/$\ce{H2}$/$\ce{Al}$ 当还原剂——高炉炼铁 $3\ce{CO + Fe2O3 ->[\text{高温}] 2Fe + 3CO2}$、焦炭还原氧化铜、铝热法；
- **热分解法**（$\ce{Hg}$、$\ce{Ag}$）：$2\ce{HgO ->[\Delta] 2Hg + O2 ^}$；
- 补充：湿法炼铜 $\ce{Fe + CuSO4 = Cu + FeSO4}$（曾青得铁则化为铜）、富集法（物理淘洗 $\ce{Pt}$、$\ce{Au}$）。

</Callout>

规律一句话：金属活动性越强，冶炼越费电、开发年代越晚（铜器早于铁器早于铝器）。
