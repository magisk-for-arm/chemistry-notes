## 考情速览

铝是元素化合物与图像计算的**交汇主战场**：$Al^{3+}$ 与 $OH^-$ / $H^+$ / $AlO_2^-$ 的「量决定产物」题几乎年年出现；铝镁合金常作计算情境（与酸反应放氢的双守恒）；海水提镁、铝土矿提铝是流程题两大模板；金属冶炼方法与活动性表的搭配是选择题常客。

## 考点一：铝三角与量判断

<Callout type="formula" title="三物种六边转化一句话版">

$\ce{Al^3+}$（加碱走一格到 $\ce{Al(OH)3}$、走两格到 $\ce{[Al(OH)4]-}$）、$\ce{[Al(OH)4]-}$（加酸回退）、「$\ce{Al^3+}$ 遇 $\ce{[Al(OH)4]-}$ 中途相撞生成 $\ce{Al(OH)3}$」。**量决定停在哪一格**——「少量/过量」四个字的翻译题。

</Callout>

高频判断集：$\ce{Al}$ 与酸碱「等量放氢相同」（$2\ce{Al}\sim 3\ce{H2}$）；$\ce{AlCl3}$ 溶液中滴氨水与滴 $\ce{NaOH}$ 现象**不同**（后者有溶解段）；$\ce{[Al(OH)4]-}$、$\ce{Al^3+}$ 都不能与对方共存（归中沉淀）。

## 考点二：Al(OH)₃ 制备路线评价（绿色化学视角）

三条路线，原料相同产物相同，**评价维度是酸/碱耗量与操作难度**：

| 路线 | 步骤 | 耗酸碱（均按制 $4\ \mathrm{mol}\ \ce{Al(OH)3}$ 计） |
| --- | --- | --- |
| 甲：铝 → $\ce{Al^3+}$ → 氨水 | 酸溶 + 弱碱沉 | $12\ \mathrm{mol}\ \ce{H+}$ + 足量氨水（不溶不化易操作） |
| 乙：铝 → $\ce{[Al(OH)4]-}$ → 通 $\ce{CO2}$ | 碱溶 + 气沉 | $4\ \mathrm{mol}\ \ce{OH-}$ + 任意量 $\ce{CO2}$（过量不重溶） |
| 丙：铝分两份，$\ce{Al^3+}$ 与 $\ce{[Al(OH)4]-}$ 混合 | 归中沉淀 | 制 $4\ \mathrm{mol}$ 沉淀仅耗 $3\ \mathrm{mol}\ \ce{H+}$ + $1\ \mathrm{mol}\ \ce{OH-}$，**最省**（高考最优答案） |

最优解「丙」：铝按 **1∶3** 分份，一份走酸、三份走碱再混合（$\ce{Al^3+ + 3[Al(OH)4]- = 4Al(OH)3 v}$），酸碱耗量双低且沉淀一步到位、无需控制量。

## 考点四：铝镁及合金——双守恒计算母题

<Callout type="memory" title="合金题只有两条方程">

质量守恒：$27n(\ce{Al}) + 24n(\ce{Mg}) = m$；电子守恒：$3n(\ce{Al}) + 2n(\ce{Mg}) = 2n(\ce{H2})$（或与硝酸等其他氧化剂的得电子量匹配）。两式联立解二元，「与足量酸/碱」的措辞决定谁是限制者。追加问「最多需 $\ce{NaOH}$」时：终点沉淀量最大，$n(\ce{NaOH}) = 3n(\ce{Al^3+}) + 2n(\ce{Mg^2+})$，铝若转 $\ce{[Al(OH)4]-}$ 再加 $n(\ce{Al})$——问清楚终态再动笔。

</Callout>

## 考点五：金属冶炼与开发

活动性顺序从上往下读方法：$\ce{K Ca Na Mg Al}$ **电解**（熔融）、$\ce{Zn Fe Sn Pb Cu}$ **热还原**（$\ce{C/CO/H2/Al}$）、$\ce{Hg Ag}$ **热分解**、$\ce{Pt Au}$ **物理富集**。细节考法：电解法炼 $\ce{Mg}$、$\ce{Al}$ 用**氯化物/氧化物熔融**（$\ce{AlCl3}$ 共价分子不导电，不能电解它炼铝——高频判断）；铝热剂是混合物不是化合物；冶炼史与活动性负相关。
