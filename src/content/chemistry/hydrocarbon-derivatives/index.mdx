## 一、总览：一个碳骨架，换一副官能团

按官能团分类：卤代烃（$\ce{-X}$）、醇（$-\ce{OH}$ 连脂肪碳）、酚（$-\ce{OH}$ **直接**连苯环）、醛（$\ce{-CHO}$）、酮（羰基居链中）、羧酸（$\ce{-COOH}$）、酯（$\ce{-COOR}$）、胺与酰胺、油脂（高级脂肪酸甘油酯）。转化主线一条：

$$\ce{CH2=CH2 ->[HBr] CH3CH2Br ->[NaOH 水] CH3CH2OH ->[Cu,\Delta] CH3CHO ->[O] CH3COOH ->[+C2H5OH] CH3COOC2H5}$$

分子式相同的醇与醚互为异构体（$\ce{C_nH_{2n+2}O}$ 可能是醇也可能是醚），$\ce{C3H8O}$、$\ce{C4H10O}$ 不一定同属同系物——数异构体时先分官能团类别再排碳链。

## 二、卤代烃：水解与消去两条路

$\ce{C-X}$ 键极性强（$\ce{C^{\delta+}-Br^{\delta-}}$）、易断裂，但卤素以**共价键**结合、不电离出 $\ce{X-}$——一切卤素检验都要先把它「拆下来」。

<Callout type="formula" title="水解 vs 消去：一字之差看溶剂">

- **水解（取代）**：$\ce{NaOH}$ **水**溶液、加热 → 醇：$\ce{CH3CH2Br + NaOH ->[H2O][\Delta] CH3CH2OH + NaBr}$
- **消去**：$\ce{NaOH}$ **醇**溶液、加热 → 烯：$\ce{CH3CH2Br + NaOH ->[乙醇][\Delta] CH2=CH2 ^ + NaBr + H2O}$

消去资格三查：①至少 2 个碳；②**β-碳（卤素所在碳的邻位碳）上有 H**；③卤素**直接连苯环的不能消去**（氯苯消不去）。2-氯丁烷两个邻位都有 H，消去得 1-丁烯与 2-丁烯混合物。二元卤代烃两次消去可引入三键：$\ce{CH3CCl2CH3 + 2NaOH ->[醇][\Delta] CH3C#CH + 2NaCl + 2H2O}$（原文源料反应物碳数对不上，已订正重写）。

</Callout>

**溴乙烷中溴元素的检验三步**：加 $\ce{NaOH}$ 溶液共热 → 冷却后加**过量稀硝酸**酸化 → 滴 $\ce{AgNO3}$ 溶液，淡黄色沉淀 $\ce{AgBr}$ 为证。漏掉酸化一步，$\ce{Ag+ + OH-}$ 生成的 $\ce{AgOH -> Ag2O}$（褐色）会毁掉整实验。沉淀色卡：$\ce{AgCl}$ 白、$\ce{AgBr}$ 浅黄、$\ce{AgI}$ 黄。

物性备忘：标况下 $\ce{CH3Cl}$、$\ce{CH3CH2Cl}$、$\ce{CH2=CHCl}$ 为气体，其余多为液体；不溶于水，密度一般**大于水**（脂肪烃一氟/一氯代物除外）。$\ce{CHCl3}$（氯仿，曾被用作麻醉剂，见光被空气氧化生成剧毒光气）、$\ce{CCl4}$（萃取剂）、氟利昂（臭氧层空洞元凶）。

## 三、醇：羟基五反应，断键位置定产物

物性三条（都是氢键的账）：相对分子质量相近的醇沸点**远高于**烷烃；羟基数越多沸点越高（丙三醇＞丙二醇＞丙醇＞乙醇＞丙烷）；低级醇与水任意比互溶（羟基亲水、烷基憎水，碳数↑溶解度↓）。甲醇 $\ce{CH3OH}$（原源料误作 $\ce{CHOH}$）有毒伤视神经；乙二醇做防冻液、合成涤纶；丙三醇吸水护肤。

<Callout type="formula" title="乙醇的五本账（按断键记）">

编号：① $\ce{O-H}$、② $\ce{C-O}$、③ α-C 上的 $\ce{C-H}$、⑤ β-C 上的 $\ce{C-H}$。

| 反应 | 条件 | 断键 | 产物记忆点 |
| --- | --- | --- | --- |
| 与 Na 置换 | 常温 | ① | $\ce{2CH3CH2OH + 2Na -> 2CH3CH2ONa + H2 ^}$，比水缓和（烷基推电子） |
| 与 HX 取代 | 浓氢卤酸 | ② | $\ce{CH3CH2OH + HBr -> CH3CH2Br + H2O}$ |
| 催化氧化 | Cu/Ag、△ | ①③ | 见「α-H 资格」框 |
| 消去 | 浓硫酸、170 ℃ | ②⑤ | 乙烯；先通 NaOH 洗气再检验 |
| 分子间脱水 | 浓硫酸、140 ℃ | ①② | 乙醚 $\ce{C2H5-O-C2H5}$（醚 $\ce{R-O-R'}$） |
| 酯化 | 浓硫酸、△ | ① | 酸脱羟基醇脱氢（$^{18}\ce{O}$ 示踪证实） |

</Callout>

**催化氧化看 α-H**：与 $-\ce{OH}$ 相连的碳上必须有 H——伯醇→醛、仲醇→酮、**叔醇（如叔丁醇）无 α-H 不被催化氧化**。铜丝实验「变黑（$\ce{CuO}$）—插乙醇变红（还原为 Cu）、有刺激性气味」，两步方程式合起来看铜是催化剂。强氧化剂（酸性 $\ce{KMnO4}$、酸性 $\ce{K2Cr2O7}$）则直接氧化成乙酸；重铬酸钾**橙变绿**是查酒驾原理。

**消去实验要点**：浓硫酸与乙醇按体积 3∶1 混合（**酸加入醇**）、碎瓷片防暴沸、**迅速升至 170 ℃**（140 ℃ 走成醚副反应）；气体先过 NaOH 溶液除 $\ce{SO2}$、$\ce{CO2}$ 与乙醇蒸气（三者都能搅局褪色检验）再通 $\ce{KMnO4}$/溴的四氯化碳。

**酯化实验要点**：加药序**乙醇 → 浓硫酸 → 乙酸**（原源料文字与口诀自相矛盾，按规范序订正）；浓硫酸催化+吸水（促平衡正移）；导管**悬于饱和 $\ce{Na2CO3}$ 液面上方**防倒吸；饱和碳酸钠三作用——吸收乙醇、中和乙酸、降低酯的溶解度。

## 四、酚：弱酸、取代、显色，环与羟基互相「捎话」

苯酚无色晶体（熔点 43 ℃）、特殊气味、有毒腐蚀皮肤（沾肤**先酒精洗再水洗**）；常温水中溶解度小、**65 ℃ 以上与水互溶**；久置粉红是被空气氧化。结构：至少 12 个原子共面、最多 13。

- **弱酸性**（俗称石炭酸）：酸性太弱**不能使指示剂变色**；与 NaOH 浑浊变清；苯酚钠溶液通 $\ce{CO2}$ 又变浑：$\ce{C6H5ONa + CO2 + H2O -> C6H5OH + NaHCO3}$——**无论 $\ce{CO2}$ 过量与否都生成 $\ce{NaHCO3}$**（酸性：碳酸＞苯酚＞$\ce{HCO3^-}$）。
- **取代**：浓溴水**不需催化剂**即生成 2,4,6-三溴苯酚白色沉淀：$\ce{C6H5OH + 3Br2 -> C6H2Br3OH v + 3HBr}$，灵敏到可定量——但**不能用来除苯中的苯酚**（三溴苯酚与溴都溶于苯）。羟基活化苯环邻对位（对比苯的溴代要液溴+FeBr₃ 且一取代）。

<ChemStructure smiles="Oc1c(Br)cc(Br)cc1Br" caption="2,4,6-三溴苯酚：羟基的邻位与对位氢全部被溴取代，析出白色沉淀" alt="2,4,6-三溴苯酚的结构式，苯环上羟基的邻位和对位各连一个溴原子" height="150px" />
- **显色**：滴 $\ce{FeCl3}$ 溶液显紫色（$\ce{6C6H5OH + Fe^3+ -> [Fe(OC6H5)6]^3- + 6H+}$），酚类的身份证。
- 氧化与加成：使酸性 $\ce{KMnO4}$ 褪色；与 $\ce{H2}$ 1∶3 加成得环己醇。

## 五、醛与酮：两大特征氧化与两路加成增长

甲醛是唯一气态醛（35%~40% 水溶液即福尔马林）；乙醛无色刺激性液体、沸点 20.8 ℃（原源料小节标题误写「乙醇的物理性质」，实讲乙醛）。饱和一元醛通式 $\ce{C_nH_{2n}O}$（$n\ge1$）；饱和一元酮同通式但 **$n\ge3$**（丙酮恰为 C₃，原源料误写 $n>3$）；同碳数醛酮互为异构体，酮羰基居链中、**不被银氨溶液与新制氢氧化铜氧化**。

<Callout type="formula" title="银镜反应与新制 Cu(OH)₂">

- 银镜：$\ce{AgNO3}$ 中**逐滴**加稀氨水至沉淀**恰好溶解**得 $\ce{[Ag(NH3)2]OH}$；滴 3 滴乙醛、**水浴**加热：$\ce{CH3CHO + 2[Ag(NH3)2]OH ->[\Delta] CH3COONH4 + 2Ag v + 3NH3 + H2O}$（记忆：水银铵「1、2、3」，再加一个羧酸铵）。注意五条：试管洁净、银氨液现配、水浴不直火、醛勿过量、银镜用稀硝酸洗去。
- 新制 $\ce{Cu(OH)2}$：$\ce{CuSO4 + 2NaOH = Cu(OH)2 v + Na2SO4}$（**NaOH 必须过量**），加醛**加热至沸腾**：$\ce{CH3CHO + 2Cu(OH)2 + NaOH ->[\Delta] CH3COONa + Cu2O v + 3H2O}$，蓝色→**砖红色**；久沸会出黑色 CuO。斐林试剂检葡萄糖同此。
- 能发生银镜的不止醛类：**甲酸、甲酸酯、葡萄糖等还原糖**都含「隐形醛基」。

</Callout>

**甲醛的特殊账**：$\ce{HCHO}$ 氧化产物甲酸仍含醛基、可再银镜一次——**1 mol 甲醛 ~ 4 mol Ag**（$\ce{HCHO + 4[Ag(NH3)2]OH ->[\Delta] (NH4)2CO3 + 2H2O + 4Ag v + 6NH3}$），与新制 $\ce{Cu(OH)2}$ 同样 1∶4 得 $\ce{Na2CO3}$。

加成两路：催化加氢（$\ce{CH3CHO + H2 ->[催化剂][\Delta] CH3CH2OH}$，醛加氢必得**伯醇**——原源料「端醇」订正；加氢即还原）；$\ce{HCN}$ 加成氰醇**碳链 +1**。含 α-H 的醛还能**羟醛缩合**：$\ce{2CH3CHO ->[稀碱][\Delta] CH3CH(OH)CH2CHO}$，碳链倍增的常用增长手段。

## 六、羧酸与酯：酸性账、水解账、异构账

羧酸显酸性（$\ce{O-H}$ 断裂电离出 $\ce{H+}$）、衍生物生成走 $\ce{C-O}$ 断（酯化、成酰胺）。能使紫色石蕊变红（原源料「紫红色石蕊试纸变红」表述已订正）、与活泼金属/碱性氧化物/碱/碳酸盐反应。

<Callout type="formula" title="酸性排队与三装置实验">

酸性序：**乙二酸＞甲酸＞苯甲酸＞乙酸＞丙酸＞碳酸＞苯酚＞$\ce{HCO3^-}$**。

比较实验一条龙：A（乙酸滴入 $\ce{Na2CO3}$，冒气泡：乙酸＞碳酸）→ B（**饱和 $\ce{NaHCO3}$ 溶液**除去 $\ce{CO2}$ 里混的乙酸蒸气，防干扰）→ C（气体通苯酚钠溶液变浑：碳酸＞苯酚）。缺 B 则整条链作废。

甲酸 HCOOH 一手两官能团：既有 $-\ce{COOH}$ 的酸性、又有「隐形 $-\ce{CHO}$」——能银镜、能被 $\ce{KMnO4}$ 氧化（工业还原剂、消毒剂）；草酸（乙二酸）是分析化学常用还原剂，其钙盐 $\ce{CaC2O4}$ 是结石主成分；苯甲酸（安息香酸）易升华、钠盐作食品防腐剂。
</Callout>

酯 $\ce{RCOOR'}$（$\ce{R'}$ 不能是 H）：低级酯香、果香来源，难溶于水密度小于水。水解两式对照——**酸催化写可逆、碱直写到底**：

$$\ce{RCOOR' + H2O <=>[稀硫酸][\Delta] RCOOH + R'OH} \qquad \ce{RCOOR' + NaOH ->[\Delta] RCOONa + R'OH}$$

碱性水解因 NaOH 中和生成的酸、平衡彻底正移；酯在碱性溶液中的水解即**皂化**（见油脂）。

**$\ce{C_nH_{2n}O_2}$ 异构账（已核算，仅羧酸、酯、羟基醛三类）**：$\ce{C4H8O2}$ 三类共 **11 种** = 酸 2（丙基 2 式）+ 酯 4（甲酸丙酯 2、乙酸乙酯 1、丙酸甲酯 1）+ 羟基醛 5；$\ce{C5H_{10}O2}$ 三类共 **25 种** = 酸 4（丁基 4 式）+ 酯 9（甲酸丁酯 4、乙酸丙酯 2、丙酸乙酯 1、丁酸甲酯 2）+ 羟基醛 12（此外还有羟基酮、醚醛/醚酮、环状缩醛等类别，题面需限定类别才取数）。按性质再切一遍：$\ce{C5H10O2}$ 中能耗 NaOH 的 4+9=13 种，能银镜的 12+4=16 种（羟基醛+甲酸酯）。

羧酸的两条「非常规」反应：$\ce{LiAlH4}$ 还原为伯醇 $\ce{R-COOH ->[LiAlH4] R-CH2OH}$（**注意**：四氢铝酸锂超出高考考纲，催化加氢还原不动羧基这条才是考纲内的对比项；超纲试剂的定义、方程式与考场处置见[有机反应类型与合成推断](/chemistry/organic-inference/)页末「课外拓展」小节）；α-H 氯化制卤代酸（再通往氨基酸、羟基酸）：$\ce{RCH2COOH + Cl2 ->[催化剂][\Delta] RCHClCOOH + HCl}$。

## 七、胺、酰胺与油脂

**胺**（$\ce{NH3}$ 的烃基取代物，三角锥形）是有机物里少见的**碱性**基团：氮上孤对电子结合 $\ce{H+}$ 成盐：$\ce{CH3CH2NH2 + HCl -> CH3CH2NH3Cl}$（原源料把乙胺盐酸盐分子式误作 $\ce{CH3CN2NH3Cl}$，已订正）；盐遇 NaOH 又游离出胺——制药把难溶易氧化的胺做成可溶性铵盐便于保存运输。三甲胺的鱼腥味、腐烂鱼虾的臭味即低级胺。

**酰胺** $\ce{RCONH2}$：酸性水解得羧酸+铵盐、碱性水解得羧酸盐并**放出氨**：$\ce{RCONH2 + NaOH ->[\Delta] RCOONa + NH3 ^}$。胺⇌酰胺的相互转化（酰化保护氨基、水解脱保护）是有机合成的经典保护策略。

**油脂**＝高级脂肪酸＋甘油（丙三醇）形成的酯：R、R′、R″ 不同为混合甘油酯，天然油脂是混合物、**无固定熔沸点**，且**不是高分子化合物**——这两个「不是」是判断题常客。高级脂肪酸口诀「软 15、硬 17、油酸不饱和 17 碳带一烯、亚油酸再多一烯」：软脂酸 $\ce{C15H31COOH}$、硬脂酸 $\ce{C17H35COOH}$（饱和，动物油多，常温**脂肪**态）；油酸 $\ce{C17H33COOH}$（一烯）、亚油酸 $\ce{C17H31COOH}$（二烯）（植物油多，常温**油**态）。化学性质两把：碱性皂化 $\ce{(C17H35COO)3C3H5 + 3NaOH ->[\Delta] 3C17H35COONa + C3H5(OH)3}$，加饱和 NaCl **盐析**分出硬脂酸钠（肥皂）；液态油催化**氢化（硬化）**成半固态脂肪——硬化油耐储存、制人造奶油。
