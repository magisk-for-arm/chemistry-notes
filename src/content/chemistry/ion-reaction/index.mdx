## 一、离子反应的本质

有离子参加（或生成）的反应，在溶液中进行，**本质是溶液中某些离子浓度的降低**。三大类去向：生成沉淀、生成气体、生成难电离物质（弱酸、弱碱、水），以及电子转移（氧化还原型离子反应）。

<Callout type="formula" title="离子方程式：写—拆—删—查">

1. **写**：先写出正确的化学方程式（反应事实是第一位的）；
2. **拆**：把「**易溶且易电离**」的物质拆成离子——强酸、强碱、可溶性盐；
3. **删**：删去两边不参加反应的「旁观离子」，系数化为最简整数比；
4. **查**：查原子守恒、电荷守恒；是氧化还原型的，再查电子得失守恒。

</Callout>

## 二、拆与不拆：一条主线，几个例外

<Callout type="memory" title="能拆的唯一标准">

同时满足**易溶**与**易电离**两个条件才拆成离子，其余一律写化学式。

- **必拆**：六大强酸 $\ce{HCl}$、$\ce{HNO3}$、$\ce{H2SO4}$、$\ce{HClO4}$、$\ce{HBr}$、$\ce{HI}$；可溶强碱 $\ce{NaOH}$、$\ce{KOH}$、$\ce{Ba(OH)2}$；可溶性盐。
- **不拆**：单质、氧化物、气体、难溶物（$\ce{CaCO3}$、$\ce{BaSO4}$……）、弱电解质（弱酸、弱碱、水）、多元弱酸的酸式酸根（$\ce{HCO3-}$、$\ce{HSO3-}$、$\ce{HS-}$……）。

</Callout>

<Callout type="tip" title="四个高频例外">

- **浓硫酸不拆**（主要以分子存在），浓盐酸、浓硝酸可拆；
- **$\ce{HSO4-}$ 在水中要拆**成 $\ce{H+}$ 与 $\ce{SO4^2-}$（硫酸是强酸），这是酸式酸根里唯一的「叛徒」；
- **微溶物看身份**：澄清石灰水中 $\ce{Ca(OH)2}$ 已溶尽——**拆**；石灰乳、生成物中的微溶物——**不拆**；
- 氧化物在任何水溶液方程式里都不拆成 $\ce{O^2-}$。

</Callout>

## 三、符号的三档用法

<Callout type="formula" title="= 、⇌ 、↑↓ 各有归属">

- 强电解质电离、绝大多数离子反应：用 $=$；
- 弱电解质电离、**盐类水解**：用 $\rightleftharpoons$，且水解程度微弱，产物**不标** $\downarrow$、$\uparrow$，也不写水解终产物 $\ce{H2O}$ 聚集；
- **完全双水解**（相互促进进行到底）：回到 $=$，并**要标** $\downarrow$、$\uparrow$，如 $2\ce{Fe^3+ + 3CO3^2- + 3H2O = 2Fe(OH)3 v + 3CO2 ^}$；
- 生成胶体注明「（胶体）」：$\ce{Fe^3+ + 3H2O ->[\Delta] Fe(OH)3}$（胶体）$\ce{+ 3H+}$。

</Callout>

## 四、「量」决定产物

同一对反应物，少量/过量写出**不同**的离子方程式。裁决原则两条：

1. **以「少量」为 1，将其消耗完**：少量物质电离出的全部离子都参与反应；过量一方按需提供。
2. **逐级反应看优先序**：$\ce{OH-}$ 滴入含 $\ce{Al^3+}$、$\ce{NH4+}$ 的溶液，顺序是「先沉淀 $\ce{Al^3+}$ → 再与 $\ce{NH4+}$ 结合 → 最后溶解 $\ce{Al(OH)3}$」。

<Callout type="note" title="两个标杆案例">

向 $\ce{NH4Al(SO4)2}$ 溶液中滴加 $\ce{Ba(OH)2}$ 使 $\ce{SO4^2-}$ 恰好完全沉淀（$1:2$）：

$$\ce{NH4+ + Al^3+ + 2SO4^2- + 2Ba^2+ + 4OH- = NH3.H2O + Al(OH)3 v + 2BaSO4 v}$$

少量 $\ce{CO2}$ 通入 $\ce{NaClO}$ 溶液（酸性 $\ce{H2CO3 > HClO > HCO3-}$，第二步制不出 $\ce{HClO}$）：

$$\ce{ClO- + CO2 + H2O = HClO + HCO3-}$$

</Callout>

## 五、离子共存：不共存的六条理由

「能大量共存」＝两两之间**任一条都不触发**：

<Callout type="note" title="六查清单">

1. **查沉淀**：$\ce{Ba^2+}$—$\ce{SO4^2- / CO3^2-}$、$\ce{Ag+}$—$\ce{Cl-}$、$\ce{Ca^2+}$—$\ce{CO3^2- / SO4^2-}$、$\ce{Mg^2+ / Fe^2+ / Fe^3+ / Cu^2+}$—$\ce{OH-}$；
2. **查气体或挥发物**：$\ce{H+}$—$\ce{CO3^2- / HCO3- / SO3^2- / S^2-}$、$\ce{OH-}$—$\ce{NH4+}$（加热）；
3. **查弱电解质**：$\ce{H+}$—$\ce{CH3COO- / ClO- / F- / AlO2-}$，$\ce{OH-}$—$\ce{Mg^2+}$ 等；
4. **查氧化还原**：$\ce{Fe^3+}$—$\ce{I- / S^2- / SO3^2-}$；$\ce{H+ + NO3-}$—$\ce{Fe^2+ / I- / S^2- / SO3^2-}$；$\ce{MnO4- / ClO-}$ 与一切还原性离子；
5. **查双水解互促**：$\ce{Al^3+}$（或 $\ce{Fe^3+}$）—$\ce{HCO3- / CO3^2- / AlO2- / S^2-}$，$\ce{NH4+}$—$\ce{AlO2- / SiO3^2-}$；
6. **查络合**：$\ce{Fe^3+}$—$\ce{SCN-}$（变血红）、$\ce{Ag+ / Cu^2+}$—足量浓氨水。

</Callout>

题目常埋**隐含条件**：「无色透明」排除 $\ce{Cu^2+}$（蓝）、$\ce{Fe^3+}$（黄）、$\ce{Fe^2+}$（浅绿）、$\ce{MnO4-}$（紫）；「与 Al 反应放 $\ce{H2}$」＝强酸或强碱**两解**；「水电离出的 $c(\ce{H+}) = 1 \times 10^{-13}\ \mathrm{mol/L}$」＝外加酸或碱抑制了水，也是两解。

## 六、常见离子检验（速查）

<Callout type="note" title="大题通用句式">

取少量待测液于试管中，滴加……溶液，若出现……，则含有……。（操作 → 现象 → 结论，三步缺一不可）

</Callout>

| 离子 | 试剂/操作 | 特征现象 |
| --- | --- | --- |
| $\ce{Na+}$ / $\ce{K+}$ | 铂丝蘸取灼烧 | 黄色 / 透过蓝色钴玻璃呈紫色 |
| $\ce{Fe^3+}$ | KSCN 溶液 | 变血红色 |
| $\ce{Fe^2+}$ | $\ce{K3[Fe(CN)6]}$ 溶液 | 蓝色沉淀 |
| $\ce{NH4+}$ | 加足量 $\ce{NaOH}$ 并加热 | 刺激性气体使湿润红色石蕊试纸变蓝 |
| $\ce{SO4^2-}$ | 先足量稀盐酸，再 $\ce{BaCl2}$ | 白色沉淀不溶解（顺序不可颠倒、不可用硝酸酸化） |
| $\ce{Cl-}$ | 稀硝酸酸化，再 $\ce{AgNO3}$ | 白色沉淀不溶解 |
| $\ce{I-}$ | 先加氯水氧化，再滴淀粉 | 溶液变蓝（淀粉遇 $\ce{I-}$ **不**变色） |
