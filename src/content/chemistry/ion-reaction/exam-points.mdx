## 考情速览

离子方程式正误判断是选择题「常青树」，常与 NA 陷阱、氧化还原拼盘出题；离子共存为必刷题型；大题中「检验/推断的文字表述」和「陌生情境离子方程式书写」是得分重灾区。**给分点往往不在结论，而在描述规范与条件审查。**

## 考点一：正误判断的「五查」维度

<Callout type="formula" title="命题人埋雷的五个位置">

1. **查事实**：产物是否符合反应原理（$\ce{Fe}$ 与 $\ce{Cl2}$ 只生成 $\ce{Fe^3+}$；硝酸不放 $\ce{H2}$；$\ce{Na}$ 入 $\ce{CuSO4}$ 溶液先与水反应）；
2. **查守恒**：原子、电荷、电子得失三关；
3. **查符号**：$=$ 与 $\rightleftharpoons$、$\uparrow$/$\downarrow$、「胶体」标注、条件（浓/稀、加热、滴加顺序）；
4. **查拆分**：可溶易电离才拆；浓硫酸、弱电解质、难溶物、$\ce{HCO3-}$ 型酸式根不拆，$\ce{HSO4-}$ 必拆；
5. **查用量**：少量/过量/等物质的量/滴加顺序是否反映在产物上。

</Callout>

<Callout type="tip" title="高频「事实」雷区清单">

- $\ce{Fe ->[Cl2] Fe^3+}$、$\ce{Fe ->[S、I2] Fe^2+}$、$\ce{Fe ->[H+(非氧化性酸)] Fe^2+}$；
- 少量 Fe 与稀硝酸得 $\ce{Fe^3+}$，**过量 Fe** 与稀硝酸得 $\ce{Fe^2+}$；
- 常温 Fe、Al 遇浓硝酸、浓硫酸**钝化**（写不出「反应方程式」并非不反应，而是生成致密氧化膜）；
- $\ce{SO2}$ 通入 $\ce{BaCl2}$ 溶液**不产生沉淀**（弱酸制不了强酸）；$\ce{SO2}$ 通入 $\ce{Ba(NO3)2}$ 溶液**有** $\ce{BaSO4}$ 沉淀（$\ce{H+ + NO3-}$ 把 +4 硫氧化为 +6）。

</Callout>

## 考点二：离子共存——先把条件翻译成离子

<Callout type="note" title="条件翻译表">

| 题干条件 | 翻译结果 |
| --- | --- |
| 无色透明 | 无 $\ce{Cu^2+}$、$\ce{Fe^3+}$、$\ce{Fe^2+}$、$\ce{MnO4-}$（「透明」只排悬浊物，不等于无色） |
| 强酸性 / $\mathrm{pH}=1$ | 大量 $\ce{H+}$：弱酸根、$\ce{OH-}$ 出局 |
| 强碱性 | 大量 $\ce{OH-}$：$\ce{NH4+}$、$\ce{Mg^2+}$、$\ce{Al^3+}$、$\ce{HCO3-}$ 出局 |
| 与 Al 反应放 $\ce{H2}$ | 强酸**或**强碱两解（含 $\ce{NO3-}$ 的酸性溶液放 NO，自相矛盾→排除该组） |
| 水电离的 $c(\ce{H+})=10^{-13}$ | 外加酸或碱，两解分别检验 |
| 使红色石蕊试纸变蓝 | 碱性；使甲基橙变红 → $\mathrm{pH}<3.1$ 酸性 |
| 加入 $\ce{Al2O3}$ 溶解 | 强酸或强碱（$\ce{Al2O3}$ 两性） |

</Callout>

共存判断本体按「六查」走：沉淀、气体/挥发物、弱电解质、氧化还原、双水解互促、络合。**氧化还原是最隐蔽的一条**：$\ce{Fe^3+}$ 与 $\ce{I-}$、$\ce{S^2-}$、$\ce{SO3^2-}$ 看似不沉淀不产气，实际发生 $2\ce{Fe^3+ + 2I- = 2Fe^2+ + I2}$。

## 考点三：与量有关的离子方程式书写

<Callout type="memory" title="两套标准手法">

- **定少法（少量/滴加少量）**：把少量物质定为 $1\ \mathrm{mol}$，其电离离子**全部**消耗，过量一方按需要提供。例：少量 $\ce{NaOH}$ 滴入 $\ce{Ca(HCO3)2}$：$\ce{Ca^2+ + HCO3- + OH- = CaCO3 v + H2O}$（$1$ 个 $\ce{OH-}$ 只够激活 $1$ 个 $\ce{HCO3-}$）。
- **序贯法（多元体系滴加）**：按反应优先序逐级消耗。$\ce{OH-}$ 入 $\ce{Al^3+}$、$\ce{NH4+}$ 混合液：先 $\ce{Al^3+ -> Al(OH)3}$（3 份），再 $\ce{NH4+ -> NH3.H2O}$（1 份），最后溶解 $\ce{Al(OH)3}$（1 份）。

</Callout>

三大常考家族：

1. **$\ce{CO2}$/$\ce{SO2}$ 与碱/弱酸盐**：产物在 $\ce{CO3^2-}$、$\ce{HCO3-}$ 或 $\ce{SO3^2-}$、$\ce{HSO3-}$ 之间切换；与 $\ce{NaClO}$、苯酚钠反应时**永远停在** $\ce{HCO3-}$（酸性卡档）。
2. **铝盐与碱、偏铝酸盐与酸**：$\ce{Al(OH)3}$ 的两性决定「过量溶解」分支。
3. **含多种可反应离子的盐 + $\ce{Ba(OH)2}$/$\ce{NaOH}$**：$\ce{NH4Al(SO4)2}$、$\ce{NH4Fe(SO4)2}$ 系列，用序贯法 + 恰好沉淀条件联立。

## 考点四：检验、推断与文字表述

<Callout type="note" title="给分句式（背模板）">

**取少量待测液于试管中，滴加（加入）×× 至 ×× 现象，静置/过滤后向上层清液继续滴加 ××，若出现 ×× 现象，则证明含 ××。**

四要素缺一不可：取样 → 操作 → 现象 → 结论。只写试剂名不写现象、或把「现象」写成「结论」（如「证明有 $\ce{SO4^2-}$」当成现象）都扣分。

</Callout>

推断题两条铁律：

- **电荷守恒是隐形闸门**：算出已确定阳离子所带正电荷与已知阴离子负电荷不相等时，缺口必然由「未检出但必存在」的离子补足；
- **引入即失效**：加氯水后再验 $\ce{Cl-}$、加硝酸后再验 $\ce{SO4^2-}$，前面步骤引入的离子使后面的证据作废——排除干扰试剂的顺序本身就是考点（$\ce{SO4^2-}$ 检验必须「先盐酸后 $\ce{BaCl2}$」且全程远离硝酸根）。
