## 一、滴定管：一支「倒着数」的量器

三段标注：使用温度（$20^{\circ}\mathrm{C}$）、容积（$25\ \mathrm{mL}$ / $50\ \mathrm{mL}$）、**0 刻度在上方**——越往下读数越大，且最下端一截无刻度（满管放液也放不到「50.00」之外）。读数**估读到小数点后两位**（$22.60\ \mathrm{mL}$，末尾 0 也是有效数字）。

<Callout type="formula" title="三系滴定管与配对铁律">

**酸式**（玻璃旋塞）：装酸性、氧化性液体——$\ce{KMnO4}$ 必须酸式（氧化橡胶）；**碱式**（橡胶管+玻璃珠）：装碱性液体——碱会腐蚀玻璃旋塞磨面使之粘死；**通用**（聚四氟乙烯旋塞）：酸碱通吃，新式首选。记忆轴：**旋塞怕碱、橡胶怕氧化剂**。

</Callout>

## 二、操作七步曲

**检漏 → 水洗 → 润洗 → 注液赶气泡 → 调液面记初读 → 滴定 → 终读重复 2~3 次取均值**。

- 检漏：酸式关旋塞注水直立观察、旋塞转 $180^{\circ}$ 再观察；碱式装水直立看橡胶处（漏了换管换珠，涂凡士林护旋塞）；
- 润洗：滴定管**必须**用所盛液润洗 2~3 次（每次 3~5 mL，倾斜转圈润遍内壁）；**锥形瓶绝不润洗、不烘干**——它守的是「待测物的物质的量不变」；
- 赶气泡：酸式倾斜 $30^{\circ}$ 快开放液冲走；碱式弯折胶管挤压玻璃珠使尖嘴朝上冲出；量液前气泡在、量完消失＝把气泡记成了液体；
- 滴定姿势：左手控管、右手持瓶颈**同向旋转摇瓶**（不前后晃）、眼睛**盯锥形瓶内颜色变化**而不是盯刻度；近终点改一滴一摇、过渡到**半滴**（悬半滴于管口→碰瓶壁冲下）；
- 读数细节：等待 1~2 min 让内壁液流下，取出竖直、视线与凹液面最低点齐平。

## 三、指示剂：三选二弃

甲基橙（红 $<3.1$／橙／黄 $>4.4$）、酚酞（无色 $<8.2$／浅红／红 $>10.0$）、石蕊**弃用**（变色不敏锐）。配对逻辑：强酸滴强碱两者皆可；强碱滴弱酸（终点碱性）选**酚酞**；强酸滴弱碱（终点酸性）选**甲基橙**——指示剂变色域尽量落在滴定终点的 pH 突跃里。盐酸滴 $\ce{Na2CO3}$·$\ce{NaNO3}$ 混合液用**双指示剂法**（酚酞褪色记第一终点、续滴加甲基橙记第二终点）。

## 四、终点判断句式（背整句）

> 「当滴入**最后半滴**××标准液时，溶液由××色变为××色，且**半分钟内不恢复原色**，即为滴定终点。」

变色方向按「谁在瓶里」定：碱在瓶里（酚酞）→ 由红变无色；酸在瓶里反滴 → 由无色变浅红且不褪。$\ce{KMnO4}$ 系**自身指示**（终点：无色→浅紫红，半分钟不褪）；碘量法用**淀粉**——且滴碘时淀粉近终点再加（过早则 $\ce{I2}$ 被淀粉包合释放不出来，终点拖长）。

## 五、氧化还原滴定两条常管线

①$\ce{KMnO4}$ 滴 $\ce{H2C2O4}$/$\ce{Fe^2+}$：$5\ce{H2C2O4 + 2MnO4- + 6H+ = 10CO2 ^ + 2Mn^2+ + 8H2O}$（自动催化：产物 $\ce{Mn^2+}$ 是催化剂，反应先慢后快）；②碘量法：$2\ce{S2O3^2- + I2 = S4O6^2- + 2I-}$——硫代硫酸钠遇酸就歧化，**不能**参与酸性介质（见「硫及其化合物」例题五）。间接碘量测定铜：$2\ce{Cu^2+ + 4I- = 2CuI v + I2}$ 再滴 $\ce{I2}$，得「守恒桥」$\ce{Cu^2+ ~ S2O3^2-}$（1∶1）。

## 六、误差分析的单杠杆

计算主干：$c_{待} = \dfrac{c_{标} V_{标}}{V_{待}}$（1∶1 反应；非 1∶1 时按系数比折算，本质是**恰好完全反应的物质的量等式**）。$c_{标}$、$V_{待}$ 已定，**一切操作误差只看一个落点：$V_{标}$ 读大了还是真大了**。口诀链：滴定管没润洗→标准液被稀释→$V_{标}$ 偏大→结果偏高；锥形瓶润洗→待测物虚增→$V_{标}$ 偏大→偏高；前仰后俯（末读偏小）→$V_{标}$ 偏小→偏低；末读数时尖嘴悬挂半滴未冲下→$V_{标}$ 记多→偏高。完整对表见易错点与考点解析。
