## 一、硫元素：火山口的黄色家族

游离态：硫黄（黄色晶体，火山口附近）；化合态：$\ce{FeS2}$（黄铁矿）、$\ce{CuFeS2}$（黄铜矿）、$\ce{CaSO4.2H2O}$（生石膏）、$\ce{Na2SO4.10H2O}$（芒硝）。常见价态 $-2 \to 0 \to +4 \to +6$ 四档主阶梯（$\ce{FeS2}$ 中 $\ce{S}$ 为 $-1$；**硫没有 +5、+7 等高价**——最外层只有 6 个电子）。

物理性质记忆点：硫**难溶于水、微溶于酒精、易溶于 $\ce{CS2}$**（洗硫渍试管用 $\ce{CS2}$）；更常用的除硫法是**热浓 $\ce{NaOH}$ 歧化**：$3\ce{S + 6NaOH ->[\Delta] 2Na2S + Na2SO3 + 3H2O}$。撒落的汞滴上覆盖硫粉处理（$\ce{Hg + S = HgS}$，常温即行，防汞蒸气中毒）。

## 二、硫单质：温和的氧化剂

与**变价金属只压到低档**——氧化性 $\ce{Cl2 > S}$ 的直接证据：

- $\ce{Fe + S ->[\Delta] FeS}$（氯气则推到 $\ce{FeCl3}$）；$2\ce{Cu + S ->[\Delta] Cu2S}$（$+1$ 价）；
- $\ce{H2 + S ->[\Delta] H2S}$（$\ce{H2S}$：臭鸡蛋气味、剧毒）；
- 可燃性：$\ce{S + O2 ->[\text{点燃}] SO2}$——空气中微淡蓝、**氧气中明亮蓝紫色**火焰；**无论氧气多少都只生成 $\ce{SO2}$**（$\ce{SO3}$ 只认催化剂）。

## 三、SO₂：一瓶试剂的四重身份

无色刺激性、有毒、易溶（1:40）、密度大于空气。四路出击：

<Callout type="formula" title="四重身份逐条落位">

- **酸性氧化物**（与 $\ce{CO2}$ 同族双档）：少量 $\ce{SO2}$ 入碱得 $\ce{SO3^2-}$、过量得 $\ce{HSO3-}$；$\ce{H2SO3}$ 二元中强酸，$\ce{NaHSO3}$ 溶液**电离大于水解显酸性**（与 $\ce{NaHCO3}$ 显碱恰好对照）；
- **还原性（主力）**：$2\ce{SO2 + O2 <=>[V2O5][\Delta] 2SO3}$（工业制硫酸心脏）；使氯水/溴水/碘水、$\ce{Fe^3+}$、酸性 $\ce{KMnO4}$ 褪色——$\ce{SO2 + Cl2 + 2H2O = H2SO4 + 2HCl}$、$5\ce{SO2 + 2MnO4- + 2H2O = 2Mn^2+ + 5SO4^2- + 4H+}$；
- **氧化性（少数派）**：$\ce{SO2 + 2H2S = 3S v + 2H2O}$（归中，气相可发生——酸雨机理外的除 $\ce{H2S}$ 思路）；
- **漂白性（化合型）**：与品红等有色物**化合**成不稳定无色物，**加热复色**；只漂有机色素、**不漂酸碱指示剂**，也不如氧化型那样杀菌——与氯水的氧化型漂白构成三大漂白体系两席（第三席活性炭吸附型，对照表见「氯及其化合物」考点三）。

</Callout>

<Callout type="memory" title="褪色三机理一句话分家">

$\ce{SO2}$ 使**品红**褪色——漂白性（加热复红）；使**溴水/高锰酸钾**褪色——**还原性**（不是漂白！）；使**滴有酚酞的 NaOH** 褪色——**酸性氧化物**耗碱（$\ce{H2SO3}$ 中和）。同一个「褪色」三个凶手，追问「加热后怎样、换成石蕊怎样」即可归案。

</Callout>

## 四、浓硫酸：两「吸」一氧化

纯硫酸无色黏稠油状、**难挥发**（制 $\ce{HCl}$、$\ce{HNO3}$ 等挥发性的酸：$\ce{NaCl + H2SO4(浓) ->[\Delta] NaHSO4 + HCl ^}$）；常用浓硫酸 $98\%$、$18.4\ \mathrm{mol/L}$。

- **吸水性**（拿现成的水）：干燥剂——可干 $\ce{H2/O2/CO2/Cl2/SO2/HCl/CO}$ 等；**不可干** $\ce{NH3}$（酸碱）与 $\ce{H2S/HI/HBr}$（**被氧化**，属氧化还原而非酸碱反应）；
- **脱水性**（按 2:1 强拆化合物里的氢氧）：蔗糖「黑面包」——先脱水成炭、炭再被浓硫酸氧化（$\ce{C + 2H2SO4(浓) ->[\Delta] CO2 ^ + 2SO2 ^ + 2H2O}$），膨胀疏松多孔兼示强氧化性；使石蕊试纸**先红后黑**（炭化）；
- **强氧化性**（+6 价硫亲自下场）：
  $$\ce{Cu + 2H2SO4(浓) ->[\Delta] CuSO4 + SO2 ^ + 2H2O}$$
  「**不浓不热不反应**」；常温 $\ce{Fe}$、$\ce{Al}$ **钝化**（化学变化，铝罐可运冷浓硫酸）；加热可氧化非金属（碳、$\ce{H2S}$ 等）。稀硫酸的氧化性走 $\ce{H+}$（活泼金属放 $\ce{H2}$）——浓稀两条氧化线不可混。

## 五、SO₃ 与硫酸的两条制备线

$\ce{SO3}$：标况**无色固体**（熔点 $16.8\ \mathrm{^{\circ}C}$，常温液态）、极易溶于水——**工业不用水吸收**而用 $98\%$ 浓硫酸（防水汽化酸雾带走 $\ce{SO3}$）。鉴别小刀：$\ce{SO3}$ 入 $\ce{BaCl2}$ 溶液立得 $\ce{BaSO4}$ 沉淀、$\ce{SO2}$ 却**无沉淀**（弱酸不能制强酸，$\ce{H2SO3}$ 酸性不足以拆 $\ce{BaCl2}$）。

接触法制硫酸三线：$\ce{S}$ 或 $\ce{FeS2}$（$\ce{4FeS2 + 11O2 ->[\text{高温}] 2Fe2O3 + 8SO2}$）$\to \ce{SO2 ->[O2][\text{催化剂}] SO3 ->[\text{浓硫酸吸收}] H2SO4}$。

## 六、SO₄²⁻ 检验与亚硫酸盐的保管

$\ce{SO4^2-}$ 检验标准三步：足量**稀盐酸**酸化（排除 $\ce{CO3^2-}$、$\ce{SO3^2-}$、$\ce{Ag+}$——顺序不可颠倒，**先加 $\ce{BaCl2}$ 后加盐酸则 $\ce{AgCl}$ 白沉淀无法排除**）→ 无现象后加 $\ce{BaCl2}$ → 白色沉淀不溶。**全程禁止引入 $\ce{NO3-}$**（酸化后氧化 $\ce{SO3^2-}$ 制造假阳性）。

$\ce{Na2SO3}$ 固体/溶液**易被空气氧化变质**（$2\ce{Na2SO3 + O2 = 2Na2SO4}$）——检变质：加盐酸酸化后再加 $\ce{BaCl2}$（有白色沉淀说明已含 $\ce{SO4^2-}$）。

## 七、硫与环境·信息含硫家族

酸雨双路：$\ce{SO2 ->[H2O] H2SO3 ->[O2] H2SO4}$（雨水中 $\text{pH}$ 随放置**先降后稳**的原因）或 $\ce{SO2 ->[O2/粉尘] SO3 -> H2SO4}$；燃煤脱硫（石灰石-石膏法）、硫酸厂尾气碱吸。「葡萄酒适量 $\ce{SO2}$」= 杀菌 + 抗氧化（合法添加剂，STSE 判对）。信息家族三角：硫代硫酸钠 $\ce{Na2S2O3}$（海波，遇酸歧化出硫乳浊——「探究浓度对速率影响」的经典沉淀钟实验；碘量法 $2\ce{S2O3^2- + I2 = S4O6^2- + 2I-}$）；连二亚硫酸钠 $\ce{Na2S2O4}$（保险粉，强还原剂，潮湿空气中易被氧化甚至自燃）；焦亚硫酸钠 $\ce{Na2S2O5}$（食品抗氧化剂、入酸放 $\ce{SO2}$）。
