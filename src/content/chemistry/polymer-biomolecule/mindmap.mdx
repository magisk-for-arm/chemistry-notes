# 生物大分子与合成高分子

## 主线

- 单体链节聚合度三个词
- 高分子都是混合物
- 天然三兄弟 糖 蛋白质 核酸

## 糖类

- 定义看结构 多羟基醛酮及其水解产物
- 甜味溶解性只是侧写
- 碳水是历史名 乙酸合通式却不是糖
- 单糖不水解 二糖多糖逐级拆
- 红榜能银镜 单糖麦芽糖乳糖
- 黑榜蔗糖加全部多糖
- 果糖是酮糖 碱里异构照样银镜

## 葡萄糖五本账

- 银镜一比二 水系数是一
- 新制氢氧化铜一比二 砖红氧化亚铜
- 催化加氢一比一 只有一枚醛基
- 发酵一比二比二 乙醇和二氧化碳
- 生理氧化放热两千八百千焦

## 二糖与多糖

- 蔗糖拆一醛一酮 麦芽糖拆两葡萄
- 淀粉遇碘变蓝 碘水不是碘化钾
- 淀粉水解四级 糊精麦芽糖再到葡萄糖
- 纤维素人体无酶 只做膳食纤维
- 通式相同不等于同分异构 各是混合物

## 水解检验双线

- 一路直接加碘水 查淀粉剩多少
- 一路先碱中和 再银镜查葡萄糖
- 不变蓝出银镜是完全 都阳性是部分
- 变蓝无银镜尚未水解
- 银镜活碱里 卤检活酸里

## 氨基酸与蛋白质

- 氨基羧基同碳叫阿尔法氨基酸
- 两性 既能配酸又能配碱
- 成肽脱一水 肽键是碳氮单键
- 一条链脱 n 减一 成环脱满 n
- 几种氨基酸做二肽 种数平方起
- 盐析可逆是物理 提纯保活性
- 变性不可逆是化学 消毒靠它
- 浓硝酸变黄查苯环 灼烧焦羽毛辨真丝

## 核酸

- 单体核苷酸 磷酸五碳糖碱基
- 脱氧核糖核酸双螺旋 碱基爱胸腺
- 核糖核酸多单链 尿嘧啶顶替

## 加聚与缩聚

- 加聚开双键 无副产物链节等于单体
- 缩聚脱小分子 链节比单体瘦
- 二烯一比四聚合 链节留双键
- 羟基酸自聚 脱 n 减一水
- 双酸双醇交替 脱二 n 减一
- 酚醛接线 邻对位脱水成链
- 倒推单体拉链法 两碳一组回乙烯
- 见酯基肽键剪断 酸侧补羟基 氧氮补氢

## 三大材料

- 热塑链状可重塑 热固网状一次成型
- 聚氯乙烯含增塑剂 不碰熟食
- 食品包装认聚乙烯聚丙烯
- 纤维三层 天然 人造 合成
- 粘胶醋酸是人造 涤纶腈纶是合成

## 化学品合理使用

- 农药方向 高效低毒低残留
- 有机氯富集受禁 DDT 收手
- 阿司匹林是乙酰水杨酸
- 哈喇味是氧化不是水解
- 维 C 抗氧化靠还原性
- 甲醛泡标本 泡食品是违法
