# 阿伏加德罗常数

## 核心概念

### 定义
- 1 mol 粒子的粒子数
- 符号 N_A
### 单位
- mol⁻¹
### 数值
- 精确值 6.02214076×10²³
- 近似 6.02×10²³
### 物理意义
- 宏观 n 与微观 N 的桥梁

## 核心公式

### n = N / N_A
### n = m / M
### n = V / V_m
### n = cV
