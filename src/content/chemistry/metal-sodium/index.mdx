## 一、钠单质：活泼金属的四张面孔

物理性质：银白色、质软（小刀可切）、密度 $\rho(\text{煤油}) < \rho(\ce{Na}) < \rho(\ce{H2O})$，**保存在煤油或石蜡油中**；着火用**细沙**覆盖，禁用水和 $\ce{CO2}$ 灭火器。

<Callout type="formula" title="四条化学性质主线">

- 与 $\ce{O2}$：常温 $4\ce{Na + O2 = 2Na2O}$（切面变暗）；点燃 $2\ce{Na + O2 ->[点燃] Na2O2}$（黄色火焰，淡黄色固体）；
- 与 $\ce{H2O}$：$2\ce{Na + 2H2O = 2NaOH + H2 ^}$——现象五字诀「**浮、熔、游、响、红**」（密度小浮水面；放热且熔点低熔成小球；氢气推动四处游动；嘶嘶作响；酚酞变红）；
- 与盐溶液：**先与水反应**，生成的 $\ce{NaOH}$ 再与盐复分解——$\ce{Na}$ 投入 $\ce{CuSO4}$ 溶液得到 $\ce{Cu(OH)2}$ 蓝色沉淀，**置换不出铜**；
- 与乙醇：$2\ce{C2H5OH + 2Na -> 2C2H5ONa + H2 ^}$，钠沉底、平缓冒泡（羟基氢活性：水 > 乙醇）。

</Callout>

工业制钠：电解熔融氯化钠 $2\ce{NaCl(熔融) ->[电解] 2Na + Cl2 ^}$。用途：$\ce{Na}$-$\ce{K}$ 合金作快中子反应堆导热剂、$\ce{TiCl4}$ 等金属冶炼还原剂、高压钠灯。

## 二、氧化钠与过氧化钠

| 项目 | $\ce{Na2O}$（白色） | $\ce{Na2O2}$（淡黄色） |
| --- | --- | --- |
| 类别 | 碱性氧化物 | **过氧化物，不是碱性氧化物** |
| 阴离子 | $\ce{O^2-}$ | $\ce{O2^2-}$（过氧根，O 为 $-1$ 价） |
| 阳∶阴离子比 | $2:1$ | $2:1$（$1\ \mathrm{mol}$ 固体均含 $3N_A$ 个离子） |
| 与水 | $\ce{Na2O + H2O = 2NaOH}$ | $2\ce{Na2O2 + 2H2O = 4NaOH + O2 ^}$ |
| 与 $\ce{CO2}$ | $\ce{Na2O + CO2 = Na2CO3}$ | $2\ce{Na2O2 + 2CO2 = 2Na2CO3 + O2}$ |
| 与盐酸 | $\ce{Na2O + 2HCl = 2NaCl + H2O}$ | $2\ce{Na2O2 + 4HCl = 4NaCl + 2H2O + O2 ^}$ |
| 特性 | 加热转化为 $\ce{Na2O2}$ | 强氧化性：漂白、消毒、供氧剂 |

<Callout type="tip" title="Na₂O₂ 的两条隐藏考点">

- 与水/二氧化碳反应中 $\ce{Na2O2}$ **既是氧化剂又是还原剂**：每生成 $1\ \mathrm{mol}\ \ce{O2}$ 转移 $2\ \mathrm{mol}$ 电子；
- 强氧化性表现：使品红褪色；滴入酚酞水中**先红后褪色**；把 $\ce{SO2}$、$\ce{SO3^2-}$ 氧化为 $\ce{SO4^2-}$；投入 $\ce{FeCl2}$ 溶液最终得 $\ce{Fe(OH)3}$ 红褐色沉淀。

</Callout>

## 三、碳酸钠与碳酸氢钠

| 项目 | $\ce{Na2CO3}$（纯碱、苏打） | $\ce{NaHCO3}$（小苏打） |
| --- | --- | --- |
| 外观 | 白色粉末，加水**放热**结块 | 细小白色晶体，加水溶解**吸热** |
| 溶解度（同温） | 大 | 小（饱和溶液通 $\ce{CO2}$ 析晶的依据） |
| 热稳定性 | 稳定，受热难分解 | $\ce{2NaHCO3 ->[\Delta] Na2CO3 + H2O + CO2 ^}$ |
| 与盐酸 | 分步：先 $\ce{HCO3-}$ 后放气 | 立即：$\ce{HCO3- + H+ = H2O + CO2 ^}$ |
| 与 $\ce{Ca(OH)2}$ | $\ce{Ca^2+ + CO3^2- = CaCO3 v}$ | 均产生 $\ce{CaCO3}$ 沉淀（档位不同） |
| 与 $\ce{CaCl2}$ | $\ce{CaCO3}$ 沉淀 | 不反应 |
| 用途 | 纺织、皂化、造纸、玻璃 | 发酵粉、胃药 |

转化与除杂：$\ce{Na2CO3 ->[CO2 通入/适量 H+] NaHCO3}$，$\ce{NaHCO3 ->[NaOH 适量/\Delta] Na2CO3}$。固体 $\ce{Na2CO3}$ 中混 $\ce{NaHCO3}$——**加热至恒重**；溶液里则加适量 $\ce{NaOH}$；$\ce{NaHCO3}$ 溶液中混 $\ce{Na2CO3}$——**通足量 $\ce{CO2}$**（不引入新杂质）。

## 四、侯氏制碱法的溶解度逻辑

向饱和食盐水中**先通 $\ce{NH3}$ 后通 $\ce{CO2}$**（氨使溶液呈碱性、大增二氧化碳吸收量，顺序不可换）：

$$\ce{NaCl + NH3 + CO2 + H2O = NaHCO3 v + NH4Cl}$$

$\ce{NaHCO3}$ 是当时体系中溶解度最小的盐，**最先结晶析出**；煅烧得纯碱。

## 五、焰色反应（物理变化）

铂丝（或无锈铁丝、镍丝）蘸**稀盐酸**在火焰上灼烧至与原火焰同色 → 蘸取试样灼烧观察：$\ce{Na}$ **黄色**；$\ce{K}$ **紫色（必须透过蓝色钴玻璃**滤去钠的黄光干扰）；$\ce{Ca}$ 砖红色、$\ce{Ba}$ 黄绿色、$\ce{Cu}$ 绿色。

<Callout type="memory" title="三句规则">

玻璃棒含 $\ce{Na2SiO3}$ 不能代替铂丝；洗丝用盐酸不用硫酸（氯化物易挥发）；焰色反应是**元素**的性质、属物理变化。

</Callout>
