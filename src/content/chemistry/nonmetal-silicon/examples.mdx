## 例题一：材料用途配对（easy）

<ExampleCard title="四种硅产品的身份证" difficulty="easy">

下列用途与材料对应**不正确**的是（　　）

- A．计算机芯片——晶体硅
- B．光导纤维——二氧化硅
- C．食品干燥剂——硅胶
- D．木材防火剂——碳化硅

<Reveal summary="查看解析">

<Callout type="right" title="答案：D">

木材（纺织品）防火剂是**硅酸钠溶液（水玻璃）**，不是碳化硅；$\ce{SiC}$（金刚砂）的身份是硬度大的耐磨/耐高温材料。A、B、C 恰是「硅管导电、硅石管导光、硅胶管吸水」三句口诀的正身。

</Callout>

</Reveal>

<Reveal summary="变式训练">

**变式** 「石墨烯属新型有机高分子材料」这句话对吗？

**答案**：错。石墨烯是**碳单质**，与「有机」无关。材料判断题先问「是不是单质/氧化物」，再谈材料分类。

</Reveal>
</ExampleCard>

## 例题二：试剂贮存判断（medium）

<ExampleCard title="四瓶试剂对号入座" difficulty="medium" source="改编 · 原型：试剂保存正误判断">

实验室保存 $\ce{NaOH}$ 溶液、氢氟酸、水玻璃、澄清石灰水四种试剂。下列说法正确的是（　　）

- A．$\ce{NaOH}$ 溶液盛于带磨砂玻璃塞的细口瓶
- B．氢氟酸盛于带玻璃塞的广口瓶
- C．水玻璃密封保存，且瓶塞不用玻璃塞
- D．澄清石灰水敞口放置不影响浓度

<Reveal summary="查看解析">

<Callout type="formula" title="逐项过筛">

A 错：玻璃塞磨砂面与 $\ce{NaOH}$ 缓慢反应生成硅酸钠，瓶塞被**粘死**——碱液用橡胶塞。B 错双连：HF 蚀玻璃（瓶不能是玻璃的），且液体药品用**细口瓶**（广口留固体）。D 错：石灰水吸收 $\ce{CO2}$ 变浊、浓度下降。

</Callout>

<Callout type="right" title="答案：C">

水玻璃本身是矿物胶，敞口失水变稠、还会把玻璃磨口粘住——**密封 + 非玻璃塞**双保险，C 正确。

</Callout>

</Reveal>

<Reveal summary="变式训练">

**变式** 盛 $\ce{Na2SiO3}$ 溶液的试剂瓶用后未洗，瓶塞拔不出——用学过的化学式解释并给出日常预防。

**答案**：$\ce{Na2SiO3}$ 溶液吸收空气中 $\ce{CO2}$ 与自身失水，在磨口处结成硅酸/碳酸钠「水泥层」（$\ce{Na2SiO3 + CO2 + H2O = Na2CO3 + H2SiO3 v}$ 型）；预防：用后随即盖紧、定期转动瓶塞、量大时改塑料塞。

</Reveal>
</ExampleCard>

## 例题三：N_A 的键数账（medium）

<ExampleCard title="60 g 二氧化硅的三本账" difficulty="medium" source="改编 · 原型：晶体结构 N_A 计数题">

设 $N_A$ 为阿伏加德罗常数的值。下列说法正确的是（　　）

- A．$60\ \mathrm{g}\ \ce{SiO2}$ 含 $N_A$ 个 $\ce{SiO2}$ 分子
- B．$60\ \mathrm{g}\ \ce{SiO2}$ 含 $2N_A$ 条 Si—O 键
- C．$60\ \mathrm{g}\ \ce{SiO2}$ 含 $4N_A$ 条 Si—O 键
- D．$28\ \mathrm{g}$ 晶体硅含 $4N_A$ 条 Si—Si 键

<Reveal summary="查看解析">

<Callout type="why" title="错项解剖">

A：$\ce{SiO2}$ 是共价晶体，**不存在分子**，化学式只是最简式——「分子数」三个字一出即错。B/D 都是**均摊**忘了做：每条键被两个原子共用，键数不能按「配位数直接乘」。

</Callout>

<Callout type="right" title="答案：C">

$60\ \mathrm{g}=1\ \mathrm{mol}\ \ce{SiO2}$，每个 $\ce{Si}$ 伸出 $4$ 条 Si—O 键且**这条键整个归该 Si 名下计数无共享问题**（Si—O 键两端原子不同，$1\ \mathrm{mol}$ Si 对 $4\ \mathrm{mol}$ 键）——$4N_A$ 条 ✓。D 应折半：晶体硅中每个 Si 连 $4$ 邻、每键两 Si 共用，$28\ \mathrm{g}=1\ \mathrm{mol}$ Si 只含 $4/2=2\ \mathrm{mol}$（$2N_A$ 条）Si—Si 键。

</Callout>

</Reveal>

<Reveal summary="变式训练">

**变式** $1\ \mathrm{mol}$ 金刚石与 $1\ \mathrm{mol}\ \ce{SiO2}$ 中共价键之比是多少？

**答案**：$2:4=1:2$。金刚石同款均摊（$\ce{C}$∶键 $=1:2$）；$\ce{SiO2}$ 是 $\ce{Si}$∶键 $=1:4$。此类题的总钥匙：**「谁和谁共用一条键」除以二，两端不同原子的键（Si—O）不除**。更多 $N_A$ 陷阱见本站「阿伏加德罗常数」易错点清单。

</Reveal>
</ExampleCard>

## 例题四：酸性验证链（medium）

<ExampleCard title="盐酸 · 碳酸 · 硅酸三段装置" difficulty="medium" source="改编 · 原型：比较氯碳硅非金属性的实验装置">

用装置链「① 分液漏斗（稀盐酸）+ 圆底烧瓶（石灰石）→ ② 洗气瓶（饱和 $\ce{NaHCO3}$ 溶液）→ ③ 试管（$\ce{Na2SiO3}$ 溶液）」验证酸性：盐酸 > 碳酸 > 硅酸。（1）说明②的作用与「若撤去②」的后果；（2）写出③中现象与对应离子方程式（$\ce{CO2}$ 足量）；（3）有同学欲借该实验「顺便」证明非金属性 Cl > C > Si，请评价。

<Reveal summary="查看解析">

<Callout type="formula" title="（1）伪证制造者">

盐酸挥发，$\ce{CO2}$ 气流携带 HCl 进入③；HCl 是强酸，**直接**与 $\ce{Na2SiO3}$ 反应也出硅酸沉淀——沉淀到底记在碳酸还是盐酸头上就说不清了。饱和 $\ce{NaHCO3}$ 只吃 HCl（$\ce{HCl + NaHCO3 = NaCl + CO2 + H2O}$）不放走 $\ce{CO2}$，反手还补上一份 $\ce{CO2}$。

</Callout>

<Callout type="why" title="（2）落点反应">

③中**出现白色胶状沉淀**：$\ce{SiO3^2- + 2CO2 + 2H2O = H2SiO3 v + 2HCO3-}$（$\ce{CO2}$ 足量写 $\ce{HCO3-}$，写 $\ce{CO3^2-}$ 者扣分）。

</Callout>

<Callout type="right" title="（3）结论越界">

证到「酸性：碳酸 > 硅酸 ⇒ 非金属性 C > Si」即可停笔。比 Cl 必须用**最高价氧化物对应水化物**的酸性——盐酸不是含氧酸更不是最高价（该用 $\ce{HClO4}$）；且①中「盐酸 > 碳酸」也只是**无氧强酸**比含氧酸，本就推不出 Cl 的位置。实验结论的边界感是评分点。

</Callout>

</Reveal>

<Reveal summary="变式训练">

**变式** ②能否换成盛 $\ce{Na2CO3}$ 溶液的洗气瓶？

**答案**：不能。$\ce{CO2 + Na2CO3 + H2O = 2NaHCO3}$——除杂试剂把**待检气体本体**也吞了，③前功尽弃。除杂铁律：只宰杂质，不伤主客。

</Reveal>
</ExampleCard>

## 例题五：高纯硅流程计算（hard）

<ExampleCard title="400 mol 高纯硅的原料与循环账单" difficulty="hard" source="改编 · 原型：高纯硅三步工艺流程计算">

工业制备高纯硅：① $\ce{SiO2 + 2C ->[\text{高温}] Si + 2CO ^}$；② $\ce{Si + 3HCl ->[\text{高温}] SiHCl3 + H2}$；③ $\ce{SiHCl3 + H2 ->[\text{高温}] Si + 3HCl}$。某厂计划产出 $400\ \mathrm{mol}$ 高纯硅，假设每步转化完全、粗硅全部进入②。（1）②至少消耗 HCl 多少 mol？（2）②产生的 $\ce{H2}$ 能否满足③的需要？（3）若③再生 HCl 全部循环至②，系统净补充 HCl 多少 mol？（4）$28\ \mathrm{t}$ 石英砂（$\ce{SiO2}$ 质量分数 $60\%$，杂质不含硅）最多产高纯硅多少吨？

<Reveal summary="查看解析">

<Callout type="formula" title="（1）（2）系数对表">

③逆推：$400\ \mathrm{mol}\ \ce{Si}$ ← $400\ \mathrm{mol}\ \ce{SiHCl3}$ + $400\ \mathrm{mol}\ \ce{H2}$，并再生 $1200\ \mathrm{mol}\ \ce{HCl}$。②正推：$400\ \mathrm{mol}\ \ce{SiHCl3}$ 耗 $\boxed{1200\ \mathrm{mol}\ \ce{HCl}}$、**产 $400\ \mathrm{mol}\ \ce{H2}$**——与③需求一比一正好咬合，氢源无需外购。

</Callout>

<Callout type="why" title="（3）循环账">

②耗 $1200\ \mathrm{mol}$、③还 $1200\ \mathrm{mol}$，**净补充 $0\ \mathrm{mol}$**（理想态）——这就是「HCl 与 H₂ 双闭环」的算术含义。现实题眼：闭环只保「物料种类」，不保「数量」，任何一步的泄漏都要外购补足，所以工业装置仍持续补 HCl。

</Callout>

<Callout type="right" title="（4）硅守恒一竿子到底">

$28\ \mathrm{t}\times 60\% = 16.8\ \mathrm{t}\ \ce{SiO2}$。硅元素全程 $1:1$ 挂链（$\ce{SiO2 -> Si -> SiHCl3 -> Si}$），质量直接按摩尔质量比值折算：$m(\ce{Si}) = 16.8\ \mathrm{t} \times \dfrac{28}{60} = \boxed{7.84\ \mathrm{t}}$。流程计算的第一杠杆永远是**目标元素守恒**，不必逐步换算。

</Callout>

</Reveal>

<Reveal summary="变式训练">

**变式** $2.8\ \mathrm{g}$ 晶体硅与足量 NaOH 溶液充分反应，标况放 $\ce{H2}$ 多少升？氧化剂是什么？

**答案**：$\ce{Si + 2NaOH + H2O = Na2SiO3 + 2H2 ^}$，$0.1\ \mathrm{mol}$ Si 放 $0.2\ \mathrm{mol}\ \ce{H2}$，标况 $\boxed{4.48\ \mathrm{L}}$。**氧化剂是 $\ce{H2O}$**（氢元素 $+1 \to 0$），$\ce{NaOH}$ 只负责把硅酸溶走；电子账自查：Si 失 $0.1\times 4 = 0.4\ \mathrm{mol}\ e^-$，H 得 $0.2\times 2 = 0.4\ \mathrm{mol}\ e^-$ ✓。

</Reveal>
</ExampleCard>
