## 一、硅元素：无游离态的「亲氧之王」

硅在地壳中含量居第二（仅次于氧），**全部以化合态存在**——$\ce{SiO2}$ 与硅酸盐两大类矿物。它与碳同族，性质记忆骨架就是「碳的同族表亲，但更亲氧、单质更惰性」。用途两朵金花：**晶体硅**做半导体芯片与太阳能电池（「硅谷」之名所系），**二氧化硅**拉光纤。推断题暗号：「既能与酸反应又能与碱溶液反应放氢气的**非金属单质**」——$\ce{Si}$（对家 $\ce{Al}$ 是金属）。

## 二、硅单质：常温三知己

灰黑色金属光泽固体、硬度大熔点高、半导体。常温化学性不活泼，但恰好有三个对手：

$$\ce{Si + 2F2 = SiF4}\qquad \ce{Si + 4HF = SiF4 ^ + 2H2 ^}\qquad \ce{Si + 2NaOH + H2O = Na2SiO3 + 2H2 ^}$$

<Callout type="tip" title="与碱放氢的机理账">

$\ce{Si}$ 与 $\ce{NaOH}$ 溶液反应中，**氧化剂是 $\ce{H2O}$ 不是 $\ce{NaOH}$**（放出的 $\ce{H2}$ 里氢来自水），$\ce{NaOH}$ 只负责溶解生成的硅酸把平衡推到底；$1\ \mathrm{mol}\ \ce{Si}$ 对应 $2\ \mathrm{mol}\ \ce{H2}$——与 $\ce{2Al + 2NaOH + 2H2O = 2AlO2- + 3H2 ^}$ 的 $2:3$ 是推断题的对照卡。加热条件下硅还能与 $\ce{Cl2}$、$\ce{O2}$、碳（生成金刚砂 $\ce{SiC}$）化合。

</Callout>

## 三、SiO₂ 与 CO₂：同组成式的两个世界

| | $\ce{CO2}$ | $\ce{SiO2}$ |
| --- | --- | --- |
| 晶体 | 分子晶体（干冰升华） | **共价晶体**（金刚石同款网状） |
| 熔沸点 | 低 | 高、硬度大 |
| 与水 | 反应成碳酸 | **不与水反应** |
| 微观 | 存在 $\ce{CO2}$ 分子 | **无分子**，化学式只是原子比（最简式） |

结构账本（$N_A$ 题素材）：每个 $\ce{Si}$ 连 $4$ 个 $\ce{O}$、每个 $\ce{O}$ 桥连 $2$ 个 $\ce{Si}$；$\ce{Si}$ 原子数 ∶ $\ce{Si-O}$ 键数 $=1:4$；最小环为**十二元环**（6 硅 6 氧）；$1\ \mathrm{mol}\ \ce{SiO2}$（$60\ \mathrm{g}$）含 **$4N_A$ 个 Si—O 键、$0$ 个分子**。

## 四、二氧化硅的五路反应

<Callout type="formula" title="酸性氧化物里唯一的「叛徒」">

- 与强碱：$\ce{SiO2 + 2NaOH = Na2SiO3 + H2O}$——**盛碱试剂瓶不用玻璃塞**（生成的硅酸钠是矿物胶，把瓶塞粘死）；
- **与酸只认氢氟酸**：$\ce{SiO2 + 4HF = SiF4 ^ + 2H2O}$——刻蚀玻璃/雕花原理；氢氟酸**必须住塑料瓶**；
- 与碱性氧化物（高温）：$\ce{SiO2 + CaO ->[\text{高温}] CaSiO3}$（炼铁造渣同款：$\ce{SiO2 + CaCO3 ->[\text{高温}] CaSiO3 + CO2 ^}$）；
- 与**盐**（高挥发制低挥发）：$\ce{SiO2 + Na2CO3 ->[\text{高温}] Na2SiO3 + CO2 ^}$（玻璃窑炉主反应之一）——注意这是「难挥发酸酐赶出易挥发酸酐」，**不能**用来比碳酸与硅酸的酸性；
- 被碳还原（高温）：$\ce{SiO2 + 2C ->[\text{高温}] Si + 2CO ^}$（**产物是 CO 不是 $\ce{CO2}$**）；配碳过量则 $\ce{SiO2 + 3C ->[\text{高温}] SiC + 2CO ^}$。

</Callout>

## 五、硅酸与水玻璃：弱酸三性一池胶水

$\ce{H2SiO3}$：白色胶状沉淀、**不使指示剂变色**（难溶）、弱于碳酸、受热分解（$\ce{H2SiO3 ->[\Delta] SiO2 + H2O}$）。凝胶脱水得**硅胶**——多孔吸附水，食品级干燥剂兼催化剂载体。

制备走「强酸制弱酸」两线：$\ce{Na2SiO3 + 2HCl = H2SiO3 v + 2NaCl}$；通 $\ce{CO2}$ 分两档——少量 $\ce{CO2}$ 写 $\ce{Na2CO3}$、**过量 $\ce{CO2}$ 写 $\ce{NaHCO3}$**（$\ce{Na2SiO3 + 2CO2 + 2H2O = 2NaHCO3 + H2SiO3 v}$）。

$\ce{Na2SiO3}$ 水溶液俗称**水玻璃/泡花碱**：黏合剂（矿物胶）、木材纺织品**防火剂**、防腐剂；与氯化钙等可溶性盐复分解出硅酸钙沉淀（溶液中即行）。

## 六、高纯硅的工业三步法

$$\ce{SiO2 ->[C,\ 2000^{\circ}C][\text{①粗炼}] Si\ (粗) ->[HCl,\ 300^{\circ}C][\text{②氯化}] SiHCl3 ->[H2,\ 1100^{\circ}C][\text{③氢还原}] Si\ (高纯)}$$

$$\ce{SiO2 + 2C ->[\text{高温}] Si + 2CO ^}\quad \ce{Si + 3HCl ->[\text{高温}] SiHCl3 + H2}\quad \ce{SiHCl3 + H2 ->[\text{高温}] Si + 3HCl}$$

**循环双雄**：②的产物 $\ce{H2}$ 供③作原料、③再生的 $\ce{HCl}$ 回送②——流程题圈「可循环利用物质」的标准答案。为什么不一步到位？炭还原得到的**粗硅**纯度不够（半导体要求 $9N+$），提纯必须绕道气态中间体。信息线：$\ce{Mg2Si + 4HCl = 2MgCl2 + SiH4 ^}$，硅烷**空气中自燃**（$\ce{SiH4 + 2O2 = SiO2 + 2H2O}$）——与甲烷的常温惰性构成同族递变反差。

## 七、无机非金属材料家族（STSE 定位表）

传统三件套：**陶瓷**（黏土烧制）、**玻璃**（纯碱+石灰石+石英，窑中复杂反应都指向硅酸盐；普通玻璃无固定熔点）、**水泥**（石灰石+黏土）。新潮主力：**硅芯片/光导纤维**（$\ce{Si}$ 半导体 / $\ce{SiO2}$ 导光，别写反）、**碳化硅 SiC**（金刚砂，硬、耐高温结构陶瓷）、**氮化硅 Si₃N₄**（陶瓷发动机）、新型陶瓷按性能分工（氧化铝耐摔、氧化锆义齿等）。判断题高频错位：「光纤成分是硅单质」（错，$\ce{SiO2}$）、「芯片成分是二氧化硅」（错，$\ce{Si}$）——**硅管导电、硅石管导光**。
