## 一、氯气：强氧化剂的三线作战

**黄绿色**、刺激性气味、有毒气体，密度大于空气，可溶于水（1 体积水约溶 2 体积 $\ce{Cl2}$），易液化。闻气体气味：**手掌扇动、少量飘入**，禁止直接凑近嗅。

<Callout type="formula" title="与金属/氢气/水的三线反应">

- 与金属（**一律推到最高价**）：$2\ce{Fe + 3Cl2 ->[\Delta] 2FeCl3}$（棕褐色烟，与水、量的多少无关——$\ce{Fe^3+ ->[\ce{Fe}] Fe^2+}$ 只发生在溶液里）；$\ce{Cu + Cl2 ->[\Delta] CuCl2}$（棕黄色烟）；$2\ce{Na + Cl2 ->[\text{点燃}] 2NaCl}$（白烟）。氧化性排序佐证：$\ce{Cl2}$ 把铁推到 $+3$、$\ce{O2}$ 只到混价 $\ce{Fe3O4}$、$\ce{S}$ 只到 $+2$；
- 与 $\ce{H2}$：$\ce{H2 + Cl2 ->[\text{点燃}] 2HCl}$——**安静燃烧、苍白色火焰、瓶口白雾**（工业制盐酸；氢气与氯气混合后光照即爆炸）；
- 与水（可逆）：$\ce{Cl2 + H2O <=> H+ + Cl- + HClO}$——$\ce{HClO}$ 是弱酸，**离子方程式中不拆**。

</Callout>

## 二、氯气与碱：同一反应的两个温度档

- 常温（制**漂白液/84 消毒液**，有效成分 $\ce{NaClO}$）：$\ce{Cl2 + 2NaOH = NaCl + NaClO + H2O}$；
- 加热（制**氯酸钾**）：$3\ce{Cl2 + 6NaOH ->[\Delta] 5NaCl + NaClO3 + 3H2O}$；工业用 $\ce{Cl2}$ 与浓 $\ce{KOH}$ 热反应制较纯 $\ce{KClO3}$（降温结晶分离）；
- 与**石灰乳**（制漂白粉，有效成分 $\ce{Ca(ClO)2}$）：$2\ce{Cl2 + 2Ca(OH)2 = CaCl2 + Ca(ClO)2 + 2H2O}$——石灰乳是悬浊液，写离子方程式时 $\ce{Ca(OH)2}$ **不拆**。

<Callout type="memory" title="起效与失效都靠碳酸打配合">

$\ce{ClO-}$ 生效（遇酸产 $\ce{HClO}$）：$\ce{NaClO + CO2 + H2O = NaHCO3 + HClO}$（产物是 $\ce{NaHCO3}$ 不是碳酸钠——酸性排序 $\ce{H2CO3 > HClO > HCO3-}$ 的经典证据）；失效：$2\ce{HClO ->[\text{光照}] 2HCl + O2 ^}$。**84 消毒液（碱性）与洁厕灵（盐酸）混用即中毒**：$\ce{ClO- + Cl- + 2H+ = Cl2 ^ + H2O}$。

</Callout>

## 三、抢电子清单：氯气氧化的六类对手

$\ce{Cl2 + 2Fe^2+ = 2Fe^3+ + 2Cl-}$（除 $\ce{FeCl3}$ 中的 $\ce{FeCl2}$）｜$\ce{Cl2 + H2S = 2HCl + S v}$｜$\ce{Cl2 + 2Br- = Br2 + 2Cl-}$、$\ce{Cl2 + 2I- = I2 + 2Cl-}$（置换萃取、$\ce{KI}$-淀粉试纸验满）｜$\ce{Cl2 + SO2 + 2H2O = H2SO4 + 2HCl}$（**1:1 混合作用于水，漂白性同归于尽**）｜$3\ce{Cl2 + 8NH3 = 6NH4Cl + N2}$（浓氨水查氯气管道漏点：白烟）。

## 四、实验室制氯气：一条龙装置

$$\ce{MnO2 + 4HCl(浓) ->[\Delta] MnCl2 + Cl2 ^ + 2H2O}$$

**「不浓不热不反应」**（稀盐酸、不加热均不行）。装置五连：发生（分液漏斗+圆底烧瓶）→ **饱和食盐水**除 $\ce{HCl}$（同时降 $\ce{Cl2}$ 溶解损耗）→ **浓硫酸**干燥 → **向上排空气**收集（或排饱和食盐水）→ **$\ce{NaOH}$ 溶液**尾气吸收。验满：湿润 $\ce{KI}$-淀粉试纸靠瓶口变蓝。

替代方案：$2\ce{KMnO4 + 16HCl(浓) = 2KCl + 2MnCl2 + 5Cl2 ^ + 8H2O}$（**不加热**，氧化剂更强）。

## 五、氯水：一瓶「混合物超市」

新制氯水**三分四离**：分子 $\ce{Cl2}$、$\ce{H2O}$、$\ce{HClO}$；离子 $\ce{H+}$、$\ce{Cl-}$、$\ce{ClO-}$、$\ce{OH-}$（极稀）。按成分记性质：

| 成分 | 性质 | 典型反应/现象 |
| --- | --- | --- |
| $\ce{Cl2}$ | 强氧化性 | 氧化 $\ce{Br-}$、$\ce{I-}$、$\ce{Fe^2+}$、$\ce{SO2}$ |
| $\ce{H+}$ | 酸性（强） | 与 $\ce{Mg}$ 放氢、与 $\ce{CaCO3}$ 放 $\ce{CO2}$ |
| $\ce{HClO}$ | 弱酸 + **强氧化性** | 漂白杀菌；使石蕊**先红后褪色** |
| $\ce{Cl-}$ | 沉淀 | 加 $\ce{AgNO3}$ 的白色沉淀 |

**干燥氯气无漂白性**（干燥布条不褪色、湿润布条褪色）——漂白主角是 $\ce{HClO}$。久置氯水 $=$ 稀盐酸（$\ce{HClO}$ 光解殆尽）：酸性反而更强，但失去漂白性。氯水须**现用现配、棕色瓶避光密封**。液氯是纯净物（$\ce{Cl2}$，可用钢瓶储运）、新制氯水与久置氯水均为混合物。

## 六、Cl⁻ 检验与卤族递变

$\ce{Cl-}$ 检验两步：先加**稀硝酸**酸化（排 $\ce{CO3^2-}$ 等干扰，$\ce{Ag2CO3}$ 溶解放气泡），再加 $\ce{AgNO3}$ 得**不溶的白色沉淀**。（沉淀颜色档：$\ce{AgCl}$ 白、$\ce{AgBr}$ 浅黄、$\ce{AgI}$ 黄——亦是 $\ce{Br-}$/$\ce{I-}$ 的检验依据；$\ce{AgF}$ 可溶，硝酸银法检不了 $\ce{F-}$。）

卤族递变（$\ce{F2 -> I2}$）：颜色加深、熔沸点升高、密度增大；氧化性 $\ce{F2 > Cl2 > Br2 > I2}$（与氢气化合由爆到缓、氢化物稳定性递减）；$\ce{X-}$ 还原性反排。特殊性三件套：

<Callout type="tip" title="氟、溴、碘的各怀心思">

- **氟**：无正价、非金属性之王；与**水**都反应（$2\ce{F2 + 2H2O = 4HF + O2}$），置换法在它面前失灵；$\ce{HF}$ 是弱酸、腐蚀玻璃（塑料瓶保存）、卤化氢中沸点最高（氢键）；
- **溴**：唯一的液态非金属单质（深红棕色、易挥发）——试剂瓶**水封**保存，禁橡胶塞；
- **碘**：$\ce{I2}$ 遇淀粉变蓝、加热易升华（提纯）；碘盐补的是 $\ce{KIO3}$；$\ce{I2}$ 氧化性弱到把铁只按到 $+2$（$\ce{FeI2}$）。

</Callout>

置换—萃取判别法：未知液加新制氯水、再注入 $\ce{CCl4}$ 振荡——有机层**橙红**为 $\ce{Br-}$、**紫红**为 $\ce{I-}$。

## 七、海水资源：淡化·氯碱·提溴·提碘

- 海水淡化三法：**蒸馏法**、电渗析法、离子交换法（后两者也在考）；
- 氯碱工业（电解饱和食盐水的**溶液**）：$2\ce{NaCl + 2H2O ->[\text{电解}] 2NaOH + H2 ^ + Cl2 ^}$——**阳极出氯气、阴极出氢气与 NaOH**（阴极区碱）；与「电解熔融 $\ce{NaCl}$ 制钠」严格区分；
- 海水提溴三步曲：浓缩海水 + $\ce{Cl2}$ 氧化 → **热空气/水蒸气吹出** $\ce{Br2}$ → $\ce{SO2}$ 水溶液吸收富集（$\ce{Br2 + SO2 + 2H2O = 2HBr + H2SO4}$）→ 再氯气氧化精馏（「**吹出—吸收—再氧化**」的富集循环必背）；
- 海水提碘（海带）：灼烧成灰 → 浸泡过滤 → 氧化剂**只能选 $\ce{H2O2}$（稀硫酸酸化）**——氯水过量会把 $\ce{I2}$ 进一步氧化成 $\ce{IO3-}$ → $\ce{CCl4}$ 萃取分液（上层水相应无色；若仍显浅黄，说明萃取不完全或氧化剂偏少）。
