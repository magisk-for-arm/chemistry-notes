## 一、氮元素价类阶梯：一条线管全章

$-3$（$\ce{NH3/NH4+}$）→ $0$（$\ce{N2}$）→ $+2$（$\ce{NO}$）→ $+4$（$\ce{NO2}$）→ $+5$（$\ce{HNO3/\text{硝酸盐}}$）。左端只可被氧化、右端只可被还原、中间两头能战——**归中**（$\ce{NO + NO2 + 2OH- = 2NO2- + H2O}$）与**歧化**（$\ce{2NO2 + 2NaOH = NaNO2 + NaNO3 + H2O}$）都发生在相邻档位之间。

## 二、氮气：三键锁住的惰性

$\ce{N\equiv N}$ 键能极大，通常情况下氮气化学性质稳定、难被生物直接吸收。三条「撬锁」反应：

- $\ce{N2 + O2 ->[\text{放电}] 2NO}$（高能固氮，「雷雨发庄稼」第一步）；
- $3\ce{Mg + N2 ->[\text{点燃}] Mg3N2}$——**镁能在氮气中燃烧**，点燃的镁条在 $\ce{CO2}$、$\ce{N2}$ 里都灭不掉；$\ce{Mg3N2}$ 遇水双解放氨（$\ce{Mg3N2 + 6H2O = 3Mg(OH)2 + 2NH3 ^}$）；
- $\ce{N2 + 3H2 <=>[高温高压][催化剂] 2NH3}$（哈伯法人工固氮，化肥工业的起点，养活了数十亿人）。

氮的固定 = 游离态氮 → 化合态氮：自然固氮（闪电高能固氮 + 根瘤菌生物固氮）与人工固氮（合成氨）两条路。

## 三、NO 与 NO₂：颜色会变的孪生兄弟

| | $\ce{NO}$ | $\ce{NO2}$ |
| --- | --- | --- |
| 颜色状态 | 无色气体 | **红棕色**刺激性气体 |
| 溶解性 | 不溶于水 | 与水反应 |
| 收集 | **只能排水法**（密度近空气且与 $\ce{O2}$ 反应） | 只能向上排空气 |
| 毒性 | 有毒（与血红蛋白结合） | 有毒 |

相互转化：$2\ce{NO + O2 = 2NO2}$；$3\ce{NO2 + H2O = 2HNO3 + NO}$（**恰好水面上升 2/3、余 1/3 无色气体**——试管倒立实验的画面脚本）。除杂：$\ce{NO}$ 里的 $\ce{NO2}$ 水洗即除。存在平衡 $2\ce{NO2 <=> N2O4}$（无色），降温颜色变浅——$N_A$ 题「46 g $\ce{NO2}$ 与 $\ce{N2O4}$ 混合气所含分子数」的陷阱根源（关联本站「阿伏加德罗常数」）。

<Callout type="formula" title="与 O₂ 混溶于水的两个总方程">

$4\ce{NO2 + O2 + 2H2O = 4HNO3}$、$4\ce{NO + 3O2 + 2H2O = 4HNO3}$——气体恰好被水全吸收的配比锚点（体积比 $4:1$ 与 $4:3$）。尾气碱吸收：$\ce{NO + NO2 + 2NaOH = 2NaNO2 + H2O}$（归中到 $+3$，**产物是亚硝酸钠不是硝酸钠**）、$2\ce{NO2 + 2NaOH = NaNO2 + NaNO3 + H2O}$。

</Callout>

## 四、氨：唯一的碱性气体

无色刺激性气味、密度小于空气、**1 体积水溶 700 体积氨**、易液化（制冷剂）。四条化学线：

- **碱性**：$\ce{NH3 + HCl = NH4Cl}$（浓氨水与浓盐酸靠近产生**白烟**；$\ce{HNO3}$ 同样、$\ce{H2SO4}$ 因不挥发只能"闻"不能"烟"）；$\ce{NH3 + H2O <=> NH3.H2O <=> NH4+ + OH-}$——氨水成分三分子四离子，$\ce{NH3.H2O}$ 是弱碱**写离子方程式不拆**；
- **可燃**：$4\ce{NH3 + 3O2 ->[\text{点燃}] 2N2 + 6H2O}$；
- **还原性（催化氧化，工业制硝酸第一步）**：$4\ce{NH3 + 5O2 ->[Pt][\Delta] 4NO + 6H2O}$；
- 与氯气：$8\ce{NH3 + 3Cl2 = N2 + 6NH4Cl}$——**浓氨水检验氯气管道漏点**（白烟）。

<Callout type="memory" title="实验室制氨的装置三问">

发生：$2\ce{NH4Cl + Ca(OH)2 ->[\Delta] CaCl2 + 2NH3 ^ + 2H2O}$（固固加热、**试管口略向下倾斜**防水冷凝回流炸裂；不用 $\ce{NaOH}$——腐蚀玻璃且易结块；绝不能单加热 $\ce{NH4Cl}$——瓶口遇冷重新化合）。干燥：**碱石灰**（禁浓硫酸、$\ce{P2O5}$、无水 $\ce{CaCl2}$——后者生成 $\ce{CaCl2.8NH3}$）。收集：向下排空气，管口湿润红色石蕊试纸变蓝验满；棉花（水或稀硫酸浸湿）防对流兼吸尾气。替代路线：浓氨水 + $\ce{NaOH}$ 固体 / 生石灰（放热 + 增 $\ce{OH-}$ + 减溶剂，三重逼氨出逃）。

</Callout>

## 五、喷泉实验：一句话「制造压强差」

挤压胶头滴管让少量水进入充满 $\ce{NH3}$ 的烧瓶 → 氨速溶、瓶内压强骤减 → 烧杯里的水（加酚酞）**喷成红色喷泉**。酚酞一石二鸟：证明极易溶、证明溶液显碱性。判据推广——**气体在液体里"消失"得足够快即可喷泉**：$\ce{HCl/HBr}$ 与水（1:500）、$\ce{NH3}$ 与稀硫酸、$\ce{CO2/SO2/Cl2/H2S}$ 与 $\ce{NaOH}$ 溶液（**反应型**喷泉）。液体只喷不满？说明气体不纯或混有难溶成分——$\ce{NO2/O2}$、$\ce{NO/O2}$ 按 $4:1$、$4:3$ 配比可满（本站「阿伏加德罗常数」混合喷泉例题同款数学）。

## 六、铵盐三性 NH₄⁺ 一个检验

受热易分解（$\ce{NH4Cl ->[\Delta] NH3 ^ + HCl ^}$，冷却复化合——**升华假象，是化学变化**；$\ce{NH4HCO3}$ 全气态分解）｜与碱放氨（施用铵态氮肥**忌与草木灰 $\ce{K2CO3}$ 混用**）｜溶解性良好。

$\ce{NH4+}$ 检验标准句式：取样 + **浓** $\ce{NaOH}$ 溶液、**加热** → 产生能使**湿润的红色石蕊试纸变蓝**的气体。（"稀碱不加热"检不出；试纸必须湿润且**不**用玻璃棒蘸溶液接触——考的全在修饰词。）

## 七、硝酸：三副面孔与工业四步

**不稳定性**：$4\ce{HNO3 ->[\text{光照或}\Delta] 4NO2 ^ + O2 ^ + 2H2O}$——浓硝酸常显黄色（溶了分解的 $\ce{NO2}$）；棕色瓶阴凉处、**玻璃塞**（腐蚀橡胶）。

**强氧化性两档**（与金属反应**永不放 $\ce{H2}$**）：

$$\ce{Cu + 4HNO3(浓) = Cu(NO3)2 + 2NO2 ^ + 2H2O}$$
$$3\ce{Cu + 8HNO3(稀) = 3Cu(NO3)2 + 2NO ^ + 4H2O}$$

浓→$\ce{NO2}$、稀→$\ce{NO}$；**浓度越大氧化性越强**（与盐酸的"浓度大还原性强"恰好反着记）。常温下 $\ce{Fe}$、$\ce{Al}$ 遇浓硝酸/浓硫酸**钝化**——致密氧化膜是"以柔克刚"，不是不反应（钝化是**化学变化**，故可用铝槽车运浓硝酸）。加热时还能氧化非金属：$\ce{C + 4HNO3(浓) ->[\Delta] CO2 ^ + 4NO2 ^ + 2H2O}$。王水（浓盐酸:浓硝酸 $=3:1$）溶金溶铂。

工业氨氧化四步：$\ce{NH3 ->[O2] NO ->[O2] NO2 ->[H2O] HNO3}$（$\ce{NO}$ 循环利用）。

## 八、氮与环境三条线

正常雨水 $\text{pH} \approx 5.6$（溶 $\ce{CO2}$），**酸雨 $\text{pH} < 5.6$**（元凶 $\ce{SO2}$ 与 $\ce{NO_x}$）；汽车尾气中 $\ce{NO}$ 与碳氢化合物在紫外线下成**光化学烟雾**；尾气净化器（钯催化）：$2\ce{NO + 2CO ->[\text{催化剂}] N2 + 2CO2}$。「雷雨发庄稼」三连：$\ce{N2 -> NO -> NO2 -> HNO3}$（随雨水落成硝酸盐氮肥）。
