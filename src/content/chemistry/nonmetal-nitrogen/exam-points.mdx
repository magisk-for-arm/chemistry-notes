## 考情速览

氮章是「实验 + 计算」双料题库：选择题常考 $\ce{NO2/NO}$ 与 $\ce{O2}$ 混溶于水的体积讨论；实验大题以氨的制备装置评价、喷泉原理迁移为骨架；工业流程里氨氧化法制硝酸连年出现；STSE 卷爱从酸雨、光化学烟雾、汽车尾气净化切入。

## 考点一：氮氧化物与 O₂ 混溶于水的计算

三个方程构成全部题库：$3\ce{NO2 + H2O = 2HNO3 + NO}$、$4\ce{NO2 + O2 + 2H2O = 4HNO3}$、$4\ce{NO + 3O2 + 2H2O = 4HNO3}$。

<Callout type="memory" title="残气讨论的两把钥匙">

- 混合气通入水中「无气体剩余」的临界配比：$\ce{NO2}:\ce{O2} = 4:1$、$\ce{NO}:\ce{O2} = 4:3$；残气若是 $\ce{O2}$ 直接按第二个方程倒推；残气若是 $\ce{NO}$ 则可能来自「$\ce{NO2}$ 过量自产」（每 3 体积 $\ce{NO2}$ 出 1 体积 $\ce{NO}$）；
- 纯 $\ce{NO2}$ 试管倒立水槽：液面停在 $\tfrac{2}{3}$ 处；再补 $\ce{O2}$ 至充满需原体积的 $\tfrac{1}{4}$——两步合计仍是 $4\ce{NO2} \sim \ce{O2}$。

</Callout>

## 考点二：喷泉实验的原理与装置迁移

判据只有一条：**让烧瓶内气体快速消失、形成负压**。引发手段（挤滴管、热敷、冷敷、注反应液）与气液配对（$\ce{NH3}$—水、$\ce{HCl}$—$\ce{NaOH}$、$\ce{CO2/SO2/Cl2}$—碱液）都是这条判据的变奏。定量侧：喷泉止于何处 = 气体被吸收了多少——「$\ce{NH3}$ 与空气混溶」喷不满、$\ce{NO2 + O2}$ 按 $4:1$ 恰好满瓶。关联本站「阿伏加德罗常数」的混合喷泉例题。

## 考点三：氨的催化氧化与铵盐实验链

催化氧化 $4\ce{NH3 + 5O2 ->[Pt][\Delta] 4NO + 6H2O}$ 是工业制硝酸的头步，也是「氨气使铂催化剂中毒」「白雾自何来」类实验题的源头（生成的 $\ce{NO -> NO2 -> HNO3}$ 酸雾）。铵盐侧三件套：受热分解（$\ce{NH4Cl}$ 的「假升华」）、与碱放氨（施肥忌草木灰）、$\ce{NH4+}$ 检验（浓、热、湿三修饰词缺一不可）。

## 考点四：硝酸与金属反应的计算

<Callout type="formula" title="两守恒一口价">

金属失电子总数 $=$ 氮得电子总数（$\ce{HNO3 -> NO2}$ 得 $1e$、$\ce{-> NO}$ 得 $3e$、$\ce{-> N2O}$ 得 $8e$、$\ce{-> NH4NO3}$ 得 $8e$）；硝酸分两路——**成盐的 $\ce{NO3-}$ 走 N 守恒、被还原的走电子守恒**。列「$n(\ce{HNO3}) = n(\text{盐中的}\ce{NO3-}) + n(\text{还原产物中的N})$」即可通吃，包括「浓变稀混合气体」双解型（见例题五）。

</Callout>

混合酸（$\ce{H+}$ 来自硫酸、$\ce{NO3-}$ 来自硝酸盐或硝酸）先写离子式 $3\ce{Cu + 8H+ + 2NO3- = 3Cu^2+ + 2NO ^ + 4H2O}$ 再判缺项——「硫酸根旁观、氢硝酸根联营」。铁过量终态 $\ce{Fe^2+}$、硝酸过量终态 $\ce{Fe^3+}$，$2\ce{Fe^3+ + Fe = 3Fe^2+}$ 是档位切换桥。

## 考点五：氮循环与环境的 STSE 命题点

「雷雨发庄稼」三步方程、酸雨 $\text{pH} < 5.6$（硝酸型与硫酸型）、光化学烟雾（$\ce{NO_x}$ + 碳氢 + 紫外线）、尾气催化净化 $2\ce{NO + 2CO ->[\text{催化剂}] N2 + 2CO2}$、铵态氮肥施用禁忌。判断题高频错项：「$\ce{CO2}$ 排放造成酸雨」（错，酸雨元凶是 $\ce{SO2/NO_x}$）、「pH 小于 7 的雨水即酸雨」（错，界线是 5.6）。
