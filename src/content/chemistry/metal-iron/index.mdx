## 一、铁单质：变价金属的「看人下菜」

银白色固体（铁粉黑色），能被磁铁吸引，地壳中含量居第四位。铁有 $+2$、$+3$ 两种主要价态，**遇强氧化剂上 $+3$，遇弱氧化剂守 $+2$**：

<Callout type="formula" title="四条化学性质主线">

- 与非金属：$3\ce{Fe + 2O2 ->[点燃] Fe3O4}$；$2\ce{Fe + 3Cl2 ->[\Delta] 2FeCl3}$（强氧化剂 → $+3$）；$\ce{Fe + S ->[\Delta] FeS}$（弱氧化剂 → $+2$，$\ce{I2}$ 同理）；
- 与水蒸气：$3\ce{Fe + 4H2O(g) ->[高温] Fe3O4 + 4H2}$（常温铁与水不反应，「铁与水蒸气」是唯一写法）；
- 与非氧化性酸：$\ce{Fe + 2H+ = Fe^2+ + H2 ^}$；**冷的浓硫酸、浓硝酸中钝化**（表面生成致密氧化膜，属化学变化，加热后反应剧烈）；
- 与盐溶液：$\ce{Fe + Cu^2+ = Fe^2+ + Cu}$、$\ce{Fe + 2Fe^3+ = 3Fe^2+}$。

</Callout>

## 二、铁与稀硝酸：三档配比

$n(\ce{Fe}):n(\ce{HNO3})$ 按物质的量之比分档（稀硝酸还原产物为 $\ce{NO}$）：

| $\ce{Fe}:\ce{HNO3}$ | 结局 | 离子方程式 |
| --- | --- | --- |
| $\geq 3:8$（铁过量） | 全部 $\ce{Fe^2+}$ | $3\ce{Fe + 8H+ + 2NO3- = 3Fe^2+ + 2NO ^ + 4H2O}$ |
| 介于两档之间 | $\ce{Fe^2+}$、$\ce{Fe^3+}$ 共存 | 两个方程式联立 + 守恒 |
| $\leq 1:4$（硝酸足量） | 全部 $\ce{Fe^3+}$ | $\ce{Fe + 4H+ + NO3- = Fe^3+ + NO ^ + 2H2O}$ |

中间档可理解为：先生成 $\ce{Fe^2+}$，余酸再把部分 $\ce{Fe^2+}$ 续氧化：$3\ce{Fe^2+ + 4H+ + NO3- = 3Fe^3+ + NO ^ + 2H2O}$。

## 三、三种氧化物

| 项目 | $\ce{FeO}$ | $\ce{Fe2O3}$ | $\ce{Fe3O4}$ |
| --- | --- | --- | --- |
| 俗称/色态 | 黑色粉末 | 铁红、红棕色粉末 | 磁性氧化铁、黑色晶体 |
| 铁的价态 | $+2$ | $+3$ | $+2$ 一个、$+3$ 两个 |
| 与盐酸 | $\ce{FeO + 2H+ = Fe^2+ + H2O}$ | $\ce{Fe2O3 + 6H+ = 2Fe^3+ + 3H2O}$ | $\ce{Fe3O4 + 8H+ = Fe^2+ + 2Fe^3+ + 4H2O}$ |
| 与稀硝酸（氧化） | $3\ce{FeO + 10H+ + NO3- = 3Fe^3+ + NO ^ + 5H2O}$ | 只发生复分解 | $3\ce{Fe3O4 + 28H+ + NO3- = 9Fe^3+ + NO ^ + 14H2O}$ |
| 与氢碘酸（还原） | $\ce{FeO + 2H+ = Fe^2+ + H2O}$ | $\ce{Fe2O3 + 6H+ + 2I- = 2Fe^2+ + I2 + 3H2O}$ | $\ce{Fe3O4 + 8H+ + 2I- = 3Fe^2+ + I2 + 4H2O}$ |
| 用途 | — | 红砖、炼铁、铝热剂、油漆 | 炼铁、磁性材料 |

<Callout type="tip" title="读表口诀">

$\ce{FeO}$ 与 $\ce{Fe3O4}$ 里的 $+2$ 铁遇硝酸要被氧化并放出 $\ce{NO}$——**「遇酸看有没有价可升」**；$\ce{I-}$ 反过来把 $+3$ 铁还原成 $\ce{Fe^2+}$ 自身变 $\ce{I2}$。同一氧化物对不同氧化性/还原性酸，产物完全不同。

</Callout>

## 四、两种氢氧化物

| 项目 | $\ce{Fe(OH)2}$ | $\ce{Fe(OH)3}$ |
| --- | --- | --- |
| 色态 | 白色固体 | 红褐色固体 |
| 制备 | $\ce{Fe^2+ + 2OH- = Fe(OH)2 v}$（防氧化操作见易错点） | $\ce{Fe^3+ + 3OH- = Fe(OH)3 v}$ |
| 稳定性 | 极易被氧化：$4\ce{Fe(OH)2 + O2 + 2H2O = 4Fe(OH)3}$（**白 → 灰绿 → 红褐**） | 受热分解：$2\ce{Fe(OH)3 ->[\Delta] Fe2O3 + 3H2O}$ |
| 与盐酸 | $\ce{Fe(OH)2 + 2H+ = Fe^2+ + 2H2O}$ | $\ce{Fe(OH)3 + 3H+ = Fe^3+ + 3H2O}$ |
| 与稀硝酸 | 少量酸走复分解；过量酸被氧化：$3\ce{Fe(OH)2 + 10H+ + NO3- = 3Fe^3+ + NO ^ + 8H2O}$ | 复分解 |
| 与氢碘酸 | $\ce{Fe(OH)2 + 2HI = FeI2 + 2H2O}$ | $2\ce{Fe(OH)3 + 6H+ + 2I- = 2Fe^2+ + I2 + 6H2O}$ |

## 五、铁盐与亚铁盐

- **保存**：$\ce{Fe^2+}$ 溶液加**少量铁粉**（防氧化）+ 少量对应酸（抑水解）；$\ce{Fe^3+}$ 溶液只需加酸抑水解。
- **$\ce{Fe^3+}$ 的氧化性**：$2\ce{Fe^3+ + Cu = 2Fe^2+ + Cu^2+}$（刻蚀印刷电路板）、$2\ce{Fe^3+ + 2I- = 2Fe^2+ + I2}$、$2\ce{Fe^3+ + 3S^2- = 2FeS v + S v}$（$\ce{Fe2S3}$ 不稳定，不存在）。
- **$\ce{FeCl3}$ 三兄弟用途**：净水（水解生成 $\ce{Fe(OH)3}$ 胶体吸附悬浮物）；向**沸蒸馏水**中滴入饱和 $\ce{FeCl3}$ 溶液、煮至红褐色即得胶体（不是加 $\ce{NaOH}$）；蒸干溶液得 $\ce{Fe(OH)3}$/$\ce{Fe2O3}$，制无水 $\ce{FeCl3}$ 须在 **$\ce{HCl}$ 气流中**蒸干以抑制水解。
- **常见盐**：绿矾 $\ce{FeSO4\cdot 7H2O}$（还原剂、补血剂）；高铁酸钾 $\ce{K2FeO4}$（强氧化性杀菌 + 还原产物 $\ce{Fe^3+}$ 水解成胶体吸附，**消毒净水双功能**）；铁铵矾 $\ce{NH4Fe(SO4)2\cdot 12H2O}$（分析试剂）。
- **铁氰化钾 $\ce{K3[Fe(CN)6]}$（赤血盐）**：检验 $\ce{Fe^2+}$，生成蓝色沉淀 $\ce{KFe[Fe(CN)6]}$（滕氏蓝）；**亚铁氰化钾 $\ce{K4[Fe(CN)6]}$（黄血盐）**：检验 $\ce{Fe^3+}$，生成普鲁士蓝——两者化学组成相同，晶型差异使颜色略有不同。

## 六、Fe²⁺ 与 Fe³⁺ 检验速查

| 试剂/方法 | $\ce{Fe^2+}$（浅绿色） | $\ce{Fe^3+}$（黄色） |
| --- | --- | --- |
| 观察颜色 | 浅绿色 | 黄色 |
| $\ce{KSCN}$ 溶液 | 不变红，加氯水后变红 | **立即变红** |
| $\ce{NaOH}$ 溶液 | 白色絮状 → 灰绿 → 红褐 | 红褐色沉淀 |
| $\ce{K3[Fe(CN)6]}$ | **蓝色沉淀**（特征） | 无 |
| $\ce{K4[Fe(CN)6]}$ | 无 | **蓝色沉淀**（特征） |
| 苯酚 | 无 | **显紫色** |
| 淀粉 $\ce{KI}$ 试纸 / 铜片 | 无 | 试纸变蓝 / 铜被腐蚀 |
| 溴水 / 酸性 $\ce{KMnO4}$ | **褪色**（还原性） | 无 |

## 七、链接板块：铜及其化合物

铜稳定，主要 $+1$、$+2$ 价；紫红色，导电性仅次于银。

- 铜锈（铜绿）：$2\ce{Cu + O2 + H2O + CO2 = Cu2(OH)2CO3}$，受热分解 $\ce{Cu2(OH)2CO3 ->[\Delta] 2CuO + CO2 ^ + H2O}$；
- 与酸：不与盐酸/稀硫酸反应；浓硫酸 $\ce{Cu + 2H2SO4(浓) ->[\Delta] CuSO4 + SO2 ^ + 2H2O}$；稀硝酸产 $\ce{NO}$、浓硝酸产 $\ce{NO2}$；
- 与硫反应生成 $\ce{Cu2S}$（硫氧化性弱，铜只显 $+1$ 价），与氯气生成 $\ce{CuCl2}$；
- 氧化物：$\ce{CuO}$ 黑色、$\ce{Cu2O}$ **砖红色**；$\ce{Cu2O}$ 遇酸**歧化**：$\ce{Cu2O + 2H+ = Cu + Cu^2+ + H2O}$；高温 $4\ce{CuO ->[\text{高温}] 2Cu2O + O2 ^}$；
- 鉴别水：无水 $\ce{CuSO4}$ 白色遇水变蓝（$\ce{CuSO4\cdot 5H2O}$ 蓝矾/胆矾）；胆矾高温分解 $\ce{CuSO4 ->[\text{高温}] CuO + SO3 ^}$（古法制硫酸），而 $\ce{FeSO4}$ 分解发生氧化还原：$2\ce{FeSO4 ->[\Delta] Fe2O3 + SO2 ^ + SO3 ^}$；
- $\ce{Cu(OH)2}$ 新制悬浊液检验醛基，生成**砖红色** $\ce{Cu2O}$ 沉淀；
- 波尔多液（胆矾 + 生石灰 + 水）：$\ce{Cu^2+}$ 重金属使蛋白质变性杀菌。
