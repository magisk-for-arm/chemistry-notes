## 考情速览

铁是元素化合物考查的**频率之王**：$N_A$ 与离子共存选择题里 $\ce{Fe^2+}$/$\ce{Fe^3+}$ 的氧化还原对几乎每卷必现；工业流程题以「铁的浸出—除铁—沉淀」为主线；实验题偏爱 $\ce{Fe(OH)2}$ 防氧化设计与 $\ce{Fe^3+}$、$\ce{Cu^2+}$ 的分离检验。铜常作铁的「伴生考区」出现（刻蚀液、湿法炼铜、胆矾制备）。

## 考点一：铁三角的转化网络

<Callout type="formula" title="三个价态两两互通">

- $\ce{Fe ->[弱氧化剂：H+ / Cu^2+ / S / I2][\text{或强氧化剂不足}] Fe^2+ ->[强氧化剂：Cl2 / Br2 / NO3-(H+) / H2O2 / MnO4-] Fe^3+}$；
- 回退全靠还原剂：$\ce{Fe^3+ ->[Fe / Cu / I- / S^2- / H2S / SO2] Fe^2+ ->[Zn / Al（过量则到 Fe）] Fe}$；
- $\ce{Fe ->[Cl2 / \text{足量}HNO3][\text{直接}] Fe^3+}$，$\ce{Fe ->[\text{少量}HNO3 / \text{过量}Fe][\text{一步}] Fe^2+}$——「**量决定终点**」。

</Callout>

高频判断：$2\ce{Fe^3+ + S^2-}$ 型「氧化 + 沉淀」耦合反应（产物 $\ce{FeS + S}$）、$\ce{Fe^3+}$ 与 $\ce{HCO3-}$ 双水解（$\ce{Fe^3+ + 3HCO3- = Fe(OH)3 v + 3CO2 ^}$，泡沫灭火器原理的变种）都是共存题宠儿。

## 考点二：Fe 与稀硝酸的三档配比

给定 $n(\ce{Fe})$ 与 $n(\ce{HNO3})$ 先比大小定档：$3:8$ 与 $1:4$ 是两个**临界点**。

| 比值 $n(\ce{Fe}):n(\ce{HNO3})$ | 溶质 | 快速算法 |
| --- | --- | --- |
| $\geq 3:8$ | 只有 $\ce{Fe(NO3)2}$ | 按 $3\ce{Fe} \sim 8\ce{HNO3} \sim 2\ce{NO}$ |
| $\leq 1:4$ | 只有 $\ce{Fe(NO3)3}$ | 按 $\ce{Fe} \sim 4\ce{HNO3} \sim \ce{NO}$ |
| 之间 | 两种硝酸盐都有 | 设 $\ce{Fe^2+}\ x$、$\ce{Fe^3+}\ y$，**铁守恒 + 电子守恒（=N 守恒）**联立 |

<Callout type="tip" title="中间档的通解">

设 $x=n(\ce{Fe^2+})$、$y=n(\ce{Fe^3+})$，铁守恒 $x+y=n(\ce{Fe})$；铁失电子总数 $2x+3y$ 恰等于生成 $\ce{NO}$ 得电子数（每个 $\ce{NO}$ 得 $3e^-$），结合 N 原子守恒 $n(\ce{HNO3}) = (2x+3y) + n(\ce{NO})$，二式合一即 $n(\ce{HNO3}) = \dfrac{4}{3}(2x+3y)$。

</Callout>

## 考点三：Fe²⁺ 与 Fe³⁺ 的检验与除杂

- 检验组合拳：$\ce{KSCN}$ + 氯水两步法（证 $\ce{Fe^2+}$）、$\ce{K3[Fe(CN)6]}$ 蓝色沉淀（$\ce{Fe^2+}$ 专属）、苯酚显紫（$\ce{Fe^3+}$ 专属）；
- 除杂定式：$\ce{FeCl2}$ 液混 $\ce{FeCl3}$ —— **加过量铁粉过滤**（不引入新杂质）；$\ce{FeCl3}$ 液混 $\ce{FeCl2}$ —— 通适量 $\ce{Cl2}$ 或滴 $\ce{H2O2}$（绿色氧化剂）；$\ce{FeSO4}$ 混 $\ce{CuSO4}$ —— 铁粉过滤；
- 「除铁」是流程题万能步骤：调节 pH 使 $\ce{Fe^3+}$ 先行水解沉淀除去（$\ce{Fe^3+}$ 完全沉淀 pH 约 3.7，远小于 $\ce{Cu^2+}$、$\ce{Fe^2+}$），故常先把 $\ce{Fe^2+}$ 氧化成 $\ce{Fe^3+}$ 再调 pH。

## 考点四：含铁混合物的守恒计算

<Callout type="memory" title="三条守恒任选其二">

$\ce{Fe}$/$\ce{Fe2O3}$（或加 $\ce{Fe3O4}$）混合物溶于酸：① **Fe 原子守恒**定产物总铁；② **电子守恒**联系 $\ce{H2}$、$\ce{NO}$ 等氧化还原产物的量（$\ce{Fe}$ 失电子给 $\ce{H+}$/$\ce{NO3-}$；$\ce{Fe2O3}$ 溶解不涉电子，$\ce{Fe^3+}$ 与 $\ce{Fe}$ 的归中属「内部交易」不改变总账）；③ 电荷/离子守恒收尾。「KSCN 不变红」「恰好完全溶解」这类话术 = 告知终态只有 $\ce{Fe^2+}$（或无剩余），是列方程的钥匙。

</Callout>

## 考点五：铜的化合物与工业载体

- 湿法炼铜 $\ce{Fe + CuSO4 = FeSO4 + Cu}$ 与刻蚀液 $2\ce{Fe^3+ + Cu = 2Fe^2+ + Cu^2+}$ 构成「铁铜互检」闭环：刻蚀废液（$\ce{Fe^2+}$、$\ce{Cu^2+}$）加过量铁粉可回收铜（得 $\ce{Cu + Fe}$ 混合固体，再用盐酸溶铁提纯）；
- 制胆矾两条路线评价：$\ce{Cu ->[浓硫酸, \Delta] CuSO4}$（放 $\ce{SO2}$、酸耗倍增）vs $\ce{Cu ->[O2][\Delta] CuO ->[稀硫酸] CuSO4}$（无污染、原子经济），绿色化学高频答题点；
- $\ce{CuSO4}$ 三种脸谱：检验水的无水白粉、波尔多液杀菌、电解精炼铜的电解液。
