## 一、推断三要素：条件、现象、量

有机框图题的全部线索不过三类：**箭头上的条件**暗示反应类型（NaOH 水溶液＝水解、NaOH 醇溶液＝消去、浓硫酸 170 ℃＝消去、Cu/△＝催化氧化）；**特征现象**点认官能团（褪色、沉淀、显色、银镜）；**定量关系**锁定官能团数目（1 mol 物质吃掉几 mol NaOH、放出几 mol 气体）。三要素交叉验证，就能从未知物身上榨出结构。

三大「家族式」反应的记忆锚点：**取代**看「换」（卤代、硝化、磺化、酯化、水解全部归此，形式都是 $\ce{A1-B1 + A2-B2 -> A1-B2 + A2-B1}$）；**加成**看「双键打开」（烯炔苯醛酮各按资格答题）；**消去**看「邻碳有氢」（醇、卤代烃两户）。

## 三、读条件：箭头上的暗号

- 「$\ce{NaOH}$ **水**溶液、加热」：$-\ce{X}$、酯基、酰胺基的水解。
- 「$\ce{NaOH}$ **醇**溶液、加热」：$-\ce{X}$ 的消去（成烯）。
- 「浓 $\ce{HNO3}$、浓 $\ce{H2SO4}$、加热」：苯环硝化。
- 「浓 $\ce{H2SO4}$、170 ℃」醇消去成烯；「140 ℃ 左右」分子间脱水成醚；与羧酸共热＝酯化；稀硫酸加热＝酯水解。
- 「$\ce{Cl2/Fe}$ 或 $\ce{FeBr3}$」：苯环上的取代；「$\ce{Cl2}$/光照」：侧链烷基（或烷烃）的自由基氯代。
- 「$\ce{O2/Cu}$、△」：醇催化氧化（伯醇→醛→酸、仲醇→酮）或醛氧化成酸。
- 「银氨溶液/△」或「新制 $\ce{Cu(OH)2}$/△」：醛基氧化。
- 「$\ce{H2/Ni}$」：双键、三键、醛基、酮羰基、苯环加氢（酯基、羧基中的碳氧双键一般不认账）。

## 四、读现象：五类褪色与成套显色

**使酸性 $\ce{KMnO4}$ 褪色**（氧化）：烯炔、苯的同系物（**与苯环直接相连的碳上有 H**）、醛及甲酸酯族、含 α-H 的醇、酚。

**使溴水褪色**（三种命运先分清）：①烯炔**加成**；②醛基**氧化**——$\ce{CH3CHO + Br2 + H2O -> CH3COOH + 2HBr}$（须有水参与，所以醛**不能**使溴的四氯化碳溶液褪色）；③酚类生成三溴苯酚**白色沉淀**；外加「萃取分层」这一物理假阳性。

**其余特征**：遇 $\ce{FeCl3}$ 显紫→酚；银镜/砖红色沉淀→$-\ce{CHO}$ 与 $\ce{HCOO}-$（甲酸、甲酸酯、葡萄糖、麦芽糖全套隐形醛基）；遇碘变蓝→淀粉；浓硝酸变黄→含苯环蛋白质；茚三酮加热显紫蓝→α-氨基酸与蛋白质；与 Na 放气→$-\ce{OH}$/$-\ce{COOH}$；与 $\ce{NaHCO3}$ 放气→只有 $-\ce{COOH}$（苯酚不行）。

## 五、定量账本：官能团数目的天平

<Callout type="formula" title="六本常备账">

- **与 Na**：$2\ce{-OH}$（醇、酚）或 $2\ce{-COOH}$ 供 1 $\ce{H2}$——见活泼氢就乘一半。
- **与 NaOH**：$-\ce{COOH}$、酚羟基各 1；酯基水解 1、**酚酯 1 变 2**；酰胺基 1；卤代烃中卤原子 1、**苯环上的卤 1 变 2**（$\ce{C6H5Br + 2NaOH ->[\Delta][加压] C6H5ONa + NaBr + H2O}$）。
- **与 $\ce{Na2CO3}$**：羧酸足量时 $2\ce{-COOH}\to1\ce{CO2}$；苯酚只到 $\ce{NaHCO3}$ **不放气**（$\ce{C6H5OH + Na2CO3 -> C6H5ONa + NaHCO3}$）。
- **与 $\ce{NaHCO3}$**：只有 $-\ce{COOH}$ 应答：$\ce{RCOOH + NaHCO3 -> RCOONa + CO2 ^ + H2O}$（1∶1）。
- **醛基氧化账**：1 $-\ce{CHO}$ ～ 2 $\ce{Ag}$ ～ 1 $\ce{Cu2O}$；**甲醛**当两个醛基（1∶4），甲酸、甲酸酯按 $-\ce{CHO}$ 记账。
- **苯酚溴代**：溴水取代只认酚羟基的**邻、对位氢**，1 mol 苯酚吃 3 mol $\ce{Br2}$；位被占则不反应。

</Callout>

**连续氧化的质量暗号**：$\ce{RCH2OH -> RCHO -> RCOOH}$ 质量 $M$、$M-2$、$M+14$；与乙酸酯化 $M\to M+42$、与乙醇酯化 $M\to M+28$——框图题里报数字就能反推档位。

## 六、碳骨架构建：增长、缩短、成环

**增长碳链**五把刀：

1. **炔/醛/酮与 HCN 加成**：$\ce{HC#CH ->[HCN][催化剂] CH2=CH-CN ->[H2O/H+][\Delta] CH2=CH-COOH}$（乙炔→丙烯酸模板）；$\ce{CH3CHO + HCN ->[催化剂] CH3CH(OH)CN ->[H2][催化剂] CH3CH(OH)CH2NH2}$——$-\ce{CN}$ 占一碳、水解成酸、还原成胺。
2. **卤代烃与 NaCN 取代**：$\ce{CH3CH2Br + NaCN -> CH3CH2CN + NaBr}$、$\ce{CH3CH2CN ->[H2O/H+] CH3CH2COOH}$——比原料多一个碳的丙酸。
3. **格氏试剂**：$\ce{CH3CH2Br + Mg ->[无水乙醚] CH3CH2MgBr}$，随后 $\ce{CH3CH2MgBr ->[(1) CO2][(2) H2O/H+] CH3CH2COOH}$、$\ce{CH3CH2MgBr ->[(1) HCHO][(2) H2O/H+] CH3CH2CH2OH}$（甲醛增长一碳成伯醇）；遇水遇醇立即报废（$\ce{RMgX + H2O -> RH + Mg(OH)X}$）——**全程无水**是它的生死线。
4. **羟醛缩合**：含 α-H 的醛加成再失水，碳链翻倍：$\ce{2CH3CHO ->[催化剂] CH3CH(OH)CH2CHO ->[\Delta][-H2O] CH3CH=CHCHO}$。
5. **成醚/成环外快**：威廉森合成 $\ce{RONa + R'X ->[无水] ROR' + NaX}$ 制不对称醚；傅-克烷基化 $\ce{PhH + CH3CH=CH2 ->[AlCl3] PhCH(CH3)2}$（苯＋丙烯→异丙苯；碳正离子机理，卤代烃碳数 ≥3 会重排）。

**缩短碳链**：烯烃被酸性 $\ce{KMnO4}$ 断键氧化 $\ce{R-CH=CH-R' ->[KMnO4/H+] RCOOH + R'COOH}$（口诀「有氢成酸、无氢成酮、端碳成气」）；炔烃三键全断成两分子羧酸（端炔出 $\ce{CO2}$）；苯的同系物侧链整条氧化成 $-\ce{COOH}$；羧酸盐碱石灰脱羧、石油裂化。

**成环反应**：双烯与亲双烯体的**狄尔斯-阿尔德反应**构建六元环（$\ce{CH2=CH-CH=CH2 + CH2=CHCOOH ->[\Delta]}$ 环己烯羧酸，二烯两根双键各开一半、新双键立在原来单键处）；羟基酸/二元醇/二元酸/氨基酸的分子内或两分子间酯化（醚化、成肽）脱小分子闭环——**环的大小数原子**是信息题标配。

## 七、官能团的引入、消除、搬移与保护

引入对照表（示例均已在前篇展开）：引入 $\ce{C=C}$＝卤代烃/醇的消去；引入 $-\ce{X}$＝烃取代或 $\ce{HX/X2}$ 加成或醇与 $\ce{HX}$ 取代；引入 $-\ce{OH}$＝烯加水、醛酮加氢、卤代烃水解、酯水解（$\ce{CH3CH=CH2 + HBr -> CH3CHBrCH3}$ 走马氏规则）；引入 $-\ce{CHO}$＝醇催化氧化、$\ce{HC#CH + H2O ->[催化剂][\Delta] CH3CHO}$（乙炔水化先成乙烯醇再异构）；引入 $-\ce{COOH}$＝醛氧化、酸性强氧化剂氧化醇、苯环侧链氧化、酯/酰胺水解。还原家族的明星是**硼氢化钠**：只把醛酮羰基放倒成羟基（$\ce{CH2=CH-CH2-CHO ->[NaBH4] CH2=CH-CH2-CH2OH}$），对孤立 $\ce{C=C}$、$\ce{C#C}$、羧基一概不动——比 $\ce{LiAlH4}$ 客气得多。

消除与搬移：加成消不饱和键、消去/氧化/酯化消羟基、加成/氧化消醛基、水解消酯基酰胺基碳卤键。**改位置**一招三式：$\ce{CH3CH2CH2Cl ->[消去] CH3CH=CH2 ->[加HCl][马氏] CH3CHClCH3}$——消出去、按规则加回来，卤原子就挪了家；羟基数目翻倍则「消去→加 $\ce{X2}$→双水解」（$\ce{CH3CH2OH -> CH2=CH2 -> ClCH2CH2Cl -> HOCH2CH2OH}$）。

**保护基三剑客**：多官能团分子做反应，非目标基团先藏后露——羟基怕氧化就**酯化保护**、怕强碱就**成醚保护**，事后水解复原；碳碳双键怕氧化，先加 $\ce{X2/HX}$「暂存」、氧化完再消去复原；羧基高温易脱羧，先转成**酯**保护再水解还原。

## 八、共聚与高分子方程收尾

两种烯烃共聚，链节按进料顺序并排：

$$
\ce{nCH2=CH2 + nCH2=CHCH3 ->[一定条件] [-CH2-CH2-CH(CH3)-CH2-]_{n}}
$$

涤纶（PET）方程收口缩聚计量：

$$
\ce{nHOOC-C6H4-COOH + nHOCH2CH2OH ->[催化剂] [-OC-C6H4-CO-OCH2CH2O-]_{n} + (2n-1)H2O}
$$

加聚看「开链手拉手」、缩聚看「脱小分子留残基」，判型与倒推单体的拉链法详见[生物大分子与合成高分子](/chemistry/polymer-biomolecule/)。
